# 百宝工具箱 产品结构与设计说明

> 本文档描述 ToolHub（百宝工具箱）的产品定位、信息架构、视觉体系与技术选型，是产品与工程层面的总纲。所有界面文案、视觉资产与代码均为本项目原创实现。

---

## 1. 产品定位

百宝工具箱是一个**纯浏览器端（client-side）工具聚合平台**：

- 核心承诺：文件永不上传、无需注册、无水印、无体积限制、加载后可离线使用。
- 技术：静态站点 + 客户端 JS/WASM 处理（Web Crypto、Canvas、pdf.js/pdf-lib、ffmpeg.wasm、浏览器内置 AI 推理框架等）。
- 不投放页面广告。

## 3. 视觉设计体系

**主题**：默认深色（深海军蓝底），可切换浅色。
- 背景基调 `#0a1018 ~ #0d1424`，面板 `#111a2c` 半透明 + 1px 细边框（rgba 白 6-8%）
- 强调色：靛蓝 `#6366f1`（首页/工具页均以靛蓝为主，个别分类使用主题色区分）
- 圆角：面板 16px、卡片 14px、胶囊 999px
- 字体：中文「系统无衬线 + Noto/苹方/雅黑」栈，本地优先，不加载外部字体
- 卡片：图标圆角方块（带低饱和彩底）+ 标题 + 右上角星标收藏按钮 + 两行截断描述
- 按钮：强调色实底胶囊（主）、细边框胶囊（次）

**首页区块顺序**：
1. Hero：徽章「370+ 工具 · 100% 本地处理」→ 超大标题 → 强调色高亮副标题 → 搜索框；右侧 2×2 特性卡（零上传/极速/离线可用/无限制）
2. 编辑器区：4 张大卡（PDF/视频/照片编辑器、数据工作台），各带 3 条特性 + 「打开」按钮
3. 工具目录：粘性分类 Tabs（图标+名称）+ 热门工具 8 卡 + 各分类区块（图标+标题+简介+数量徽章+View all，4 列卡片网格）
4. 信任区「为什么选择」3 卡（0 KB 上传 / <50ms / 完全离线）
5. 「如何工作」3 步骤（加载工具 → 拖入文件 → 即刻下载）
6. 支持格式分组（PDF 文档 / 图片 / 代码数据 / 音频）
7. FAQ 4 条
8. 最新指南 3 卡
9. 页脚 4 列（工具目录/分类/资源/法务）+ 品牌简介 + 版权行

**工具页布局**：
- 面包屑：首页 / 分类 / 工具名
- H1 大标题 + 右侧「收藏」按钮
- 隐私徽章：「🔒 100% 隐私 —— 在你的设备上运行，从不上传。加载后可离线使用。」
- 两栏：左侧工具面板（约 2/3 宽，圆角大面板）；右侧边栏：「本地信任盾」卡（处理位置=本地沙箱浏览器 / 数据传输=0 KB 上传 / 离线操作=100% 离线可用）+「快速指南」编号步骤卡
- 工具面板内：文件拖放区（虚线框 + 上传图标 + 「拖放到此处，或点击选择」+「在你的设备上处理 —— 从不上传」）、选项控件、执行按钮、结果区
- 面板下方：功能说明段落 + 相关指南 3 卡
- 通用交互：拖放上传、选项即改即预览、下载按钮、进度状态

**分类页**：H1 + 简介 + 卡片网格（同首页区块）。

## 4. 交互与通用组件清单
- 文件拖放上传区（多文件、排序、缩略图预览、删除）
- 收藏（星标）系统：全站任何卡片/工具页均可收藏，存 localStorage，导航「★ 收藏」页聚合
- 全站搜索（页头搜索 + 搜索弹窗；按名称/关键词/分类过滤）
- 明暗主题切换（持久化）
- 数值/日期/选择/滑杆控件；实时计算（边输入边出结果）
- 下载：单文件直接 blob 下载；多文件打 ZIP
- 进度条（大文件/模型加载）；「首次使用需下载模型，之后离线可用」提示（AI/OCR/转写类）
- Cookie 同意横幅

## 5. 技术选型

| 能力 | 选型 |
|---|---|
| 图片处理 | 原生 Canvas + OffscreenCanvas（零依赖引擎） |
| HEIC/TIFF 解码 | 纯 JS 解码库（heic2any / utif，懒加载） |
| OCR | tesseract.js（首次加载下载语言包） |
| 背景移除/上色/放大 | transformers.js（首次加载下载模型，浏览器缓存）+ 传统算法兜底 |
| PDF 读写 | @cantoo/pdf-lib（读写+加密）+ pdfjs-dist |
| PDF→Office | pdf.js 文本提取 + docx / SheetJS / pptxgenjs 生成 |
| Office→PDF | mammoth(docx→HTML)/SheetJS + jsPDF 输出（基础版） |
| 音频编解码 | WebAudio 解码 + WAV 自研编码 + lamejs（MP3） |
| 视频处理 | @ffmpeg/ffmpeg（懒加载 core，首次使用提示）+ Canvas/MediaRecorder 兜底 |
| 表格/图表 | papaparse + SheetJS + hyparquet + Chart.js + alasql(SQL) |
| 文本/AI | 词典/统计算法即时可用 + transformers.js 可选增强 |

**约束**：核心工具 100% 本地；需要模型/编解码器的能力统一遵循「首次加载后离线可用」模式，界面明确标注。

## 6. 产品决策
1. 品牌：**百宝工具箱 / ToolHub**，闪电 Logo（原创 SVG），口号「你的文件，永不离机」。
2. 语言：简体中文 UI；工具 URL slug 为全站唯一标识，一经发布不再更改。
3. 覆盖策略：**全部 11 分类 + 4 编辑器**全部建模；每个工具都有真实可用的实现（共享引擎 + 模式化组件），重度能力（AI/OCR/ffmpeg）懒加载并在 UI 标注首次下载。
4. 独立可部署：`npm i && npm run dev / build`，产物为纯静态文件，可放任意静态服务器。
