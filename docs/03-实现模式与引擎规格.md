# 实现模式与引擎规格（工程契约）

本文档是全部工具实现的**唯一契约**。所有工具组件/注册项必须遵守这里的接口，保证 375 项工具风格统一、可维护。

## 1. 目录结构

```
src/
  main.ts  App.vue  router.ts
  styles/            # 设计系统 CSS（tokens.css / base.css / components.css）
  data/              # categories.ts, guides.ts, site.ts
  lib/               # 共享引擎（见 §3）
  composables/       # useSaved.ts useTheme.ts useSearch.ts useModel.ts useToast.ts
  components/        # 通用 UI（见 §4）：layout/ common/
  pages/             # HomePage.vue AllToolsPage.vue CategoryPage.vue SavedPage.vue
                     # ToolPage.vue GuidesPage.vue GuidePage.vue AboutPage.vue ...
  tools/             # 每个分类一个目录，内含 registry.ts（注册表）与具体工具组件
    image/    registry.ts  components/*.vue
    video/    registry.ts  components/*.vue
    audio/    registry.ts  components/*.vue
    pdf/      registry.ts  components/*.vue
    data/     registry.ts  components/*.vue
    utility/  registry.ts  components/*.vue
    developer/registry.ts  components/*.vue
    finance/  registry.ts  components/*.vue
    business/ registry.ts  components/*.vue
    seo/      registry.ts  components/*.vue
    ai/       registry.ts  components/*.vue
    editors/  registry.ts（工作室注册入口；4 个工作室组件复用为 8 个 studio 工具：PDF/视频/照片/数据 × 编辑器+工作台双入口）
docs/               # 产品与工程文档
```

## 2. 工具注册表格式

每个分类一个 `registry.ts`，导出 `ToolDef[]`：

```ts
import type { ToolDef } from '@/types'

const tools: ToolDef[] = [
  {
    slug: 'merge-pdf',
    title: '合并 PDF',
    category: 'pdf',                 // 分类 id
    desc: '把多个 PDF 按顺序合并成一个文件，全部在浏览器本地完成。',
    keywords: ['pdf 合并', 'merge', '拼接'],   // 搜索关键词（中文/英文）
    component: () => import('./components/MergePdf.vue'),  // 懒加载工具组件
  },
]
export default tools
```

`ToolDef`（见 `src/types.ts`）：slug/title/category/desc/keywords/component/needModel?。
工具组件的约定：**不自带页面框架**，只渲染工具面板内容（见 §5 ToolPage）。需要与页面通信时用注入的 `toolMeta`。

## 5. 工具页壳（ToolPage.vue）

由路由 `/t/:slug` 承载：
1. 面包屑 → H1 + 收藏按钮 → 隐私徽章
2. 左：`<component :is="tool.component">`（工具面板内容）
3. 右：TrustSidebar（信任盾 + 快速指南[来自注册项 guide?，可省略则显示通用 3 步]）
4. 下方：工具说明（注册项 `about`，可选）→ 相关工具（同分类随机 3 个）→ 相关指南

工具组件内部只需要：输入区（FileDrop/textarea/表单）+ 选项 + 执行按钮 + 结果/下载。**不要**重复页面级标题/隐私徽章。

## 6. 十一种实现模式（含示例约定）

1. **text**：`TextTool.vue` 通用组件 + `registry.ts` 内声明 `{ kind:'text', transform: (input, opts) => output, options: [...] }`。输入/输出双 textarea + 复制/下载/交换 + 选项表单。
2. **calc**：`CalcTool.vue` 通用组件 + 配置化字段（fields: NumField/SelectField/DateField/CheckField...）+ `compute(values) => ResultRow[]`（label+value+强调位）。特殊布局（如图表）走自定义组件。
3. **img**：自定义组件用 `FileDrop` + `imageEngine.applyOps` + `CanvasStage` 实时预览 + `DownloadBar`。交互型（裁剪/取色/打码）在 canvas 上叠加鼠标交互层。
4. **imgcvt**：`ImageConvertTool.vue` 通用组件 + `{ from: string[], to: 'image/png'|'image/jpeg'|'image/webp', quality?: boolean }`。批量多文件 + ZIP。
5. **pdf**：自定义组件 + `pdfEngine`。页面型操作先渲染缩略图网格。
6. **aud**：自定义组件 + `audioEngine`；波形预览 + 操作按钮 + 编码选择。
7. **vid**：自定义组件 + `videoEngine`（Canvas/MediaRecorder 快路径）或 `ffmpeg.ts`（重转码）。ffmpeg 首次使用显示下载提示。
8. **data**：自定义组件 + `csvEngine`/`officeEngine`；表格用虚拟滚动（>1000 行分页即可）。
9. **compare**：`CompareTool.vue` 通用双输入 + 各自 transform/diff 函数；图像对比为专用组件。
10. **ai**：优先 `nlpEngine` 纯本地算法（即时、离线、诚实标注「规则模型」）；图像/AI 增强型（OCR/抠图/转写/翻译/描述/检测）用 `useModel()` 懒加载（tesseract.js / transformers.js），UI 显示模型下载进度与缓存说明。
11. **special**：完全自定义组件（二维码、科学计算器、录音机、番茄钟、发票、简历等）。工作室（`studio: true`）共 8 个注册项，复用 `editors/components/` 下 4 个组件（PdfStudio/VideoStudio/PhotoStudio/DataStudio），以「XX编辑器」「XX工作台」双入口出现在对应分类。

## 7. 质量与规范

- TypeScript strict；组件 `<script setup lang="ts">`；避免超长文件（>300 行须拆分组件/composable）
- 所有用户可见文案简体中文；注释中文
- 错误处理：解析失败给出中文友好提示（`useToast`）
- 大文件：异步 + 进度条；>50MB 给出提示
- 单元换算/金融公式等给出「计算口径」说明文字
- 所有文案与图片资源均为本项目原创（中文文案 + 自绘 SVG），不得引入任何第三方站点素材
