## 二、核心设计决策

1. **注册表驱动**：`src/tools/<cat>/registry.ts` 导出 `ToolDef[]`，聚合于 `src/tools/index.ts`；`slug` 即 URL（`/t/:slug`），发布后不改。新增工具 = 注册表加一条 + 懒加载组件/内联定义。
2. **四实现模式**：component（懒加载组件）/ textDef（TextTool）/ calcDef（CalcTool）/ imgcvt（ImageConvertTool）；工具组件只渲染面板内容，页面框架由 `ToolPage.vue` 统一承担。
3. **引擎分层**：重逻辑一律在 `src/lib/` 共享引擎（imageEngine/pdfEngine/audioEngine/videoEngine/csvEngine/textEngine/nlpEngine/finance 等 20+），工具组件只做输入交互；引擎 API 全表见基础设计规约 §9。
4. **懒加载纪律**：所有重依赖（pdfjs-dist、@cantoo/pdf-lib、lamejs、gifenc、chart.js、heic2any、utif、qrcode、jsbarcode、prettier、@ffmpeg/ffmpeg、mermaid/katex/jschardet/sql.js/libarchive.js/transformers.js 等）一律 `await import()`；静态入口只保留 Vue/router/样式。
5. **PDF/Office 元数据契约**：生成文件 producer/creator 统一写 `ToolHub`（pdfEngine `createDoc()`、officeEngine `htmlToPdfBlob` 内置）；读取外部 PDF 元数据必须 `updateMetadata:false`（@cantoo/pdf-lib load 构造时内存盖章陷阱）。
6. **路由与 SEO**：history 模式 + `base: '/'`，静态资源绝对路径；`scripts/gen-sitemap.mjs` 依 `site.siteUrl` 生成 sitemap.xml/robots.txt（域名待填，当前跳过 sitemap 仅出 robots）；宿主须支持 SPA 回退。
7. **离线数据集契约**：大体量词典/库放 `public/data/*.json`（共约 12.9MB），工具标 `needModel: true` + UI 首用下载提示，经 `utilExt.fetchDataset` 懒加载；wasm（libarchive/sqljs）随包 public/ 分发保证同源。

## 五、已知边界（UI 已诚实标注）

- 逐页实测拆分 PDF：共享资源跨卷重复计入，单卷略小于目标值。
- 字体转换：WOFF2 不支持（需 woff2 wasm，暂缓决策）。
- GIF 压缩：三参数（减帧/降色/缩放）网格，未做压到指定 KB 的自动二分。
- ECDICT 音标：源数据仅英式（us 与 uk 同值，UI 已注明）。
- 图像分类：MobileViT-Small + ImageNet-1k 英文标签；首用约 20MB（hf-mirror 镜像，唯一无备选，部分网络需真机回归）。
- email-signature-generator 复制走 ClipboardItem 富文本；不支持时降级纯文本。
- 分贝仪为参考级非计量级；调音器需 HTTPS 与麦克风授权。
- ffmpeg core 约 25–30MB 首用下载（unpkg CDN，无自建镜像）。

## 六、遗留建议（下轮）

1. siteUrl/icp 备案信息填写后重跑 build 出 sitemap（上线前必办）。
2. GIF 压到指定 KB 的二分搜索、PDF 按体积拆分的体积精确化可迭代。
3. transformers.js（image-classifier）真机验证模型下载链路（hf-mirror 在部分网络下可能需再回退）。
4. markmap 接线（Markdown 思维导图）、compress-docx 等储备件评估。
5. jschardet 打包后 1.14MB（gzip 709KB）偏大，可评估只打包常用编码模型子集。

## 七、关键工程坑位（防复发，测试/开发共用）

1. lunar-javascript：`Solar` 无 `getJieQi`；闰月 = `getMonth() < 0`，农历转公历闰月传负数月份。
2. turndown-plugin-gfm 表格规则遇 td 内块级元素整体失效 → mdEngine `htmlToMd` 前置拍平单元格内 `<p>`。
3. 专项附加扣除是报税抵扣项不是实际支出 → 到手工资口径 = 月薪×12 − 五险一金×12 − 税。
4. pinyin-pro 混排用 `nonZh: 'consecutive'`（spaced 会把英文/数字逐字符拆散）。
5. regjsparser：`group/quantifier.body` 恒为数组；命名分组/后顾断言需开 features 第三参。
6. 金融工具口径错误一律按严重缺陷处理，金标准哨兵锁定。
7. jschardet 检测用前 64KB 转 latin1 字符串；relationship.js 是 default 导出函数；otpauth ESM 形状要探测 `mod.TOTP ?? mod.default?.TOTP`；hanzi-writer `charDataLoader` 类型需 `as never`。
8. libarchive.js / sql.js 的 wasm 需拷至 public/（worker 同源加载）。
9. gen-tool-list 的 deriveMode 兜底：非 image 分类的自定义组件标 special 而非 img。
10. @cantoo/pdf-lib `load()` 构造时会把内存对象 producer 盖章为 pdf-lib → 读元数据必须 `updateMetadata:false`。
11. CodeFormatter 类工具的 QA 断言依赖输出标签文本契约（如风险提示行去 emoji 前缀保标签可匹配）。
12. **动态 import 两条铁律（BUG-001 双重根因，2026-11-15 修复轮沉淀）**：① 语言模块等带变量的模板字符串动态 import（`` import(`pkg/${x}.js`) ``）Vite 无法静态分析，产物保留原生 `import()` 浏览器解析不了 npm 说明符 → 必须写成「字面量 import 箭头函数映射表」逐条静态声明（哨兵已锁 `verify-defects.mjs` BUG-001 组）；② highlight.js/lib/core 是 ESM default-only 导出，`await import()` 拿到的是 namespace，裸用 `.registerLanguage` 报 not a function → 必须取 `.default`。此前 ② 被 ① 掩盖（语言 import 先抛错走不到注册行），修复 ① 时才暴露——修「第一层报错」后必须复验到功能可用为止，不能只看报错消失。
13. 导出引擎函数无调用方即无测试（BUG-002 numberToEnglish 小数 / BUG-003 plateValid m[3] 越界的共性根因）→ 新增导出函数至少配一条 Node 侧哨兵（`verify-defects.mjs`），含小数/越界等非常规入参。
