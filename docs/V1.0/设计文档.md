**防复发工程结论**（已写回代码注释/哨兵）：

1. lunar-javascript：`Solar` 无 `getJieQi`；闰月 = `getMonth() < 0`，农历转公历闰月传负数月份。
2. turndown-plugin-gfm 表格规则遇 td 内块级元素整体失效 → mdEngine `htmlToMd` 前置拍平单元格内 `<p>`。
3. 专项附加扣除是报税抵扣项不是实际支出 → 到手工资口径 = 月薪×12 − 五险一金×12 − 税。
4. pinyin-pro 混排用 `nonZh: 'consecutive'`（spaced 会把英文/数字逐字符拆散）。
5. regjsparser：`group/quantifier.body` 恒为数组；命名分组/后顾断言需开 features 第三参。
6. 金融工具口径错误一律按 C 级处理，金标准哨兵锁定。
