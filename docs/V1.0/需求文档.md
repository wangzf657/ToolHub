# V1.0 需求文档 —— 产品定位、渠道调研与需求基线

> 基线日期：2026-11-15 ｜ 全站 **511 个工具**（11 个内容分类 507 项 + 编辑器工作室 4 项，slug 全站唯一）。
> 本文是当前版本的**需求基线**：记录产品定位、调研渠道、各方向的需求依据（竞品/开源/规范三类参考）与明确不做清单；工具级快照见本目录 `工具清单-V1.0.md`。
> 硬约束（全量工具一律遵守）：**纯浏览器端、无后端、文件不上传**；重依赖一律 `await import()` 动态引入；slug 即 URL，发布后不改；所有文案与视觉资产原创。

## 一、产品定位

- **ToolHub / 百宝工具箱**：纯浏览器端工具聚合平台，核心承诺「你的文件，永不离机」——零上传、免注册、无水印、无体积限制、加载后可离线使用。
- 技术形态：静态站点 + 客户端 JS/WASM 处理（Web Crypto、Canvas、pdf.js/pdf-lib、ffmpeg.wasm、端侧推理框架）。
- 商业策略：不投放页面广告；国内线（备案 + 大陆 CDN + 百度收录），history 路由 + sitemap/meta 基建。
- 质量愿景：每个工具不只是「能用」，而是对标所在领域最强产品做到「好用」（七维体验口径见 `docs/测试要求.md`）。

**渠道共识方法论**：每个候选给竞品/开源/文档三类参考；被 ≥3 个独立渠道同时命中为强信号（如抽奖转盘、打字测试、节拍器、代码截图、成语词典、函数绘图、白噪音、调音器、工作日计算、睡眠周期、经期计算、PDF 扁平化均为三/四渠道共识件）。

**去重裁定**（与既有能力重叠、不单开的）：秒表（`countdown-timer` 中文名已含）、标准差（并入 `statistics-calculator`）、图片取色配色（已有 `color-palette`）、整篇文档转长图（已有 `markdown-to-image`）、IP/归属地查询（需后端）；`hash-generator` 支持文件模式后 `file-checksum` 并档；`mortgage-calculator` 缺逐月明细故 `amortization-calculator` 独立保留。

### 3.12 端侧 AI（本地推理，needModel 标注）

### 3.13 编辑器工作室（4 工作台）
