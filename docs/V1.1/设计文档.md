## 八、已知边界（诚实标注在对应工具 UI）

- 逐页实测拆分 PDF：共享资源跨卷重复计入，单卷略小于目标值

- 图像分类：MobileViT-Small + ImageNet-1k，英文标签；首用约 20MB（hf-mirror 镜像）
- 在线解压/SQLite/笔顺数据/OUI/成语等：首用下载已在注册表标 needModel + UI 提示
- email-signature-generator 复制走 ClipboardItem 富文本；不支持时降级纯文本

## 十、关键工程坑位（防复发）

- jschardet 检测用前 64KB 转 latin1 字符串
- relationship.js 是 default 导出函数；otpauth ESM 形状要探测 `mod.TOTP ?? mod.default?.TOTP`
- hanzi-writer `charDataLoader` 类型需 `as never`
- gen-tool-list 的 deriveMode 兜底：非 image 分类的自定义组件标 special 而非 img
- libarchive.js / sql.js 的 wasm 需拷至 public/（worker 同源加载）
