## 二、包一：同类合并 · 组件级（52 项）

**证据**：这些单格式工具与对应通用工具**共用同一个组件**（注册表 `component` 指向相同文件），删除条目即完成合并，通用工具的 title/desc/keywords 收编原关键词即可。

### 1.1 图片格式转换（删 14，现状 17 → 4）

现行 17 个转换工具中 14 个是 `imgcvt` 模式的单对转换，全部走同一 `ImageConvertTool`。

| 拟删 slug | 名称 | 去向 |
|---|---|---|
| png-to-jpg / jpg-to-png / webp-to-jpg / heic-to-jpg | 4 项 | → 新「图片格式转换」（输入自动识别，输出 PNG/JPG/WebP 可选，含质量与批量） |
| jpg-to-webp / png-to-webp / webp-to-png | 3 项 | 同上 |
| heic-to-png / avif-to-jpg / avif-to-png | 3 项 | 同上 |
| gif-to-png / bmp-to-png / tiff-to-png | 3 项 | 同上 |
| png-to-ico | 1 项 | → favicon-generator（已输出多尺寸 ICO，完全覆盖） |

**保留**：`svg-to-png`（栅格化倍率控制）、`ico-to-png`（ICO 目录逐帧解析导出是特色能力）、`psd-to-jpg`（PSD 解析 + 图层树）。
**小改造**：通用转换器需加「输出格式选择」（现 imgcvt 每条固定 target），解码层已有全部格式能力。
