# 工具清单总表（516 项 · V1.2 过渡蓝图：小游戏增量）

> **本版定位**：V1.1 的分组（领域族）与全量排序已落地——本清单由 `node scripts/gen-tool-list.mjs` 从注册表与 `src/data/menuGroups.ts`（`scripts/gen-menu-groups.mjs` 生成）重生成，三者顺序一致（哨兵 `run-menu-tests.mjs` 锁定）。
> **菜单大类 ≠ 数据分类**：菜单一级为 **6 个菜单大类**，是领域族的显示层归并——音视频 = 视频+音频；文档与数据 = PDF+数据；实用工具 = 实用+金融+商业+SEO+编辑器工作室。底层数据分类（12 个）、分类页、注册表 `category` 字段、路由、sitemap 不变；分类页按 12 数据分类组织（库存目录），菜单按 6 大类组织（任务导航）。
> slug 为全站唯一 URL 标识；中文名称为本项目原创命名；「模式」列沿用人工标注，详见 `docs/基础设计规约.md`。
> 模式缩写：`text`=文本转换 `compare`=双输入对比 `calc`=计算表单 `img`=图像画布 `imgcvt`=图像格式转换 `pdf`=PDF 操作 `aud`=音频 `vid`=视频 `data`=表格数据 `ai`=AI `special`=自定义组件

## 分组与排序口径

- **分组**：**6 个菜单大类 → 77 个领域族**（类内小标题），族内成员不跨数据分类（脚本断言锁定）；菜单大类 = 菜单一级（可折叠），领域族 = 类内聚拢小标题。
- **排序口径**（需求 R2.3）：组间与组内统一按 **使用频率 40% + 技术含量/差异化 25% + 人群广度 20% + 传播引流 15%** 加权；每个菜单大类小节的第一个工具 = 该大类**默认落地页**（菜单大类头点击目标，即「子工具默认路由是第一个工具」）。
- **大类节顺序**：图片 → 音视频 → 文档与数据 → 实用工具 → 开发 → AI（大众媒体处理在前，专业集群靠后）。
