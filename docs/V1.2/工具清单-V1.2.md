# 工具清单总表（364 项 · V1.2 终态蓝图：整合精简 + 小游戏）

> **本版定位**：V1.2 **终态蓝图**——2026-11-17 两轮拍板定稿（《工具整合精简提案.md》六包 + 激进增量 163 项拟删/合并 + 小游戏 P0 六款），作为本期开发的分组与排序依据。**落地时**以 `node scripts/gen-tool-list.mjs` 从注册表重生成并与本蓝图核对（行数一致、slug 一一对应）；**落地前**哨兵断言仍以《工具清单-V1.2-基线511快照.md》511 行为准。
> **账目口径**：基线 511 − 拟删 163 ＋ 新增合并载体 11 ＝ 359；＋小游戏净增 5 款（数独为 sudoku-solver 迁移升级，已含在 359 内）＝ **364**（次批 P1 记忆翻牌/黑白棋另 +2 → 366，不入本表）。
> **菜单大类 ≠ 数据分类**：菜单一级为 7 个菜单大类（原 6 类 + 小游戏），底层数据分类（13 个，新增 games）、分类页、注册表 `category` 字段、路由、sitemap 口径见《需求文档.md》R1/R7。
> **2026-11-17 IA 微调**：「AI 增强与修复」5 件归 AI 大类、4 个工作室归各自领域（photo→图片、video→音视频、pdf/data→文档与数据）；注册表层面 5 件迁 `ai` 分类、工作室改隶各域分类，`editors` 数据分类随之取消（首页编辑器区改按 `studio: true` 聚合，落地时复核）。
> slug 为全站唯一 URL 标识；「模式」列沿用人工标注；合并载体已按新定位改名，原单功能 slug 全部删除（上线前零死链窗口）。
> 模式缩写：`text`=文本转换 `compare`=双输入对比 `calc`=计算表单 `img`=图像画布 `imgcvt`=图像格式转换 `pdf`=PDF 操作 `aud`=音频 `vid`=视频 `data`=表格数据 `ai`=AI `special`=自定义组件

## 分组与排序口径

- **分组**：7 个菜单大类 → 71 个领域族（族内小标题）；族内成员不跨数据分类（脚本断言锁定）；每个菜单大类第一个工具 = 该大类默认落地页。
- **排序口径**（沿用 R2.3）：使用频率 40% + 技术含量/差异化 25% + 人群广度 20% + 传播引流 15%。
- **大类节顺序**：图片 → 音视频 → 文档与数据 → 实用工具 → 开发 → AI → 小游戏。
