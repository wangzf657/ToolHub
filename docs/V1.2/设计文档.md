## 二、结构与文件规划

### 2.1 引擎层（纯 TS、无 DOM，Node 可测）

- `src/lib/games/sudoku.ts`：由 `src/lib/utilExt.ts` 的数独段（`SudokuGrid`/`countSolutions`/`solveSudoku`/`generateSudoku`/`sudokuConflicts`，约 utilExt.ts:75-190）**迁出并扩展**——4×4 生成器、提示数区间 + 技巧门槛分级（逻辑求解器阶梯：Naked/Hidden Single → Locked Candidates → 数对 → X-Wing/鱼）、生成预算与降级。utilExt 仅此一处引用（SudokuSolver.vue），迁移后删除旧段，无兼容负担。
- `src/lib/games/gomoku.ts` + `gomokuAI.ts`：棋盘状态/胜负判定（含长连）/悔棋栈 与 AI（棋型评分表 + 切比雪夫 ≤2 候选裁剪 + α-β + 迭代加深 + 时间预算）分层；AI 走 Worker（`new Worker(new URL('./gomokuWorker.ts', import.meta.url), { type: 'module' })`，Vite 原生支持），主线程零阻塞。
- `src/lib/games/{g2048,snake,minesweeper,slidingPuzzle}.ts`：状态机 + 单测口径的核心逻辑；渲染在组件（Canvas 或 DOM 网格，组件内定夺，遵循定高/relative 容器惯例防图表式二次渲染坑）。
- 存档：各游戏进度/最高分 localStorage，key 前缀 `toolhub`（走 `src/composables/` 现有偏好模式）。

### 2.2 Word 打印（数独）

`officeEngine.ts` 新增通用 docx 表格导出（`docx@^9` 的 `Table/TableRow/TableCell` API）：题目卡 = N×N 网格表（宫线加粗边框、题号与难度小字、每页 1/2/4 题、可选答案页）；producer/creator 写 `ToolHub`（既有口径）；下载走 `lib/download.ts`。兼容目标：MS Word + WPS 双实测（qa 用例）。

## 四、已知边界与遗留

- 数独高级档出题耗时秒级：预算降级策略下可能拿到「提示数略高于目标区间」的唯一解题——UI 如实显示档位，不虚标。
- 五子棋困难档棋力受浏览器算力限制（对标站/客户端 AI 有差距），需求口径为「困难档 ≥ 深度 4 搜索 + 算杀」，不做神经网络。
- 移动端键盘游戏为「可玩」底线，触屏方向键 P1；真机矩阵随 qa 轮。
- 方块消除已按 2026-11-17 拍板移出 V1.2（Tetris 商标/trade dress 风险），入观察池；V1.2 裁剪链为次批两款（全站 518 → 516）。
- 观察池（每日挑战/变体数独/更多 Puzzle 系）一律不顺手实现，走后续版本。

## 五、门禁结论（2026-11-17 小游戏增量落地）

- **类型**：`npx vue-tsc -b` 0 错（npm run typecheck 有 TS6310 预存在问题，以 -b 为准，与基线一致）。
- **测试**：`npm run test` 全绿——254（textcalc+engine，243 过/11 警 0 败，警告为基线既有）+ 41 引擎 + 22 音频 + **57 小游戏引擎哨兵（新）** + 45 菜单/移动基座（7 大类/78 族/516 行/13 分类 EXPECT）+ 46 专项复验。
- **构建**：`npm run build` 通过（≈57s）；sitemap 因 siteUrl 未填跳过（基线遗留 OBS，不在本期范围）。
- **数独批量哨兵**：四档 × 50 = 200 题全部唯一解且与解一致；提示数口径 x4 3-8 / easy 36-45 / medium 28-34 / hard 24-30 全过；Node 端高级档最慢 25ms。
- **浏览器自测（dev + vite preview 生产构建两轮）**：
  - 接入：首页 7 大类胶囊、`/tools?cat=games`、`/games` 分类页、顶栏/工作台菜单第 7 类、搜索"五子棋"分组命中、直达/刷新/回退，1440 与 390 视口无横向溢出（385=380+滚动条 quirk 为基线特征）。
  - 数独：四档出题（提示数在带内、诚实降级标注实测有效）、数字键盘/键盘输入、笔记开关、冲突与错值标红、行列宫+同数字高亮、Esc 暂停/恢复、提示/撤销/重开/直接解出、手输求解回归、刷新续玩、Word 打印（页面导出 toast + Node 侧 docx 结构断言：1/2/4 题/页 × 3 题含答案页，宫线表格与分页计数正确）。
  - 五子棋：中级/困难 AI Worker 回应 123-131ms（生产构建同）、成五/堵五捷径、活三防守（困难档堵端点）、双人五连判胜 + 连线高亮、悔棋回撤一回合。
  - 贪吃蛇：启动/吃食(+3)/撞墙死、穿墙环绕、WASD、Esc 暂停、R 重开、最高分持久化、失焦暂停、方向键不劫持滚动。
  - 2048：合并/得分、单轮只合并一次、撤销一步（一次后禁用）、终局判定、Esc 遮罩、刷新续玩。
  - 扫雷：三档规格、首开安全洪泛、插旗/拔旗与剩余雷计数、高级 30×16 小屏横向滚动、踩雷揭雷、重开。
  - 华容道：3/4/5 阶打乱可解、点击/方向键移动、Esc、刷新续玩、完成横幅、完成后存档清除。
- **自测修复的 6 个缺陷（两轮收敛）**：① docx 布局嵌套数组致 1 题/页表格丢失 → layoutPage 扁平化；② checkbox 聚焦吞方向键（INPUT 一刀切排除）→ `keys.ts` 非文本输入放行；③ 扫雷剩余雷计数不随插旗更新（TypedArray 无响应性）→ HUD computed 挂版本号；④ 五子棋 AI 自落子被 thinking 守卫挡死 → place 守卫交调用方；⑤ `.row wrap`（不存在的类，沿旧组件笔误）移动端按钮行溢出 → `.row row-wrap`；⑥ 数独异步生成逐步 setTimeout 节流致高级档 ~800ms → 每 5 步批量让出（高级档 P95 ~156ms，5/5 无降级）。
- **Word 双端兼容（MS Word/WPS 实机打开）与真机矩阵**：未执行，随 `qa/V1.2/` 正式 QA 轮补。
