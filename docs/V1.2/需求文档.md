### 3.2 数独出题算法与正确性保证（调研 + 现状）

生成管线（业界标准做法，与现有 `utilExt.ts` 实现同构）：

1. **终盘生成**：随机化回溯填满 9×9（或 4×4）合法终盘。
2. **挖洞**：随机顺序逐格尝试移除，每移一格跑**解计数器**（`countSolutions(limit=2)`，`utilExt.ts:89`）确认解数 ≤1，否则回填；直到达到目标提示数或无可挖。
3. **唯一解硬保证**：任何被输出的题目都经过解计数器验证——这是「保证题目正确性」的构造性保证，也是现状代码已有的机制。
4. **分级口径（V1.2 升级点）**：现状三档按挖洞深度区分；升级为「**提示数区间 + 技巧门槛**」双口径——简单（约 38–45 提示，Naked/Hidden Single 即可解）→ 中级（约 30–34 提示，需 Locked Candidates / 数对）→ 高级（约 26–28 提示，需 X-Wing / 鱼 / 链以上）。技巧分级用逻辑求解器阶梯判定（参考 SudokuWiki 技巧分级），实现成本可控；生成预算内未达门槛则降级接受并如实标注。
5. **4 阶（4×4，2×2 宫）**：独立小生成器，挖洞逻辑同构，天然唯一解快。
6. **性能预算**：9 阶高级挖到 ~26 提示可能到秒级——设生成预算（超时接受次优唯一解 + busy 提示），出题放异步，避免卡主线程。

正确性三道防线：生成期唯一解校验 → **批量哨兵测试**（四档 × 50 题断言解数 = 1 且可解，进 `npm run test`）→ 作答期冲突检测与完成判定。

参考：[Stack Overflow: generate Sudoku boards with unique solutions](https://stackoverflow.com/questions/6924216/how-to-generate-sudoku-boards-with-unique-solutions)、[论文《Sudoku Puzzles Generating: from Easy to Evil》](https://zhangroup.aporc.org/images/files/Paper_3485.pdf)（终盘 + 按难度挖洞的完整管线）、[SudokuWiki 技巧分级（X-Wing 等）](https://www.sudokuwiki.org/x_wing_strategy)、[Wikipedia: Mathematics of Sudoku（proper/minimal puzzle 定义）](https://en.wikipedia.org/wiki/Mathematics_of_sudoku)。

### 3.4 五子棋 AI 方案（调研结论）

- **棋型评估**：按棋型打分——五连 > 活四 > 冲四 > 活三 > 眠三 > 活二…（权重等比，双威胁如四三/双活三提权至必胜级）。
- **候选裁剪**：只考虑已有棋子切比雪夫距离 ≤2 的空点，剪枝量级从 225 降到 ~20-40。
- **搜索**：α-β 剪枝 + 迭代加深；三档难度 = 入门（贪心 + 受控失误率）/ 中级（深度 2）/ 困难（深度 4 + 算杀）。
- **性能预算**：困难档单步 ≤1s；AI 计算放 Web Worker（Vite 原生支持），超预算中断返回当前最优。
- 参考：[gobang 算法教程](https://github.com/lihongxun945/gobang)、[知乎：从零开始开发五子棋 AI](https://zhuanlan.zhihu.com/p/700942256)。

## 五、摸鱼场景设计公约（本期全局 UX 约定，验收逐条对照）

1. **低调不显眼**：视觉完全跟随全站工具面板语言（同令牌、同组件体系），低饱和配色；主舞台宽度 ≤ ~560px，融入工作台右区，无大横幅、无大动画。
2. **静音**：全线无音效，也不提供音效开关（做就是负担）。
3. **无打断**：胜负/结算用内联小面板与 toast，无全屏庆祝、无弹窗、无 confetti。
4. **Esc = 暂停**：一键暂停并盖静态遮罩（只写「已暂停」），再按恢复；计时类游戏（贪吃蛇/2048/华容道/数独计时）页面失焦自动暂停。
5. **键盘优先**：全部游戏纯键盘可玩（含 Esc 暂停、R 重开、方向键防页面滚动劫持）；鼠标不离开小范围。
6. **状态可续**：进度与最高分存 localStorage（`toolhub` 前缀），刷新/关页续玩。
7. **暗色主题与移动端**：明暗同源令牌正常；移动端至少可玩（触屏方向键为 P1 增强，不阻断验收）。

### R3 五子棋（P0）

**验收标准**：困难档 vs 随机走子 20 局全胜（对局脚本可重复）；单步 P95 ≤1s 不冻 UI；悔棋/重开/胜负判定正确；双人模式轮转无误。
