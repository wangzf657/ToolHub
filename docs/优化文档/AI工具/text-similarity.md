## 结论与优先级

**交互优化** · P2（若补 diff 视图可升级为"交互优化 + 需拓展"）

判据：无 P0 硬伤、无功能名实冲突（:99 口径说明兜底）；核心差距是对比品类的标配"差异可视化"缺席——相似度数字之后用户仍要肉眼找差异。

## 扣分点明细

1. 【功能-核心】无 diff 可视化：组件结果区只有数值（:87-100），"哪里不一样"缺席——站内 developer/TextDiff 已有 diff 引擎却未复用/互挂，查重闭环断在最后一步
2. 【实用价值】"词级相似（中文分词）"标签名实有差：底层是 tokenizeWords 2-gram 伪分词（`nlpEngine.ts:473`；`textEngine.ts:606-613`，家族共性）且**不过停用词**——"的了/是在"类伪词双方同现反而抬升词级分；标签应改"词频重合（2-gram）"或修复分词
3. 【可用性】长文本编辑距离总是">4000 字"占位（:97）：无抽样估计等降级方案，超限后该指标直接报废
4. 【交互】无示例对预填：A/B 空窗 placeholder-only（:78-84），落后于 sentiment/entity/question-answering 同家族的预填实践；也无"交换 A/B"按钮（对称算法下的便利项）
5. 【功能】综合分口径未解释：avg=(cosine+jaccard+lex)/3 三指标等权（:66），词级弱指标拉低中文改写对的分值——权重不可配、口径无说明
6. 【灵魂】四级判定阈值无解释：0.8/0.5/0.25 分界（:67）直接下"疑似重复/主题相关"结论但无口径说明、不可调
7. 【功能】无算法详情展开：每卡只显示百分数，不展示共享/差异片段清单（如"共同 2-gram 45 个"），数值不可下钻
8. 【交互】仅支持 A/B 单对：查重场景常需"原文 vs 多个候选"一对多批量对比，当前双窗结构做不到（:76-85），只能反复粘贴

## 行业对标与差距

- **diffchecker.com**（对比交互标杆）：行级/词级 diff 高亮+行号+同步滚动，多文件类型。差距：**diff 高亮是纯前端完全可实现**（站内已有 TextDiff 引擎），"相似度数字→差异定位"闭环缺席属真差距。
- **HF transformers.js 句向量**（纯前端天花板参照）：MiniLM 类模型量化后浏览器内算语义相似度，语序调换分数稳定——与面板内"非语义模型"诚实标注（:99）正对应，是根治"语序敏感"的正当路径（needModel 纪律）。
- 借鉴优先级：**diff 视图（复用 TextDiff）> 示例对预填+交换按钮 > 综合分口径说明 > 词级标签正名 > 语义向量双引擎**。

## 可拓展性

- 短期（1 周）：A/B 预填示例对+交换按钮；verdict 阈值 tooltip 说明；结果一键复制（五指标+判定文案）
- 中期（1 月）：内嵌"差异对比"Tab（复用 developer/TextDiff 引擎）；>4000 字改分段抽样编辑距离估计；txt/md 文件拖入对比
- 远期（架构级）：transformers.js 句向量语义相似度双引擎（词面/语义切换）；批量查重（多文本两两矩阵）

## 优化处方（验收标准）

1. **diff 联动**：结果区加"差异对比"Tab，复用 TextDiff 渲染行级差异。→ **验收：预填改写对（3 处替换）在 diff 视图中 3 处高亮可数**
2. **示例与交换**：空态加"填入示例"按钮+ A/B 头部交换图标。→ **验收：一键填充后结果区立即出数；交换后各指标数值不变（对称性验证）**
3. **口径说明**：综合分卡悬停显示"三指标等权平均；词级为 2-gram 词频重合"。→ **验收：文案与实现一致，词级卡标签改为"词频重合（2-gram）"**
4. **长文降级**：>4000 字时编辑距离卡提供抽样估计（每 500 字取 200 字段）并标注"约 N（抽样估计）"。→ **验收：粘贴 8000 字文本不再显示固定">4000 字"占位**
5. **阈值可调**："疑似重复"线提供严格 0.9/标准 0.8/宽松 0.7 三档。→ **验收：同一输入在三档下判定文案按阈值正确切换**
