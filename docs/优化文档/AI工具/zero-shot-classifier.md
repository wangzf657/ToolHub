## 扣分点明细

1. 【实用价值-核心】"零样本"名不副实：真零样本 = NLI 蕴含模型对任意标签推理；本实现是文本与"标签+扩展词+示例"的 token 集合相似度（`nlpEngine.ts:472-479`，inter/√(sa·sb)），AUTO 表未覆盖的标签（如"物流""售后"）只剩标签词 2-gram 重叠，两字标签几乎必然失配
2. 【灵魂-规约红线】归一化置信度误导：confidence = score/Σscore（ZeroShotClassifier.vue:63-66），四个标签相似度全部 <0.05 时照样显示"归一化置信度 45.2%"——绝对分极低的"矮子里拔将军"没有低置信提示，与诚实标注纪律冲突
3. 【功能】无批量：运营场景"100 条留言打标签"只能一条条来
4. 【功能】单选强制：实际评论常同时含咨询+吐槽，无"输出 Top-2/多标签"开关
5. 【交互】示例句无引导填充：AUTO 表已有扩展词却不能一键转成示例句；label/example 两 input 无校验（纯空格也计入）
6. 【灵魂】无"为什么是这个标签"解释：命中了哪些扩展词/哪些词与示例句重叠不展示（对比 emotion-detector 有命中词 chips）
7. 【交互】只显示归一化百分比，原始相似度分不展示（结果行仅 confidence(s.score)，ZeroShotClassifier.vue:103）——用户无法判断"45% 是真高还是矮子里拔将军"
8. 【共性】面板首控件受 266px 装饰层前缀（共性-根因 1）；结果区无弹性高度（共性-根因 2）

## 行业对标与差距

- **HF Spaces 零样本分类 demo**（transformers.js 同源天花板）：candidate labels 随填、模型输出逐标签蕴含概率、支持 multi-label。差距：任意标签泛化属模型能力（架构天花板），纯前端可逼近 = Xenova 模型端侧部署（该管线 transformers.js 有官方支持），UI 侧 multi-label 开关可先行。
- 借鉴优先级：**低置信警告与能力标注 > multi-label 开关 > transformers.js NLI 双引擎 > 批量模式**。

## 可拓展性

- 短期（1 周）：置信度 <40% 时加"区分度低，建议补示例句"警告；命中词解释 chips；空格校验
- 中期（1 月）：multi-label 阈值开关；批量模式（逐行出逐行标签，导出 CSV）；示例句一键生成
- 远期：transformers.js 零样本 NLI 模型双引擎（词汇档即时 / 模型档准确），needModel 纪律下载预告

## 优化处方（验收标准）

1. **能力标注**：notice 改为"词汇相似度零样本（非神经网络）：内置扩展词覆盖常见标签，其他标签请填示例句"。→ **验收：面板首屏可见，且不再单独出现"零样本"裸术语**
2. **低置信警告**：top1 绝对相似度 <0.15 时结果卡变警示色并提示补示例句。→ **验收：用"物流太慢"对未覆盖标签"售后"分类时出现警示**
3. **multi-label**：加"允许多标签"开关（阈值 0.6×top1）。→ **验收："想问下怎么退货，太气人了"同时命中咨询与吐槽**
4. **命中解释**：每标签行下展示命中的扩展词/示例词 chips。→ **验收：命中词与文本子串一致可核对**
5. **批量模式**：多行文本逐行分类导出 CSV。→ **验收：3 行输入导出 3 行标签结果**
6. **原始分透出**：每标签行显示"归一化 X%｜原始相似度 Y"。→ **验收：Y 与 similarity() 返回值一致，可核对**
