## 结论与优先级

**交互优化 + 需拓展** · P1（起始号/后缀/页范围是法律刚需拓展；页面级预览与进度是交互主修）

判据：56 分无硬伤；用户群专业度高（律所/档案），对 Adobe 标准的参数差距（起始号/后缀/续编）属需拓展，零预览零进度属交互摩擦。

## 扣分点明细

1. 【功能】无起始号与续编：notice 自认"暂不支持自定义起始号"（BatesNumbering.vue:75）——法律实务今天编到 ABC-000120、明天新一批从 121 续编是刚需，现在只能重头从 000001 编；Adobe Bates 的 start number 一栏即可解决
2. 【功能】无后缀与日期戳：Adobe 支持"前缀+编号+后缀（如 ABC-000001-DEP）"及日期插入；本工具前缀只有西文且无尾部
3. 【功能/诚信】中文前缀直接失败：引擎 StandardFonts.Helvetica WinAnsi 无法编码（pdfEngine.ts:357），错误提示"前缀仅支持西文字符"（:34）在执行后才弹出；同目录 HeaderFooter 已有 cjkText 贴图兜底路径（HeaderFooter.vue:33-52）却未复用——同族工具中文能力双标，"案卷-"这类中文前缀并非不可做
4. 【可用性】零页面预览：格式 mock 只有前缀和位数（:71），位置（右下/底部居中）、字号在页面上的观感、与文档已有页脚的碰撞风险全部下载后才知道；Adobe/iLovePDF 均有页面级实时预览＋位置图示
5. 【交互】输出文件名丢弃原文件名：zip 内统一叫"{prefix}-已编号.pdf"（pdfEngine.ts:366），10 份卷宗产出 ABC--已编号.pdf、ABC--已编号-2.pdf…（download.ts:36-41 只能加 -2 后缀去重）——编号后无法对应回原文件，法律归档场景不可接受
6. 【功能】位置仅 2 种＋边距锁死 y=24/x=28（pdfEngine.ts:362-363）：无法避让已有页脚/页码；Adobe 提供 6+ 位置预设与边距参数
7. 【性能】无进度：引擎无 onProgress 回调，多文件大批量编号期间界面只有按钮 spinner（:69）

## 行业对标与差距

- **Adobe Acrobat Pro（Bates）**：前缀/后缀/起始号/日期、6+ 位置预设与边距、页面实时预览、支持"从上次编号继续"。差距：**专业参数面全面代差**；其中起始号与页面预览属纯浏览器可及（pdf-lib drawText 已具备），并非架构天花板。
- **iLovePDF Add Bates**：拖拽即用＋页面预览＋每文件编号范围设置。差距：预览与批量元信息。
- 借鉴优先级：**起始号（一天级，引擎 counter 初始化一行）> 页面级预览（复用 renderPageToCanvas）> 输出保留原文件名 > 后缀/日期 > 中文前缀贴图兜底（复用 cjkText）**。
- 术语教育：目标用户法律从业者对"Bates"耳熟能详，但 notice 应补一句使用场景说明（"用于卷宗/证据材料唯一标识"）帮助泛用户理解；当前文案只讲参数不讲场景。

## 可拓展性

- 短期（1 周）：起始号输入（引擎 counter=start）；输出名改"{原文件名}-已编号.pdf"；引擎加 onProgress 逐文件进度条
- 中期（1 月）：后缀＋日期变量；页面级预览（首页渲染叠加编号示意）；位置扩到 6 种＋边距；中文前缀走 cjkText 贴图
- 远期：并入"页面信息工作台"（与页码/页眉页脚统一模板引擎）；编号序列保存（localStorage 记忆上次编号，实现真续编）

## 优化处方（验收标准）

1. **起始号**：新增"起始编号"输入（默认 1）。→ **验收：填 121 后编号从 ABC-000121 开始，跨文件连续到第 N 页**
2. **保留原文件名**：zip 内文件名为"{原名}-已编号.pdf"。→ **验收：拖入 3 个不同名 PDF，zip 内 3 个文件名可一一对应原文件**
3. **页面级预览**：载入文件后渲染首页，叠加编号示意图（按当前位置/字号）。→ **验收：位置从右下切到底部居中，预览编号即时移动**
4. **进度反馈**：引擎加 onProgress，多文件时显示"第 i/N 个文件·第 j 页"。→ **验收：20 个文件编号过程中进度条持续推进且完成时归 100%**
5. **中文前缀**：hasCJK 命中时走 stampImageTexts 贴图路径。→ **验收：前缀"案卷-"编号成功且文字可正常显示不乱码**
6. **后缀与日期**：新增后缀输入与日期开关。→ **验收：前缀 ABC、后缀 -B、日期开启时第 1 页显示"ABC-000001-B-20261111"格式**
