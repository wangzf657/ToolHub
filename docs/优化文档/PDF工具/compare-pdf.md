## 结论与优先级

**交互优化 + 需拓展** · P0（差异不可导航=可用性硬伤；扫描件假"完全一致"=疑似功能问题，交用户决定）

判据：52 分；可用性 9/20 触发硬伤红线（核心任务"找到差异"在长文档上结构性受阻）；无文本层静默误报是正确性缺陷。

## 扣分点明细

1. 【可用性-硬伤边缘】差异定位零辅助：结果按页全量平铺（v-for pages，ComparePdf.vue:107），无"只看有差异页"开关、无"跳到下一处差异"导航、无差异页目录——diffchecker 的价值就是"秒找到改了哪"，本工具让用户在一百张卡片里肉眼扫描
2. 【疑似功能问题】扫描件假"完全一致"：pdfPageTexts 对无文本层页返回空串（pdfEngine.ts:681 trim），两份扫描件对比时全部空===空 → changedPages=0 → toast"两个文件的文本完全一致"（ComparePdf.vue:75）；"请确认两个 PDF 都有文本层"提示（:77）只在抛错时出现，静默路径无文本层检测——错误结论比没有结论更伤信任
3. 【疑似质量】中文 diff 粒度粗：diffWordsWithSpace 按空白分词（:54），中文段落无空格粘成超长 token，一字之改把整句/整段标红——主受众（中文合同）恰是最受伤场景；应 CJK 场景改 diffChars 或按标点切分
4. 【功能】无并排双栏视图：单流 inline ins/del；diffchecker PDF 模式为左右对照＋行号，Adobe Compare 另有视觉版面并排（缩略图对照属本站架构内可及）
5. 【功能】页对齐假设过强：严格 page i ↔ page i（:40），新版插入/删除一页后其后每页全标差异，无对齐/移位检测提示——用户看到的是"30 页全变了"而非"插入了 1 页"
6. 【交互】无进度：busy 只有按钮 spinner（:98-99），双文件提取+逐页 diff 期间无"已提取第 i 页"反馈；diff-body 260px 钉高（:142-148）叠加嵌套滚动（共性-根因 2）

## 行业对标与差距

- **diffchecker（PDF 模式）**：左右双栏对照＋行号＋行内高亮＋"仅显示差异"过滤＋差异计数跳转。差距：**导航与视图结构代差**——过滤+跳转是本工具最急迫的补课项。
- **Adobe Acrobat Compare Files（云）**：文本差异+视觉差异双报告、页对齐智能处理、差异摘要首页。差距：页对齐与视觉对照；缩略图并排本站可做（renderPageToCanvas 现成）。
- 借鉴优先级：**只看差异页过滤（半小时级）> 差异页目录/跳转 > 中文切词 diff > 双栏切换 > 页对齐提示（检测页数不同即警告）**。

## 可拓展性

- 短期（1 周）：结果顶部加"仅看有差异页"开关（changed 过滤，一行 filter）；检测两侧页数不同或文本层为空时黄色警告条；diff-body 弹性高度
- 中期（1 月）：差异页目录侧栏（页码+变更字数点击跳转）；中文 diffChars 切换；导出差异报告（md/pdf）；提取进度逐页回调
- 远期：视觉版面对照模式（双栏缩略图渲染+差异页红框标记，向 Adobe Compare 逼近）；与 text-diff（开发工具）共享 diff 展示组件

## 优化处方（验收标准）

1. **差异过滤**：结果区顶部加"仅显示有差异的页"开关（默认开）。→ **验收：100 页文档改 2 页时，开启后仅显示 2 张卡片且统计行不变**
2. **文本层护栏**：对比前检测任一侧全文为空时显示警告"该文件可能为扫描件（无文本层），文本对比结果不可靠"，不输出"完全一致"。→ **验收：两份扫描件对比出现黄色警告而非"文本完全一致"toast**
3. **中文 diff**：检测到 CJK 占比 >30% 时改用字符级 diff。→ **验收：中文合同改 1 个字，高亮范围仅覆盖该字附近而非整段**
4. **差异导航**：结果侧栏列出差异页（页码+新增/删除字数），点击滚动定位。→ **验收：点击"第 7 页"后视口滚至该卡片**
5. **进度反馈**：提取阶段显示"正在提取第 i/N 页"。→ **验收：50 页文档对比时进度文案逐页推进**
6. **页数对齐警告**：两侧页数不同时顶部提示"页数不一致（A:10，B:11），第 11 页起按新增处理"。→ **验收：警告文案列出两侧实际页数**
