## 扣分点明细

1. 【功能-疑似问题】CMYK 图色偏：rawToCanvas 第一分支把 data.length === w×h×4 的流直接按 RGBA 解释（`pdfEngine.ts:761-765`），DeviceCMYK 8bpc 原始流恰好同长度——4 通道被错读成 4 通道 RGBA，颜色错乱且无警示（DCT 封装分支的 CMYK JPEG 浏览器也可能不渲染）
2. 【功能】无去重与引用计数：逐页遍历 Resources（:703-744），同一 XObject 被多页引用（页眉 logo、水印）即重复提取 N 份占满网格——pdfimages 有 -dup 过滤思路，本工具连"重复 n 份"标注都没有
3. 【功能】无最小尺寸过滤：1px~50px 装饰点线、渐变块全部入列（:722 仅跳过 w/h 为 0），200 张结果里 180 张是碎图，找正图靠肉眼
4. 【可用性】无尺寸信息：网格只显 KB（:65），不显 w×h 与格式（JPEG/PNG 分不清，:26 命名仅按编码分支），"这张能不能用"要下载后查
5. 【功能】JPX/CCITT/LZW 等滤镜静默跳过：rawToCanvas 不认即 return null（:790），扫描件常用的 CCITT 传真图无声消失，仅 catch 单图跳过（:740-742），最终无"n 张图因编码不支持未提取"披露
6. 【功能】透明通道（SMask）忽略：PNG 化分支不含软掩码（alpha）读取，原图透明背景提取后变黑/白底
7. 【交互】无筛选与批量粒度：只有"逐张下载/全部打包"两端（:49-55），中间缺"按大小筛选/仅下载 JPEG/清除单张"等操作
8. 【交互】重复提取不清理上一轮的选择态：results 整体重建（:25）没有保留用户标记，二次提取（换参数后）无对比能力——本工具无参数，此条降级为"无重试/过滤参数"的功能面窄化

## 行业对标与差距

- **Poppler pdfimages（CLI）**：`-list` 列出每张图的页码/编码/色彩空间/尺寸再决定 `-all`（保原编码原色彩空间导出）或 `-png`。差距：**元数据透明度**（list 能力）与 CMYK/CCITT 覆盖；-all 的"保原编码"本工具 JPEG 分支已做到一半。
- **extractpdf.com（云）**：上传即网格预览+勾选下载，支持按尺寸筛选。差距：筛选与勾选粒度。
- 借鉴优先级：**w×h+格式标注 > CMYK 正确转换（canvas 前做 ICC/反色变换）> 最小尺寸阈值选项 > 重复引用合并标注**。

## 可拓展性

- 短期（1 周）：网格标注"名称 · w×h · JPEG/PNG · KB"；提取完成披露"另 n 张因编码不支持跳过"；重复图按内容 hash 标"与第 k 张重复"
- 中期（1 月）：CMYK→RGB 转换（4 通道反相公式或内嵌 ICC）；最小尺寸过滤输入；SMask alpha 合成；筛选栏（格式/大小/页码）
- 远期：与 pdf-to-images（页面截图）双模式入口"截图 or 原图"二选一，共享网格预览组件；矢量图导出评估（页面区域 SVG 化）

## 优化处方（验收标准）

1. **元数据标注**：每格显示 `图片-n · 1920×1080 · JPEG · 340KB` → **验收：网格标注与实际图片属性一致（抽查 3 张与下载后属性比对）**
2. **CMYK 修复或警示**：CMYK 流走反相转换后再 putImageData；短期先在完成 toast 披露"含 n 张 CMYK 图可能色偏" → **验收：CMYK 样例提取后颜色与原 PDF 目视一致（或出现警示 toast）**
3. **去重标注**：内容 hash 相同的图只保留一份并标注"重复 n 处引用" → **验收：10 页同 logo PDF 提取后 logo 仅 1 格且注明重复数**
4. **最小尺寸过滤**：选项"过滤小于 N px 的图"（默认 0，可设 100）→ **验收：设 100 后碎图消失且结果计数相应减少**
5. **解码失败披露**：完成 toast 追加"n 张图编码不支持（如 JPEG2000）未提取" → **验收：构造含 JPX 图的样例，披露数字与实际跳过数一致**
