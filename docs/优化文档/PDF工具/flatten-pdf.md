## 扣分点明细

1. 【功能-语义】勾"移除批注"是整键删除 Annots（:32-40）而非外观固化：便签/自由文本注释的可见内容直接消失——用户若想把批注内容永久留在页面上（扁平化的常见动机），得到的是内容被清掉；Acrobat 扁平化=烙进页面
2. 【功能-一致性】去注释不区分链接：整键删除连 /Link 目录跳转一起删（:36-37），而兄弟工具 pdf-annotation-remover 默认保留链接（PdfAnnotationRemover.vue:15）——同一动作两个入口两种语义，无任何提示
3. 【可用性】无法验证已扁平：完成仅 toast 计数（:46），不回读输出校验 getForm().getFields() 为 0；"归档前保险一步"的保险性要用户自己在别的软件里确认
4. 【功能】表单结构异常时产出"伪扁平"文件：getForm 抛错仅 warn"已跳过表单压平"（:30）但仍继续保存下载名为"扁平化.pdf"的未压平文件——文件名与内容不符，归档场景有欺骗性
5. 【功能】XFA 表单不支持：pdf-lib 无法压平 XFA（老 LiveCycle 表单），同样落入"跳过+照常下载"路径且不解释 XFA 是什么
6. 【交互】无输入确认区：看不到文档有几个字段、字段里填了什么就直接压平；误压平唯一恢复方式是重新上传原件
7. 【灵魂】字段为 0 的文档不劝退：toast"压平表单字段 0 个"照常产出，缺"该文档没有表单字段，无需扁平化"的前置判断

## 行业对标与差距

- **Adobe Acrobat Preflight/扁平化**：表单与注释均可选"烙进页面"，保留视觉外观只移除交互性；可预览字段清单。差距：注释语义（固化 vs 删除）+ 字段可视化。
- **Sejda Flatten**：压平前列出表单字段数量与类型，完成后预览首页。差距：输入确认与结果确认两端。
- 借鉴优先级：**注释固化选项（默认删除、可选烙入）> 保留链接复选（对齐 annotation-remover）> 字段计数前置展示 > 压平后回读自证**。

## 可拓展性

- 短期（1 周）：字段计数前置（拖入后显示"含 N 个表单字段"）；字段为 0 时提示并禁用主按钮；错误路径不再产出"扁平化.pdf"而改为"未压平-原样.pdf"
- 中期（1 月）：注释扁平化（读 Annots 外观流烙进页面内容再删注释，复用 renderPageToCanvas 路线）；保留链接复选框
- 远期：与 pdf-annotation-remover、protect-pdf 组成"定稿三件套"工作流入口（扁平→去注释→加密）

## 优化处方（验收标准）

1. **字段前置计数**：拖入后显示"该文档含 N 个表单字段"。→ **验收：含 5 个字段的 PDF 计数为 5；纯文档显示"无表单字段"且主按钮禁用**
2. **失败不冒名**：表单压平被跳过时输出名改为"未压平-原样.pdf"并在 toast 说明。→ **验收：XFA 样例走此路径，下载文件名与 toast 一致**
3. **压平自证**：完成后回读输出统计字段数并展示"输出字段数：0 ✓"。→ **验收：5 字段文档压平后回读字段数为 0**
4. **注释语义选项**：新增"批注内容烙入页面（保留视觉）"复选，默认关。→ **验收：带便签的 PDF 勾选后，便签文字在输出页面仍可见且不可编辑**
5. **链接保护**：新增"保留链接"复选（默认开），与 pdf-annotation-remover 行为对齐。→ **验收：含目录跳转的 PDF 勾选后输出内链仍可点击**
