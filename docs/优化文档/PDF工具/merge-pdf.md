## 结论与优先级

**交互优化 + 需拓展** · P1（页数显示与拖拽排序是第一步，页级合并是第二步）

判据：58 分；可用性扣分（多文件零元信息+无结果预览）与交互摩擦（逐位排序）并存；与 iLovePDF 的差距一半在交互一半在功能粒度（页级合并=需拓展）。

## 扣分点明细

1. 【可用性】多文件合并时不显示任何文件的页数——PdfToolBase 的 `pdfInfo` 查询只在 `list.length === 1` 时执行（`PdfToolBase.vue:36-45`），iLovePDF 每张缩略图都带页码；用户对"合并出来多少页"零预期
2. 【交互】排序靠 ↑↓ 逐位移动（`FileDrop.vue:57-64` move 函数、:104-105 按钮），文件多时是"点 N 次箭头"的体力活；iLovePDF 拖拽缩略图直接换位
3. 【美观/诚信】文件行渲染 GripVertical 手柄图标（`FileDrop.vue:98`）暗示可拖拽，但全组件无 dragstart/dragover 处理——图标是假的
4. 【可用性-硬伤边缘】合并完成即 `saveBlob` 自动下载（`MergePdf.vue:25`），无页数/大小确认、无结果预览（模式 F 共性，见审计底稿模式 F 行）；顺序错了只能重新合并
5. 【功能】无页级合并：iLovePDF 的杀手级场景"把 A 的第 2-5 页插到 B 后面"做不到，需先 split 再 merge 两跳
6. 【灵魂】文件列表无汇总行（共 N 个文件 · X MB · 合并后约 Y 页——页数可从 pdfInfo 拿）；空态无示例说明"顺序=合并顺序"直到用户已添加文件才看到 hint（MergePdf.vue:43）
7. 【交互】输出文件名固定"合并结果.pdf"（`MergePdf.vue:25`）不可自定义，多轮合并后下载目录里全是同名文件互相覆盖（浏览器自动加 (1)）
8. 【交互】同一文件可重复添加且无去重/重复警告（`FileDrop.vue:23-32` addFiles 直接 append），误拖两次会把整个 PDF 内容合并双份，用户毫无感知

## 行业对标与差距

- **iLovePDF**：合并页 = 缩略图网格，每页带序号、可拖拽换位、可旋转、可点选某文件某页范围；顶部工具条含"移动到最前/最后"。差距：**排序可视化与页级粒度双重代差**。
- **Smallpdf**：拖拽缩略图排序+合并后自动预览打开。差距：结果确认环节。
- **PDF24**：免费且提供页级选择合并、书签保留等高级选项。差距：输出选项（是否保留书签/表单域）。
- 借鉴优先级：**页数显示与总页汇总 > 拖拽排序（HTML5 DnD 即可）> 结果预览首页缩略图 > 页级合并**。
- 站内联动：images-to-pdf（扫描图片→PDF）与 merge-pdf 是同一条工作流，目前要在两个工具间重复拖文件——工作台化后应共享文件队列。

## 可拓展性

- 短期（1 周）：多文件时逐个调 pdfInfo 显示"名称 · N 页 · X MB"+底部汇总行；实现文件行 HTML5 拖拽换位（让 GripVertical 名副其实）
- 中期（1 月）：合并完成后展示首页缩略图+总页数确认条（复用 PageThumbs.vue）；页级选择合并（复用 PagePickerTool 的页码解析）
- 远期：与 split-pdf、reorder-pdf、page-numbers 整合为"PDF 页面工作台"（模式 E，向 PdfStudio 靠拢），一个画布完成合并/拆分/重排
- 短期补强：合并错误时保留文件列表与参数（现在刷新即丢，FileDrop 状态不持久化），减少"重头再来"成本

## 优化处方（验收标准）

1. **页数与汇总**：添加 ≥2 个文件后，每行显示"N 页 · X MB"，列表底部显示"共 N 个文件 · X 页 · X MB"。→ **验收：拖入 2 个不同页数的 PDF，行内页数与汇总行数字与实际一致（≤2s 内出现）**
2. **拖拽排序**：文件行支持 HTML5 拖拽换位，拖动时目标行高亮。→ **验收：5 个文件拖动第 1 个到第 3 位，序号即时重排且合并顺序跟随**
3. **结果确认**：合并完成后不立即下载，先展示"共 N 页 · X MB"+首页缩略图，点"下载"确认。→ **验收：合并后页面出现确认条，缩略图顺序与列表顺序一致**
4. **假手柄兑现或移除**：实现拖拽前先隐藏 GripVertical 图标，避免误导。→ **验收：FileDrop 文件行不再出现手柄图标（或拖拽功能已可用）**
5. **页级合并（中期）**：每个文件行展开可选页码范围（复用 PagePickerTool 解析"1-3,5"语法）。→ **验收：A 选 1-3、B 全选，合并产物页数 = 3+B 总页数**
6. **输出文件名**：执行按钮旁加文件名输入框（默认"合并结果"），saveBlob 使用该值。→ **验收：改名为"2026标书"后下载文件名为 2026标书.pdf**
7. **重复文件警告**：addFiles 检测同名同大小文件已存在时提示"该文件已在列表中"。→ **验收：重复拖入同一文件出现警告且默认不追加**
