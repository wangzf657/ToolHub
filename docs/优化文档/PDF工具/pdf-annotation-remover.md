## 扣分点明细

1. 【功能-疑似问题】表单字段（Widget 注释）被连带删除：整键删 Annots（:66）与逐个删非 /Link（:56-62）两条路径都不区分 Subtype /Widget——已填写表单的 PDF 走一遍"清除注释"，输入框/勾选值随注释一起从页面上消失（AcroForm 字典仍在，字段失显）；本工具 desc 只承诺删"批注、高亮、印章"，未披露会动表单
2. 【交互】"清除注释并下载"不下载：run() 仅生成 outBlob（:23-83 无 saveBlob），下载要再点出现的"重新下载"按钮（:103）——按钮文案承诺了没做的事，白付一次点击
3. 【可用性】盲删无清单：删除前不展示注释列表（哪页有什么类型、作者、内容），Acrobat 注释面板与 Sejda 都支持逐条勾选——用户"全删"决定是在零信息下做出的
4. 【功能】无类型统计与筛选：只有总数（:110-114），"只删高亮、保留印章"做不到；印章/图章类在政务场景常需保留
5. 【逻辑】无注释时仍产出副本：warn"没有可清除的注释"后继续 setProducer+save（:74-77），"重新下载"按钮照常出现——下载一个只换了 producer 章的原样文件
6. 【一致性】与 flatten-pdf 的"同时移除批注"行为分裂：flatten 整键删（含链接，FlattenPdf.vue:36）、本工具默认保链接——同一用户心智两个语义，且互不提示
7. 【边界】弹出型注释（Popup）父注释删除后子 Popup 残留引用的健壮性未处理（隐藏对象残留，文件略肥但无功能影响）

## 行业对标与差距

- **Adobe Acrobat**：左侧注释面板按页/类型/作者筛选，逐条勾选删除，可"删除所有高亮"。差距：**审查式删除代差**——对方是编辑器，本工具是粉碎机。
- **Sejda Remove Annotations**：删除前列出注释缩略与类型，支持类型白名单。差距：预览与类型粒度。
- 借鉴优先级：**注释清单预览（复用 pdfjs getAnnotations 可低成本实现）> 类型筛选（保链接之外加保图章）> Widget 保护（遇表单字段导流 flatten-pdf）> 按钮文案与行为对齐**。

## 可拓展性

- 短期（1 周）：主按钮改为"清除注释"，成功后再引导下载（或直接补上自动下载对齐文案）；无注释时禁用生成
- 中期（1 月）：删除前注释清单（页码+类型+作者+摘录）+ 类型复选（高亮/便签/图章/链接）；Widget 检测提示"该文档含表单字段，建议改用扁平化"
- 远期：与 flatten-pdf、redact-pdf 组成"对外发布三件套"（清批注→扁平→遮盖/脱敏）工作流入口

## 优化处方（验收标准）

1. **按钮对齐**：主按钮执行后自动触发下载（保留"重新下载"）。→ **验收：点击"清除注释并下载"一次即触发浏览器下载**
2. **Widget 保护**：检测页内含 /Widget 时提示"检测到表单字段，清除注释会移除其可交互外观，建议使用扁平化"。→ **验收：已填表单 PDF 载入后出现警示条，默认仍可继续**
3. **注释清单**：执行前展示"第 N 页：高亮 ×2、便签 ×1"统计列表。→ **验收：构造含 3 类注释的 PDF，统计与 Acrobat 注释面板计数一致**
4. **类型筛选**：新增"保留图章/印章"复选。→ **验收：勾选后图章保留、其余删除，stats 分别计数**
5. **空结果短路**：无注释时 toast 后不再生成下载按钮。→ **验收：纯文本 PDF 操作后页面无"重新下载"按钮**
