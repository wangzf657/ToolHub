## 结论与优先级

**需拓展 + 交互优化** · P2

判据：50 分；功能诚实但距离"可用归档工具"缺 XMP/OutputIntent 两大件（纯前端 pdf-lib 可写入 XMP，属可拓展而非天花板），且验证方法应内建而非外包给用户。

## 扣分点明细

1. 【功能-硬伤】转换不产生 PDF/A 核心要件：XMP 元数据流未写入、OutputIntent（ICC）未嵌入、字体未子集化——`pdfEngine.ts:997-1008` 实际只有 setTitle/setProducer/useObjectStreams:false；:1005 的 embedFont 结果被 `void font` 丢弃，代码即证据；notice（PdfToPdfa.vue:47）承认此为"近似转换"
2. 【可用性】验证闭环缺失：warn notice 让用户"如需严格过 ISO 校验请复核"（:47），但不给 veraPDF 在线校验入口、也不提供本站自查（至少可校验对象流已关/元数据已写），用户拿到产物仍不知道"行不行"
3. 【功能】无版本与颜色选项：PDF/A-1b/2b/3b 与 sRGB 假定（:44）均不可选——归档单位常指定具体版本（如 1b 用于政府归档），一刀切 2b 语义不达
4. 【交互】零进度反馈：无 stage 文案无进度条（`PdfToPdfa.vue:21-29` busy spinner 独转），是转换家族里反馈最弱的实现（对比 pdf-to-powerpoint 的双阶段进度）
5. 【灵魂】PDF/A 概念零教育：空态只有按钮，"为什么要归档格式、哪些场景需要"没有一段人话介绍——首次接触用户（占多数）不知道该不该用；notice 术语堆砌未降维
6. 【功能】栅格化兜底未实现：引擎注释写"栅格化可选"（`pdfEngine.ts:996`）但未实现未暴露——字体不合规文档的常见兜底路径（整页转图规避字体嵌入问题）断了
7. 【交互】输出名后缀"-PDF-A"（:23）在多轮归档后产生"报告-PDF-A-PDF-A.pdf"连锁命名，无覆盖提示
8. 【可用性】加密 PDF 处理静默依赖 ignoreEncryption（`pdfEngine.ts:999`）：加密件被"成功转换"但归档要求恰恰禁止加密，无"检测到加密已解除"警示

## 行业对标与差距

- **ocrmypdf（开源 CLI）**：`--output-type pdfa` 输出经 ghostscript 转换，XMP+OutputIntent 完整，可过 veraPDF。差距：两要件缺失是纯前端可补的（pdf-lib 支持 custom XMP metadata 流与 OutputIntent 字典写入）——这是"可拓展"而非"天花板"。
- **Adobe Acrobat 预检**：转换即附验证报告（合格/不合格逐条）。差距：验证闭环内建。
- **veraPDF**：ISO 官方认可的校验器，有在线版。差距：至少应外链引导。
- 借鉴优先级：**XMP+OutputIntent 写入 > 转换后自检清单（对象流/元数据/加密状态三项勾选）> 版本选择 > 栅格化兜底**。

## 可拓展性

- 短期（1 周）：完成 notice 改为"自检清单"（对象流已关闭✓ / 标题元数据已写✓ / XMP✗ 未实现 / 字体✗ 未嵌入）诚实呈现四要件状态；加大文件 stage 文案与进度
- 中期（1 月）：XMP 元数据流写入（pdf-lib set 原生扩展或手工构造流对象）；sRGB OutputIntent 嵌入（标准 ICC 约 60KB 可静态内置）；PDF/A 版本选择
- 远期：内嵌轻量结构校验（对象流/加密/元数据三查）；栅格化兜底管线（复用 cleanScannedPdf 的渲染路径）

## 优化处方（验收标准）

1. **XMP 元数据流**：pdf-lib 写入含 pdfaid:part="2" conformance="B" 的 XMP 流 → **验收：产物用文本编辑器打开可见 xmp 元数据段且 pdfaid 标识正确**
2. **转换后自检清单**：notice 输出四要件勾选表（已做/未做分明）→ **验收：任意 PDF 转换后清单四项状态与实际产物特征一一对应**
3. **PDF/A 版本选择**：提供 1b/2b 下拉，产物 XMP 与 Info 按所选版本标记 → **验收：选 1b 后 XMP 中 pdfaid:part=1**
4. **大文件进度**：>10MB 文件转换时显示"正在写入归档结构…"stage 文案 + 完成耗时统计 → **验收：50MB 文件处理期间不再是无文案 spinner**
5. **加密警示**：检测到输入加密时完成提示追加"源文件已加密，已解除加密后输出" → **验收：加密样例文件转换后该提示出现**
6. **空态科普**：未选文件时展示三行"PDF/A 是什么/什么场景需要/本工具能力边界" → **验收：新用户不拖文件即可在首屏读到能力边界**
