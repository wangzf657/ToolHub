> 分类：PDF工具｜模式：C（单列文件流；结果=F 型 zip 下载 + 命中分布列表）｜组件：`src/tools/pdf/components/DeepRedact.vue`（188 行）＋ `PdfToolBase.vue`｜引擎：pdfHits locateHits（pdfHits.ts:21-57，pdfjs 文本层正则定位）→ blackenRegions（pdfEngine.ts:899-917）→ 可选 compressPdf 栅格化销毁文字层（pdfEngine.ts:921-994）
> 对标标杆：Adobe Acrobat（Redact：搜索→标记→人工审查→应用的专业标准）＋ Stirling PDF（redact + sanitize）
> 家族共性（无缩略图/假拖拽手柄/自动下载）见 `merge-pdf.md`，本档案只记个性差异。

## 结论与优先级

**交互优化** · P0（合规级：报告打包泄漏 + 估算坐标无外扩 + 跨项漏检）

判据：62 分；产品方向（真脱敏）与默认值（栅格化默认开）都正确，但三处隐私工程细节让它护不住自己的核心承诺，脱敏工具的缺陷就是泄密事件。

## 扣分点明细

1. 【合规级】命中报告明文携带被脱敏内容并与成品同包：报告逐条列出"内容：「h.text」"（DeepRedact.vue:103），saveMany 把"已遮盖.pdf+命中报告.txt"打进同一个"深度脱敏结果.zip"（:105-111）——用户把 zip 转发给对方即把身份证号原文全部送出；报告应默认不打包、改为单独下载并在下载前二次确认
2. 【合规级】覆盖框按估算坐标无安全外扩：locateHits 按文本项内"字符占比"估 x/w、基线推 y（pdfHits.ts:4-5,:41-47），注释自认"复杂排版可能少量偏移"——脱敏场景偏 1 字符就是泄漏一个字符，无 ±2% 外扩选项、无烧录后放大目检
3. 【合规级】跨文本项敏感串静默漏检：正则只在单个文本项 item.str 内匹配（pdfHits.ts:35-40），pdfjs 常把一句话拆成多个 item（换行/字距/字体切换），"13xxxxxxxxx"跨项即整串漏检且无任何告警——漏报比误报危险，误报多涂无妨、漏报直接泄密
4. 【可用性】无人工审查环节：扫描只报总数与每页分布（:155-159），看不见框会落在哪、不能剔除误命中（正则误吞订单号就多涂无妨，但用户连"哪里被涂"都无从核对）；Acrobat 标准是标记后逐条确认再应用
5. 【功能】单模式单次执行：一次只跑一个正则，三类敏感信息要三遍"扫-执行-下载"；且第二遍仍作用于原文件，无法叠加
6. 【可用性】栅格化画质与进度不可控：复用 compressPdf preset medium（:92）整文档降为 JPEG（对照 compress-pdf.md 引擎问题：目标模式静默未达标的同族代码路径），正文清晰度受损程度不可选、栅格化阶段无进度反馈（:90-94 仅一条 toast）
7. 【交互】自定义正则无即时校验：非法正则静默置 null（:26-36），点扫描才报错；无常用 pattern 库（仅有 placeholder 一例，:137）

## 行业对标与差距

- **Adobe Acrobat Redact**：搜索结果逐条列出并可勾选、标记框可视化在页面预览上、应用前有醒目二次确认。差距：**可视化审查代差**——对方"看见再删"，本工具"闭眼删完给你清单"。
- **Stirling PDF redact/sanitize**：redact 支持框+文本命中、sanitize 单独清除元数据/JS/嵌入文件。差距：脱敏+元数据清洗的组合深度（本工具不处理 XMP/附件里的敏感信息）。
- 借鉴优先级：**报告与成品分包（当天可改）> 命中框可视化复核（复用 pdf-redact 的画布叠加）> 命中串合并相邻项后再匹配（修跨项漏检）> 外扩余量参数**。

## 可拓展性

- 短期（1 周）：报告改为单独下载且默认不进 zip；烧录前框坐标外扩 2%（选项可调 0~5%）；自定义正则即时校验红/绿提示
- 中期（1 月）：命中可视化复核（把 hits 叠加到 pdf-redact 的画布预览、逐条勾选）；多模式一次执行（邮箱+手机号+身份证合并正则组）；跨项文本拼接（按 transform 相邻关系合并 item 字符串后再匹配）
- 远期：脱敏+sanitize 打包成"发布前合规清洗"（文本脱敏+XMP/附件清理+清理报告），对齐 Stirling sanitize 套路

## 优化处方（验收标准）

1. **报告分包**：zip 内仅"已遮盖.pdf"，报告按钮单独下载。→ **验收：下载 zip 解压不含 txt；报告内容仍完整可另存**
2. **可视化复核**：扫描后进入复核视图，每条命中在页面预览上叠加红框、可勾选剔除。→ **验收：10 条命中全部可见红框，剔除 1 条后烧录该处无黑条**
3. **外扩防泄漏**：默认框四周外扩 2% 页宽/高。→ **验收：斜体/衬线排版 PDF 烧录后，放大 400% 目检被遮串两端各无残字**
4. **跨项匹配**：相邻文本项拼接后匹配。→ **验收：构造跨行手机号样例（13 开头行1、其余行2），扫描能命中并计数**
5. **多模式合并**：预设支持多选，一次执行。→ **验收：同时勾选邮箱+手机号，输出 zip 内成品覆盖两类且报告分组计数**
