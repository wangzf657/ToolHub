## SEO 家族关系与整合机会

本工具与 sitemap-generator/serp-snippet-preview/schema 六件套同属"SEO 工作台"愿景（DEV-5b）；独有优势是**唯一的"页面结构诊断"入口**——大纲结果可直接喂给面包屑/Article schema 的命名参考。低成本互链：结果区挂"为这些层级生成 Breadcrumb Schema"（取层级名＋URL 假设）跳 schema-breadcrumb-generator。

## 扣分点明细

1. 【交互】问题提示与大纲脱节：notice 写"第 3 个标题从 H2 跳级到 H4"（:69），大纲行无序号、不可点击定位（:107-118 无 index/无 issue 高亮），用户要自己数行
2. 【交互】手动解析：按钮触发（:27-45）而非 watch 自动，改一版 HTML 要反复点击；对照分类内 sitemap-generator/serp-preview 的实时 computed，交互代际落后半代
3. 【功能】无重复标题检测：同一文本多级重复（CMS 模板常见）不在 issues 里；无标题长度提示（SERP 里 H1 过长影响摘要）
4. 【功能】无大纲结构导出（仅复制纯文本缩进 :76-78）：无 Markdown TOC/JSON 输出，与 markdown-toc（开发分类）天然互补却无桥接
5. 【可用性-轻】HTML 源码贴入门槛无辅助：无"贴 URL"提示说明为何不支持（notice 只说本地解析 :93，未解释 CORS 边界），部分用户会疑惑"为什么不能直接查网址"
6. 【功能-轻】仅识别 h1–h6 标签（:35），`role="heading" aria-level` 的无障碍标题不识别——WAVE 场景下的盲区（低频，记录备查）

## 行业对标与差距

- **WAVE**（wave.webaim.org，云但检测可前端化）：标题结构＋层级跳跃＋空标题＋landmark 全套无障碍报告，问题与页面元素双向定位。差距：**issue→元素联动**（正是本工具扣分 1）。
- **SEOmeta in 1 click**（浏览器插件）：即开即看 heading outline＋字数。差距：**零操作直达**——本工具的"贴源码"形态决定它做不了即开即看，但 watch 自动解析可把操作压到零。
- 借鉴优先级：**issue↔大纲双向联动 > watch 自动解析 > 重复/过长检测 > Markdown TOC 导出**。

## 可拓展性

- 短期（1 周）：大纲行加序号＋issue 高亮（对应行黄/红描边）；watch 自动解析（200ms 防抖）；notice 补一句"不能查在线网址（浏览器跨域限制），请贴源码或另用浏览器插件"
- 中期（1 月）：重复标题/超长标题检测；导出 Markdown TOC；"生成面包屑 Schema"互链
- 远期：支持 role="heading"；并入 SEO 工作台作"结构诊断"面板

## 优化处方（验收标准）

1. **联动定位**：issues 每条挂大纲行索引，大纲对应行加色描边＋点击 notice 滚动定位。→ **验收：示例 HTML 解析后跳级行与空标题行分别黄/红描边，点击对应 notice 大纲自动滚动到该行**
2. **自动解析**：输入防抖 200ms 自动解析（保留手动按钮）。→ **验收：粘贴后无需点击大纲即出现；连续修改无明显卡顿**
3. **重复/超长检测**：同一标题文本出现 ≥2 次或 H1 文本 >60 有效长度（沿用 serp 口径）出 warn。→ **验收：示例中插入两个同名 h2 出现"重复标题"notice**
4. **CORS 说明**：notice 补"浏览器安全限制无法抓取在线页面"。→ **验收：文案常驻且解释了为什么需要贴源码**
5. **TOC 导出**：复制大纲旁加"导出 Markdown 目录"（按层级输出 `#`~`######`）。→ **验收：示例解析后导出文本以 `# Vue 3 组合式 API 指南` 开头且层级正确**
