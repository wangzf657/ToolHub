## 关键横向结论（写入各档案时直接引用）

1. **装饰层税**：所有工具面板 top 均为 250px（含 60px 站头+30 顶距+39 面包屑+60 H1+33 徽章+间距）——768 视口下 32.5% 首屏被不可折叠装饰占据（共性-根因 1）。
2. **高度钉死家族**：textarea 180（textDef）/170（text-diff）/220（word-counter）/320（json）；table-wrap 520（csv/sql/excel）；ResultBox height=minHeight 机制（共性-根因 2）。
3. **大屏浪费**：.container 1200px 上限 + 面板 842px，1920 宽用户两侧各留白 360px，结果区不随视口变大（M-02）。
4. **空态可达性分层**：操作按钮在顶部的工具（json-formatter/qr-code/stock-average）首屏可达性尚可；**按钮在流内底部的（TextTool 家族 607、ImageConvertTool 家族 450~520、resume-builder 1673）随内容增长把核心操作推出首屏**（共性-根因 4）。
5. **文件工具空态统一**：拖放区一律 165px 高 @top≈273，文件后选项+按钮下移（FileDrop 列表每文件 +40px），3 个文件时按钮约在 600~750 位置，逼近折叠线。
6. **移动端**：面板 340px 宽，堆叠布局可用但输出区普遍在 1~2 屏外（M-03/M-08）；断点碎片化致不同工具切换时机不一（共性-根因 5）。
7. **Cookie 横幅**：fixed bottom 首访遮挡视口底部内容（M-01 截图），与 toast 同区冲突。
