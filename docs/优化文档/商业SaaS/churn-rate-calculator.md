## 结论与优先级

**需拓展 + 交互优化** · P1

判据：相比 baremetrics 缺周期切换/年化/净流失（拓展差距）；空态"0.00% 完美留存"属误导性输出需守卫（交互优化）。

## 扣分点明细

1. 【可用性】空态谎报完美留存：start 留空时 `start > 0` 为 false，churn 直接按 0 计算（registry.ts:229），主结果"客户流失率 0.00%"+"客户留存率 100%"——未输入却得到一个看似真实的"零流失"结论；BIZ 家族共性（NaN 守卫不拦 0，CalcTool.vue:25-28）在本工具表现最误导，对照 break-even 定向守卫实践（registry.ts:108-110）
2. 【口径】周期声明缺位：字段只写"期内流失"，note（:240）与健康线却按"月流失率"解读——用户拿季度/年度数据填入即被按月口径误判健康度；月→年化换算 1−(1−m)^12 与年→月反解 1−(1−y)^(1/12) 完全没有（无切换器也无换算行）
3. 【口径】与 LTV 家族口径无法互认：ltv-calculator 的 1/churn 口径要求月流失率（registry.ts:170），本工具无周期声明、无透传——cac-calculator（36 月近似）、ltv（1/churn）、本工具（无周期）三套口径同站分裂（cac-calculator.md 扣分点 2 已记），用户在三个工具得到三个互相矛盾的结论
4. 【可用性】边界无校验：lost 填负数→留存率 120%；lost > start→流失率 200% 照算渲染，垃圾进出无拦截（:229-233）
5. 【功能】无净流失口径：流失率未扣除回流客户（reactivation），baremetrics/ProfitWell 报 gross 与 net churn 双值；收入流失率也无扩张抵消的净收入留存视角（mrr-calculator 有 NRR，本工具未链接）
6. 【功能】无判定着色与阈值行：流失率算出后无"健康/关注/危险"三态结论——同站 burn-rate（registry.ts:278）、mrr-calculator 流失率磁贴着色（MrrCalculator.vue:131）均有实践
7. 【家族共性】无输入记忆、结果不可单值复制（CalcTool.vue:10、:55-66，见 loan-calculator.md）

## 行业对标与差距

- **baremetrics**：customer churn / MRR churn / net revenue retention 同屏、按月历史序列、健康着色。差距：**周期与序列代差**——对方报"每月的流失率走势"，本工具报"某一段的孤立比值"。
- **ProfitWell**：logo churn（客户数）与 dollar churn（收入）分列并解释背离原因。差距：双值有了（:230-237），缺"两者为何背离"的解释文案。
- 借鉴优先级：周期切换+年化换算 > 空态守卫 > 三态判定行 > ltv 透传互链 > 净流失口径。

## 可拓展性

- 短期（1 周）：start/lost 空态引导行；lost 范围校验（0 ≤ lost ≤ start）；note 补"输入期为月/请在月度数据上使用"
- 中期（1 月）：周期选择器（月/季/年）+ 年化换算行"折算年流失率 = 1−(1−月流失)^12"；三态判定着色；与 ltv-calculator 透传月流失率
- 远期：按月历史序列录入（多期对比）；与 mrr/cohort/ltv/cac 组成"SaaS 指标面板"（baremetrics 式整合）

## 优化处方（验收标准）

1. **空态守卫**：start 或 lost 为空时返回"请填写期初客户数与流失客户数"引导行，不渲染任何百分比值。→ **验收：打开页面主结果为引导行；填入后 300ms 内更新**
2. **周期切换与年化**：新增"统计周期"选择（月/季/年），结果区追加"折算年流失率"行，月口径按 1−(1−m)^12、季口径按 1−(1−q)^4 换算并显示公式。→ **验收：月流失 2% 时年流失行显示 ≈21.5%；年流失 30% 切回月口径显示 ≈2.91%**
3. **三态判定行**：按折算月流失率 <2% "健康"、2~5% "关注"、>5% "危险"着色输出。→ **验收：月流失 1.5% 显示"健康"，8% 显示"危险"**
4. **边界校验**：lost<0 或 lost>start 时提示"流失数应在 0 与期初客户数之间"。→ **验收：lost=−5 与 lost=2000（期初 1000）均被拦截且给出提示行**
5. **口径互认**：结果区底部加"用此流失率算 LTV → ltv-calculator"链接并透传月流失率。→ **验收：月流失 3% 时点击后 LTV 页 churn 字段自动填 3**
