## 结论与优先级

**交互优化 + 需拓展** · P1

判据：暗色主题预览不可读属输出区可读性缺陷（交互优化）；社交图标/logo/模板库与 HubSpot/WiseStamp 差距属拓展（可与交互优化组合）。

## 扣分点明细

1. 【可用性】暗色主题预览不可读（EmailSignatureGenerator.vue:80、:97 + tokens.css:4-27）：签名 HTML 全部内联深色文字（姓名 #111827、正文 #374151、标签 #6b7280，:25-37）且表格未设背景色，preview-box 亦无白底——深色为站点默认主题（tokens.css:4 注释"深色主题（默认）"），首访用户看到的是深灰字压深蓝底，核心输出区（预览）近乎隐形
2. 【功能】社交图标行缺席（:26-32 rows 仅电话/邮箱/网址）：HubSpot/WiseStamp 的 LinkedIn/X/WhatsApp/网站图标行是商务签名标配，且图标行是"风格个性化"的主要载体——本工具连外链文字行外的任何社交维度都没有
3. 【功能】模板多样性不足：3 个"风格"实为同一模板的 3 种分隔变体（侧色条=嵌套表格左边框、分隔线、极简留白，:20-24），字体/排版/结构完全相同；WiseStamp 有数十套行业模板（法务/地产/电商）
4. 【交互】无持久化与导出：7 字段+风格全内存态（:8-15）刷新即丢；无"下载签名 .html"或"复制 HTML 源码"出口——手动改签名的用户没有抓手
5. 【交互】降级链两级而非三级：ClipboardItem 失败后直接 writeText 纯文本（:49-52），无 execCommand('copy') 中间层——非安全上下文（http）或 clipboard API 整体不可用时两级全败只弹"复制失败"，与设计文档声明的降级路径验证结论：富文本优先+纯文本降级属实，execCommand 层缺失
6. 【口径】纯文本降级残留 HTML 实体（:47）：row() 用 `&nbsp;` 排版标签与值间距（:27），剥标签正则 `/<[^>]+>/g` 不处理实体——纯文本产物含字面 "&nbsp;" 字符（如"电话&nbsp;&nbsp;138-0000-0000"），粘贴到纯文本编辑器可见
7. 【功能】字段固定无扩展：rows 数组硬编码三项（:28-32），不能添加地址/部门/slogan 行，也不能调整行序
8. 【美观】640px 断点自成体系（:99），与全站 900/760/560 断点碎片化并存（共性-根因5），跨工具切换布局时机不一

## 行业对标与差距

- **HubSpot Email Signature Generator**：10+ 模板、社交图标拖入、logo 上传、每字段独立开关、Gmail/Outlook 分客户端安装指引。差距：**模板与图标代差**——对方是"签名设计器"，本工具是"一张名片的三种边框"。
- **WiseStamp**：行业模板库、多签名管理、团队统一签名（云）。差距：模板库与多签名；团队能力属云端天花板，模板/图标纯前端可实现。
- 借鉴优先级：**暗色预览白底修复 > 社交图标行 > 下载 .html > 模板预设（3~5 套）> execCommand 中间降级层**。

## 可拓展性

- 短期（1 周）：preview-box 固定白底或签名 HTML 补背景色；`&nbsp;` 实体替换为空格字符；localStorage 持久化；下载 .html 按钮
- 中期（1 月）：社交图标行（2~6 个可开关，SVG 内联 base64 保证邮件客户端兼容）；3~5 套行业模板预设；自定义附加行（+添加行）；execCommand 降级层
- 远期：多签名管理（命名保存/切换）；vCard 联动（站内 vcard-generator 素材复用）；签名"测试发送到我的邮箱"指引页

## 优化处方（验收标准）

1. **暗色预览修复**：preview-box 增加 `background:#ffffff`（或签名 HTML 根表格加 `background:#ffffff`），并加"预览底色模拟：白/深"切换。→ **验收：默认深色主题下打开页面，姓名与正文清晰可读；切深底模拟后给出"邮件客户端多为白底"提示**
2. **社交图标行**：新增"社交链接"区（LinkedIn/X/微信/自定义，可开关排序），图标用内联 SVG（邮件兼容）追加在联系行下方。→ **验收：开启 LinkedIn 并填链接后，预览出现图标行，复制的富文本粘贴进邮件可见图标**
3. **下载与源码**：预览下方加"下载 .html"与"复制 HTML 源码"按钮。→ **验收：下载文件在浏览器打开与预览一致；复制源码剪贴板为完整 `<table>` HTML**
4. **持久化**：7 字段+风格+社交链接入 localStorage（key 前缀 toolhub）。→ **验收：修改姓名后刷新，表单与预览恢复**
5. **纯文本降级净化**：降级产物先做实体解码（&nbsp;/&amp;/&lt;）再剥标签。→ **验收：在不支持 ClipboardItem 的环境复制，纯文本中无 "&nbsp;" 字样，电话行形如"电话  138-0000-0000"**
