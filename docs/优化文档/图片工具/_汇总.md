## 五、疑似功能缺陷清单（只列编号供用户决策，均引自档案扣分点原文）

**文案失实/承诺未兑现**

1. colorize-photo：needModel 误标 true（registry.ts:65，组件无任何模型逻辑，向用户承诺不存在的 28MB 下载）
2. photo-editor：desc 列"AI 工具"，PhotoStudio.vue 全文无任何 AI 实现
3. png-to-jpg：desc"可同时选 WebP"，实际 target 单一 prop 只出一个格式（registry.ts:11）
4. tiff-to-png：desc"转 PNG/JPG"，target 钉死 image/png，JPG 路径不存在（registry.ts:34）
5. jpg-to-png：desc"支持透明通道输出"，JPG 源不含 alpha，承诺空洞（registry.ts:12）
6. heic-to-png：desc"无损无损透明支持"叠词病句，且 HEIC 照片源基本无透明（registry.ts:24）
7. add-watermark：desc"斜排角度全部可调"，实际角度钉死 -30°（registry.ts:14）
8. avif-to-jpg：desc"兼容所有设备与软件"仅对输出端成立；webp 系输入端报错误导同病（imageEngine.ts:13 把不支持说成"文件无效"）
9. pixelate-image：hint/desc 建议遮挡人脸车牌，实际只支持全图马赛克，用途与能力错位

**交互/触摸失效**

10. blur-region：触摸屏完全不可用，框选仅绑 mouse 四事件（BlurRegion.vue:224-227）
11. crop-image：选区交互仅 mouse 事件（CropImage.vue:201），移动端失效

**静默降级/数据丢失**

12. psd-to-jpg：图层 >200 静默截断 slice(0,200)，信息丢失无告知（:74）
13. compress-image-to-size：accept 含 image/* 可拖入 GIF，但只解码首帧——动图压完变静图无警告
14. jpg-to-webp / png-to-webp：toBlob MIME 静默回退 PNG 时仍按 .webp 命名（imageEngine.ts:103-115）
15. overlay-images：叠加图解码失败空 catch 静默（OverlayImages.vue:36-38），损坏图无任何反馈
16. svg-to-png：宽度无上限保护，canvas 超限静默失败，无错误提示（:23）
17. image-border：宽度拖到 0 仍可点下载，output null 时基座回退下载重编码原图（ImageToolBase.vue:103）
18. batch-file-rename：重名静默覆盖，zip 内悄悄少文件（见第四节 #8）
19. favicon-generator：webmanifest name/short_name 输出空字符串且 UI 无提示（:115-116）
20. exif-viewer：GPS 输出废值（原始值直出）
