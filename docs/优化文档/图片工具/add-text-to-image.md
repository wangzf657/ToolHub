## 扣分点明细

1. 【实用-硬伤级重复】注册表两条 slug 指向同一组件：`add-watermark`（registry.ts:14）与 `add-text-to-image`（registry.ts:45）的参数、渲染、交互、下载完全一致——搜索"文字""水印"同时命中两工具，认知与维护双成本
2. 【交互-个性】下载文件名后缀钉死 `-watermark`（AddWatermark.vue:53）："添加文字"场景产出 `照片-watermark.png`，命名错位暴露"这是水印工具的别名"
3. 【功能】无字体选择：`600 Npx sans-serif` 钉死（imageEngine.ts:384）——Canva 有数百字体+字间距+对齐，本工具连字体切换都没有
4. 【功能】单文字块：一次只能加一条文字（AddWatermark.vue:9-14），"标题+副标题""多处标注"场景不可用；无弯曲文字（Canva Curve 即拿即用）
5. 【交互】无自由定位：仅九宫格跳变+固定 pad（imageEngine.ts:388），不能拖到任意位置、不能像素微调
6. 【灵魂】无文字特效兜底：无描边/阴影/底衬色块，白字叠浅图不可辨（同 add-watermark 根因，imageEngine.ts:385-400）
7. 【可用性-共性】无按住看原图；预览无高度上限（ImageToolBase.vue:61-64）；导出锁死 PNG（ImageToolBase.vue:34）

## 行业对标与差距

- **Canva 文字工具**：字体库+弯曲文字+特效（描边/阴影/背景条）+画布拖拽+多图层+文字模板。差距：**从"文字叠图"到"文字排版"的代差**。
- **稿定设计**：中文标题样式模板一键套用。差距：模板生态。
- 借鉴优先级：先收口重复入口，再谈能力补齐——单入口+字体 > 拖拽定位 > 描边/底衬 > 多文字层 > 弯曲文字。

## 可拓展性

- 短期（1 周）：入口收口——本 slug 页面顶部加引导卡指向 add-watermark（或差异化：改名"文字标注"并下放多文本层）；下载后缀按 slug 区分
- 中期（1 月）：字体下拉+对齐选项；预览画布 pointer 拖拽定位；描边/底衬特效
- 远期：作为 PhotoStudio 文字面板的独立轻量入口，支持弯曲文字（canvas 逐字沿弧旋转排列）

## 优化处方（验收标准）

1. **收口重复**：两 slug 合并或页面互导。→ **验收：站内搜索"加水印""添加文字"只命中一个主工具，另一入口页首屏显示引导卡（点击带参数跳转）**
2. **下载命名跟随场景**：suffix 按 slug 动态。→ **验收：同组件两 slug 导出分别为 `*-watermark.png` 与 `*-text.png`**
3. **字体下拉**：≥6 种系统字族（衬线/黑体/楷体/等宽）。→ **验收：切换字体后预览 100ms 内更新且导出一致**
4. **拖拽定位**：预览画布 pointerdown 拖动文字块。→ **验收：松手后导出图与预览位置像素级一致**
5. **多文本层**："+ 添加文字"追加文本块（各自字号/颜色/位置）。→ **验收：2 个文本块分别定位改色互不影响**
