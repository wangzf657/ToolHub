## 结论与优先级

**交互优化 + 需拓展** · P1

判据：核心闭环完整实时，但"水印"能力面与 imgonline 差一代（无真平铺/无图片水印/无字体），60 分触发交互优化。

整改优先序：真平铺（P1）→ 描边兜底（P1）→ 图片水印入口与视频版统一（P1）→ 字体（P2）→ 批量（P2）。

## 扣分点明细

1. 【功能-个性】"斜排（-30° 平铺样式）"名不副实：rotate 仅把单条文字旋转 -30° 居中绘制（imageEngine.ts:391-395），并非平铺——imgonline 的整版重复水印才是防盗图主流形态；且 rotate 模式无视九宫位置选择永远居中
2. 【功能-个性】注册表描述与实现不符：desc 承诺"斜排角度全部可调"（registry.ts:14），实际角度钉死 -30°（AddWatermark.vue:79 复选框 + imageEngine.ts:393 -PI/6 硬编码），无角度滑杆
3. 【功能】无图片水印：站内 video-watermark（FfmpegWatermark.vue:59-72）支持 logo 图+边距，图片版只能文字——文字/图片水印割裂在两个分类，交互范式还不一致（视频版 select 下拉+margin 滑杆 vs 图片版九宫格+pad 固定等于字号，imageEngine.ts:388）
4. 【功能】无描边/阴影：白字叠浅色天空、深字叠暗部均直接消失（imageEngine.ts:385-400 无 strokeText 兜底）——水印在任意底色上可辨是竞品及格线
5. 【功能】无字体选择：引擎钉死 `600 Npx sans-serif`（imageEngine.ts:384）；文字输入为单行 input（:56），无多行落款场景
6. 【交互】位置微调粒度粗：仅九宫格跳变，边距固定=字号（imageEngine.ts:388），无 margin 数值、无画布拖拽
7. 【灵魂】无预设模板："@我的名字""©2026"高频水印无一键填充；无批量（多图统一水印是水印工具主场景，站内 batch-image-process 也不含水印）
8. 【可用性-共性】无按住看原图对比；预览无高度上限（ImageToolBase.vue:61-64）；导出锁死 PNG 无质量选择（ImageToolBase.vue:34）

## 行业对标与差距

- **imgonline**：平铺行列密度/间距/角度全可调、文字+图片双水印、批量队列。差距：**平铺能力代差**——本工具"斜排"只是单条旋转。
- **Canva / 稿定设计**：字体库+字间距+描边阴影+画布拖拽定位+文字模板。差距：排版能力不在一个量级。
- 借鉴优先级：真平铺 > 描边兜底 > 图片水印入口（或与 overlay-images 收口）> 字体 > 批量。

## 可拓展性

- 短期（1 周）：平铺密度/间距参数（旋转模式下重复绘制 N 条）；描边开关+自动反色描边；"斜排"文案诚实化或补角度滑杆
- 中期（1 月）：图片水印入口（复用 overlay 引擎），与 video-watermark 统一"位置/边距/大小"控件命名；字体下拉（系统字族枚举）；水印文案预设 chips
- 远期：与 add-text-to-image、overlay-images 收口为"图层叠加"单工具三模式（文字/图片/平铺），补批量队列

## 优化处方（验收标准）

1. **真平铺**：斜排模式下按密度滑杆（1~20 条）沿对角重复绘制，且整体随九宫位置偏移。→ **验收：密度 8 时画布四角均可见至少一条水印，切换九宫位后整组水印偏移生效**
2. **角度可调**：角度滑杆 -90°~90°（默认 -30°），兑现注册表描述。→ **验收：拖到 -45° 后预览 100ms 内更新且导出一致**
3. **描边兜底**：新增"描边"开关（1/2px，色自动取文字反色）。→ **验收：白字白底图开启描边后文字轮廓清晰可辨**
4. **统一水印范式**：图片水印复用九宫格+缩放+透明度+边距，控件命名与 video-watermark 一致。→ **验收：图片/视频两工具位置九选项一一对应且默认值一致**
5. **批量水印**：FileDrop multiple + 统一参数导出 zip。→ **验收：3 张图一键产出 3 个带水印文件并打包**
