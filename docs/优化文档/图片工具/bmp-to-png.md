## 结论与优先级

**交互优化** · P1（家族级整改；本工具个性补丁最少）

判据：59 分落在"能用但结果不可见"的家族基线；个性问题仅"体积收益不可见"一条，随家族结果列表处方自然解决。

整改优先序：体积收益展示（P1，随家族）→ 启用 resize → 32bpp 预警 → 格式科普（P2）。

## 扣分点明细

1. 【可用性-硬伤（家族级）】自动 zip 下载、无结果预览（`ImageConvertTool.vue:55`；M-12）——转换成败与画质只能下载后验证
2. 【功能-个性】**体积收益零展示**：BMP→PNG 的核心价值就是体积骤减，引擎拿到输入 File 与输出 Blob（:44-51）却不显示"X MB → Y KB（-87%）"——本家族里本工具最需要这块
3. 【功能-个性】选项区近乎空置：registry.ts:31 未传 resize 也未传 quality（:75-88 两个 opt 全不渲染），批量场景下想顺手缩个尺寸都做不到
4. 【灵魂】无 BMP 格式科普（为什么聊天软件发不了 BMP、PNG 为何通用），空态只有拖放提示
5. 【家族共性】文件列表无缩略图、进度条 6px 无百分比、无逐张重转——见 `png-to-jpg.md` 扣分点 5/6/7
6. 【边界】BMP 若带 alpha 通道（32bpp 非标准变体），浏览器 `<img>` 解码行为不一，透明区可能发黑且无预警——低频但存在，失败/异常时无格式级诊断

## 行业对标与差距

- **CloudConvert**：BMP→PNG/JPG/WEBP/PDF 多目标+逐文件设置+结果列表。差距：单目标、无结果列表。
- **Squoosh**：转换前后对比+体积实时可见。差距：体积收益不可见是本工具最痛的单点。
- **ezgif**：BMP 转换器支持转 JPG/GIF/WebP 多目标+结果页逐张预览。差距：单目标+零预览。
- 借鉴优先级：**前后体积对比 > 结果列表（家族级）> 启用 resize > 格式科普文案**。

## 可拓展性

- 短期（1 周）：随家族结果列表上线（缩略图+前后体积列）；desc 补"体积通常缩小数倍"
- 中期（1 月）：registry 启用 withResize；选项区空置时给格式科普卡占位
- 远期：并入"图片格式转换工作台"，与 bmp-to-jpg 等形成目标矩阵

## 优化处方（验收标准）

1. **体积收益展示**：家族结果列表落成后，本工具每行显示「原 X KB → Y KB（-N%）」。→ **验收：转换 1 张 5MB BMP 后结果行出现缩水量与百分比**
2. **启用 resize**：registry.ts:31 补 `resize: true`，转换时可顺手限宽。→ **验收：选项区出现宽/高输入框，填 800 后输出 PNG 宽 800**
3. **家族处方 1~7** 同步落地。→ **验收：同 `png-to-jpg.md` 处方 1~6**
4. **alpha 预警**：检测到 32bpp BMP 时提示"该 BMP 含透明通道，若透明区显示异常请反馈"。→ **验收：拖入 32bpp BMP 出现提示行，正常 BMP 不出现**
