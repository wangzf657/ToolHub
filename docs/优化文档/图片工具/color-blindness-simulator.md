## 结论与优先级

**交互优化 + 需拓展** · P1

判据：型谱覆盖（3/8）与强度维度缺失是相对 Coblis 的代差；对比方式（160px 小图）不足以支撑"检查可达性"的定位。

## 扣分点明细

1. 【功能】仅红色盲/绿色盲/蓝黄色盲三型（:12-16），缺色弱三型（protanomaly/deuteranomaly/tritanomaly）与全色盲——最常见的色弱人群恰恰是无障碍检查主要对象
2. 【功能-个性】矩阵锁死无严重度插值（:19-23），同类支持 0~100% 强度渐变展示"轻度→全盲"谱系
3. 【可用性-个性】对比缩略图 max-height 160px（makeThumb :25-32、CSS :103），并排小图难辨模拟前后差异；无左右滑块揭开创、无按住看原图（家族共性缺失项）
4. 【功能】desc 与文案都提"检查 UI 配色与数据可视化"（registry desc、:83），却不支持直接输入 HEX 色值列表模拟——设计师最高频路径（测一组配色）断裂
5. 【性能】12MP 原尺寸同步逐像素循环（:51-58），无 worker、无降采样档位，模式切换无进度反馈
6. 【灵魂】无样例图一键填充（色盲模拟自带演示价值，空手拖图门槛高）；无"红绿柱状图哪些组合易混"类检查要点
7. 【共性】导出走 ImageToolBase 锁死 PNG + 后缀 -cb（家族共性"导出锁死 PNG"）
8. 【可用性】模式切换后主区模拟图直接替换原图，无任何原/模并存的"回看原图"手段（setOutput 覆盖，:61）

## 行业对标与差距

- **Coblis**（color-blindness.com/coblis）：8 型一键切换（正常+3 全盲+3 色弱+单色症）、上传即看。差距：**型谱覆盖代差**。
- **DaltonLens 模拟器**：Viénot/Brettel/Machado 多算法与强度可调，方法学透明。差距：单一固定矩阵无强度档。
- 借鉴优先级：补 5 型（色弱+全色盲）> 强度滑杆 > 滑块对比揭开创 > 色值列表模式 > 大图并排 > 样例图。

## 可拓展性

- 短期（1 周）：补 3 色 weak 型（anomaly 用矩阵与恒等阵 0.6 线性插值近似）+ 全色盲（灰度化）；样例图按钮
- 中期（1 月）：强度滑杆 0~100%；主预览滑块对比组件；色值列表模式（粘贴 HEX 输出前后色卡）
- 远期：Brettel/Viénot 多算法可选并标注方法学；与 color-palette/color-converter 组成"配色无障碍工作台"

## 优化处方（验收标准）

1. **补全 8 型**：新增 protanomaly/deuteranomaly/tritanomaly/achromatopsia/achromatomaly 五个 chip。→ **验收：8 型全部可切换，色弱型与对应全盲型结果肉眼可辨**
2. **强度滑杆**：0~100% 在恒等阵与目标矩阵间线性插值。→ **验收：0% 输出与原图逐像素一致、100% 与现矩阵结果一致**
3. **滑块对比**：主预览改左右滑块揭开创（原图|模拟同构图）。→ **验收：拖动手柄无缝切换且两侧像素对齐无错位**
4. **色值模式**：文本框粘贴 HEX/RGB 列表（逗号/换行分隔），输出前后对比色卡。→ **验收：输入 ['#d62728','#1f77b4','#2ca02c'] 输出 3 组前后对比块及模拟后 HEX**
5. **性能档位**：>4MP 图片自动以预览尺寸（上限 1600px 边）模拟，下载时对原图全量重算。→ **验收：12MP 图切模式 <100ms 响应，下载 PNG 仍为原尺寸**
