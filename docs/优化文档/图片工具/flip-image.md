## 扣分点明细

1. 【实用-个性】导出锁死 PNG（ImageToolBase.vue:34 默认 mime，组件未覆盖）：照片镜像后体积膨胀数倍，JPG 用户被迫二次转换
2. 【功能】与旋转不可组合：180° 旋转（rotate-image）与 H+V 翻转是不同操作却分居两页，"自拍倒置+镜像"类复合修正要跨两个工具、两次下载；ezgif 四向翻转+旋转同页
3. 【可用性-共性】竖图预览无高度上限（ImageToolBase.vue:61-64），下载按钮（:143-151）易沉到首屏外
4. 【灵魂】无"按住看原图"：文字镜像类场景需要精确核对方向，只能靠记忆
5. 【功能】无批量：batch-image-process 无 flip op（BatchImageProcess.vue），十张图统一镜像只能逐张
6. 【灵魂】无粘贴即处理（FileDrop.vue 无 paste 监听）、无 H/V 键快捷（两 chip 加 keydown 即可实现）
7. 【功能】canvas 重编码丢弃 EXIF 方向元数据（与 rotate-image 同源）：手机竖拍图镜像后方向信息丢失且无提示

## 行业对标与差距

- **ezgif flip**：水平/垂直/转置/反对角四向 + 直角旋转同页组合。差距：四向中"转置/反对角"缺失，组合成本高。
- **Photopea**：Flip 与其他变换可叠加、快捷键化。差距：组合流水线。
- 借鉴优先级：导出格式 > 与旋转合并同页 > 快捷键 > 按住看原图。

## 可拓展性

- 短期（1 周）：下载行加 JPG/WebP 选项+质量滑杆；H/V 键盘快捷键
- 中期（1 月）：与 rotate-image 合并"方向修正"页（组件共享、slug 保留双落地页）；补"转置/反对角"两向
- 远期：方向修正并入批量工具，形成"单张精修+批量"闭环

## 优化处方（验收标准）

1. **导出格式**：下载行加格式 chips（仅 JPG/WebP 显示质量滑杆）。→ **验收：2MB JPG 水平翻转后导 JPG，输出 ≤ 原体积 1.2 倍**
2. **按住看原图**：预览左上角对比按钮（pointerdown 换源图，pointerup 恢复）。→ **验收：按住期间显示未翻转原图，松开恢复**
3. **快捷键**：H/V 键触发两 chip，输入框聚焦时不响应。→ **验收：按 H 出水平镜像效果且无焦点冲突**
4. **首屏可达**：预览 canvas max-height:min(60vh,640px)。→ **验收：1170×2532 竖图载入后下载按钮在 1366×768 首屏可见**
5. **方向修正合并**：rotate/flip 组件共享后页面提供“旋转｜镜像”两个分组。→ **验收：同页完成 90° 旋转+水平镜像一次下载**
6. **粘贴即处理**：FileDrop 支持 Ctrl+V 直接载入剪贴板图片。→ **验收：截图后在页面按 Ctrl+V，预览出现且可立即点翻转**
