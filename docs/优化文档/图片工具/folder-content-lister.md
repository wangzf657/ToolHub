# 文件夹内容清单（folder-content-lister）

> **分类错位警示：本工具同样与图像处理零关联（只读文件名与元信息，不解析任何图片），挂在图片分类（registry.ts:79 `category: 'image'`）——本质是文件管理/盘点工具；建议归入实用工具/文件管理，与 batch-file-rename 组成"文件整理"分组，入口可跨分类双挂载。**
> 分类：图片工具（错位）｜模式：C 变体（webkitdirectory 选择 + 统计清单流，非 ImageToolBase）｜组件：`src/tools/image/components/FolderContentLister.vue`（266 行）｜导出：CSV（手写 BOM）+ rowsToXlsx（officeEngine）
> 对标标杆：Everything（文件检索标杆）＋ TreeSize/WizTree（目录空间盘点标杆）

## 结论与优先级

**交互优化 + 需拓展** · P1（附分类归位建议）

判据：作为零安装清单工具底盘扎实（统计直答+BOM 导出），但搜索/排序/扩展名统计的缺席让它停留在"能列出来"，离"盘点利器"差一层。

## 扣分点明细

1. 【可用性-个性】字段不一致：平铺视图仅路径/类型/大小三列（:143-147），树视图多出修改时间（:157），CSV/XLSX 又两者都有（:83,96）——同一数据三种剪裁，平铺版恰好缺了交接盘点最常用的 mtime
2. 【功能】无搜索/过滤与排序：千文件目录里找"所有 .pdf"只能肉眼滚；列表不可按大小/名称/时间排序（tree 按目录名+文件名排序写死 :74-76）——Everything 类工具的基本功缺席
3. 【功能】无扩展名统计："这文件夹里 jpg 占多少"是照片盘点第一问，有 ext 字段（:42）却无统计条/占比图
4. 【功能】无目录大小聚合：树视图目录行只显示文件数（:152），不含子级合计大小——空间盘点需要"哪个子目录最大"，Top5 只答单文件（:60）不答目录
5. 【灵魂-边界】空文件夹不可见未披露：webkitdirectory 的 FileList 天然不含空目录，清单"完整性"有结构性缺口，notice（:174-177）只字未提（对照 BatchFileRename.vue:165 同边界有披露）
6. 【可用性】列表 400px 钉高（:212-217）：大目录在固定小窗内滚，无弹性高度无全屏（家族共性-根因 2 自建版）
7. 【交互】无"复制清单"一键：临时贴给同事的场景必须走导出文件；无 Markdown/JSON 格式
8. 【共性】文件夹仅点击选择（:119-120），无拖拽目录入口；无 File System Access API 目录句柄记忆

## 行业对标与差距

- **Everything**：即时搜索/正则/按列排序/导出。差距：过滤与排序是清单工具的地板配置，本工具全无。
- **TreeSize/WizTree**：目录树按大小排序、彩色占比条、磁盘全景。差距：目录大小聚合与可视化占比——纯前端在 FileList 数据上完全可算（累加 dir 前缀即可）。
- 借鉴优先级：**扩展名统计 > 目录大小聚合 > 搜索+排序 > 平铺补 mtime > 复制清单**。

## 可拓展性

- 短期（1 周）：平铺视图补 mtime 列；"复制为 Markdown/TSV"按钮；notice 补空文件夹边界披露
- 中期（1 月）：扩展名统计条（前 8 类占比）；目录大小聚合（树视图目录行显示合计）；搜索框+点列头排序
- 远期：File System Access API 目录句柄记忆+增量重扫；分类归位后与 batch-file-rename 组"文件整理"工具组；万级文件虚拟滚动

## 优化处方（验收标准）

1. **字段对齐**：平铺视图补修改时间列，三处字段完全一致。→ **验收：同一目录下平铺/树/CSV 三视图列名与数值一致**
2. **扩展名统计**：统计区下方显示前 8 类扩展名占比条形（类目+个数+合计大小）。→ **验收：混合目录出条形图，jpg 类合计大小与手工筛选一致**
3. **目录大小聚合**：树视图目录行显示子级合计大小并可点击排序。→ **验收：多级目录的根行合计 = 总大小卡数值**
4. **搜索+排序**：清单头加搜索框（路径/文件名包含匹配）+大小/名称/时间三档排序。→ **验收：搜索 ".pdf" 仅剩 pdf 行；按大小排序首行与 Top5 第一名一致**
5. **复制清单**：「复制为 Markdown」按钮生成表格文本。→ **验收：剪贴板粘贴进任意编辑器呈现规整表格，行数 = rows.length**
