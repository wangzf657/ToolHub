## 扣分点明细

1. 【功能】**WOFF2 双向缺失**：detect 识别 wOF2 后直接拒绝（`FontConverter.vue:48-50`），sfnt→WOFF2 也无法输出——CloudConvert/Convertio 均支持 woff2（含 brotli），当前 web 字体交付事实标准缺失；设计文档已登记为暂缓决策（V1.1 设计文档.md:71），此处计为"已知边界"而非新缺陷
2. 【功能】无批量：`:multiple="false"`（:103），多字重字体族（Light/Regular/Bold）要逐个拖放转换——字体族恰是批量需求最集中的场景
3. 【可用性】name 记录列表钉 240px（:189-194）：CJK 字体 name 表记录几十条时小窗内滚；表标签多时 tags 区无折叠
4. 【交互】转换按钮与下载按钮分离两步（:111-115）：转换成功后下载按钮才出现，新手可能不知道要再点一次"下载"（toast 有提示但按钮无高亮变化）
5. 【灵魂】无字形/字样预览：转换后不能输入一段文字看渲染效果（fontinfo 类站标配"试字"），用户验证转换产物是否可用的闭环缺最后一环
6. 【功能-边界】TTC 仅取首个字体（:144 notice 有交代），但无法选择取第 N 个字体——大 TTC（如系统字体集合）价值受限
7. 【性能】大 CJK 字体逐表 zlib 主线程执行无进度提示，busy spinner 之外无阶段反馈

## 行业对标与差距

- **CloudConvert**：TTF/OTF/WOFF/WOFF2 全矩阵互转+批量队列+结果列表。差距：WOFF2 整列+批量。
- **Convertio**：同上矩阵+每格式说明卡。差距：本工具机制说明反而更透明，格式面是唯一代差。
- **FontDrop!（fontdrop.info）**：拖入字体看全部表/字形网格/试字面板——本工具的信息面板已是同思路雏形，差字形网格与试字。
- 借鉴优先级：**WOFF2（引入 brotli wasm 解码+编码）> 批量 > 试字预览 > name 列表弹性高度**。

## 可拓展性

- 短期（1 周）：name 列表改弹性高度（上限 50vh）；下载按钮转换成功后 primary 高亮+自动聚焦
- 中期（1 月）：多文件批量（字体族一次转完，复用家族结果列表）；试字预览（input 输入文字用 FontFace 渲染）
- 远期：WOFF2 支持评估（wasm brotli，注意懒加载纪律与体积预算）；字体子集化（fonttools 级能力纯前端可做 pyftsubset 的 JS 平替有限，谨慎承诺）

## 优化处方（验收标准）

1. **name 列表弹性高度**：`.list` 改 `max-height: 50vh`。→ **验收：50 条 name 记录的 CJK 字体一屏可见 ≥20 条**
2. **下载引导**：convert 成功后"下载"按钮变 primary 并 focus。→ **验收：转换完成键盘 Enter 即可下载**
3. **试字预览**：信息面板下加试字框，默认文案"永Dj 0123"，用 FontFace 加载转换产物渲染。→ **验收：转换 WOFF 后输入自定义文字，预览区以该字体渲染且失败时提示**
4. **批量**：多选字体文件，列表逐行显示方向与状态，一键全部转换后 ZIP 下载。→ **验收：拖入 3 个字重文件，一次操作得 3 个 WOFF 的 ZIP**
5. **TTC 选择**：TTC 输入时显示字体索引下拉（读 ttcf 头 numFonts）。→ **验收：含 4 字体的 TTC 可切换导出第 2 个字体的 WOFF**
