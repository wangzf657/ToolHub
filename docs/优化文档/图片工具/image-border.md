## 结论与优先级

## 扣分点明细

1. 【功能-个性】只有四边对称纯色单框（imageEngine.ts:214-220 扩底实现）：无四边独立宽度（ezgif 支持）、无拍立得（下边加厚）、无内嵌双框、无"圆角+边框"组合——与 round-corners 组合需两次跨工具往返
2. 【功能】无留白画布模式：Instagram 式"图居中+白底方图"（1:1 画布）是电商/社媒最高频加框场景，本工具只能"外扩框"不能做"留白画布"
3. 【交互】无宽度预设与百分比：maxW 随图变化但无"边长 2%""8px"等快捷档（ImageBorder.vue:36-40）
4. 【可用性-共性】预览无高度上限（ImageToolBase.vue:61-64）+ 控件在预览后（:141-152），大图时参数与下载按钮沉底
5. 【灵魂】颜色无最近使用/常用色板（纯白/纯黑一键）；无粘贴即处理（FileDrop.vue 无 paste 监听）
6. 【功能】导出锁死 PNG（ImageToolBase.vue:34 默认 mime）：给 JPG 商品图加白框导 PNG 体积无谓膨胀（纯色边压缩率本应极高）
7. 【交互-疑似】宽度拖到 0 时仍可点“下载结果”：output 为 null 时基座回退下载重编码原图（ImageToolBase.vue:103 `output.value ?? source.value`），用户会在未加框状态下拿到一张无用 PNG——应禁用下载或提示“未添加边框”

## 行业对标与差距

- **shots.so / Screenshot.rocks**：相框+背景+阴影+尺寸预设一步出营销图。差距：**场景化代差**——对方输出"成品"，本工具输出"加了框的原图"。
- **ezgif border**：四边独立宽度、多种边框样式。差距：参数自由度。
- 借鉴优先级：留白画布模式（1:1）> 四边独立 > 圆角组合 > 色板预设。

## 可拓展性

- 短期（1 周）：宽度预设 chips（8/16/24/32/5%）+ 常用色板（白/黑/灰）；导出格式选择
- 中期（1 月）：留白画布模式（目标比例 1:1/4:5+边距百分比+背景色）；圆角+边框组合（复用 round op）；四边独立宽度（上/右/下/左）
- 远期：与 round-corners、circle-crop 合并"图片外形容器"组；接入 shots.so 式背景渐变

## 优化处方（验收标准）

1. **留白画布模式**：加"模式：外扩框｜留白画布"切换；留白模式选目标比例（1:1/4:5）+边距百分比+背景色。→ **验收：2000×1000 图选 1:1 留白 10%，输出 2000×2000 白底居中**
2. **预设与色板**：宽度滑杆旁 5 档 chips；颜色行加 6 色快选圆点。→ **验收：点击白色圆点后预览立即变白框**
3. **导出格式**：下载行加 PNG/JPG chips。→ **验收：JPG 输出的白框商品图体积 < 同图 PNG 的 1/3**
4. **首屏可达**：预览 canvas max-height:min(60vh,640px)。→ **验收：竖图加框后下载按钮 768 视口内可见**
5. **宽度 0 防呆**：宽度为 0 时下载按钮禁用并提示“拖动滑杆添加边框”。→ **验收：宽度 0 时按钮呈禁用态且提示可见**
