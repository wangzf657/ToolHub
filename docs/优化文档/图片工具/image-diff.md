## 结论与优先级

**交互优化** · P1

判据：单次对比闭环成立，但对比形态只有热力图一种、且 1px 错位即全图标红——回归测试的核心痛点（对齐）未解决。

## 扣分点明细

1. 【性能-个性】阈值 `watch(threshold, () => compute())`（:111）在滑杆拖动中逐次全量同步重算（compute :40-94 主线程无分片），12MP 双图连续卡顿、无进度提示
2. 【可用性-个性】尺寸不同直接拉伸对齐：drawImage 压到 min(w,h)（:44-55），宽高比不一致时形变误报；且无 ±px 偏移微调——截图滚动位置差 1px 即整图标红，UI 回归场景不可用
3. 【功能】对比形态单一：仅热力图 Tab（:136-140）；diffchecker 图像对比提供 slider/并排/difference 混合/闪烁四视图
4. 【功能】无差异区域汇总：无连通域 bounding box（数量/坐标/占比），差异多时只能肉眼扫热力图
5. 【功能】无放大镜 loupe——小面积差异像素无法放大检视
6. 【功能】单阈值作用于 RGB 差值和（:66 `sum > thr*3`），无通道独立/忽略抗锯齿选项——UI 截图边缘抗锯齿噪声易误报
7. 【功能】无对比报告导出（diff 占比+区域框叠加图一键出图），回归结论要手动截图
8. 【共性】结果舞台自绘无高度上限（:152,168-174，ImageToolBase 家族共性变体），长截图纵向撑开页面把下载按钮推出首屏（共性-根因4）
9. 【可用性-共性】FileDrop 无缩略图（家族共性），A/B 传反只能靠 field-label 文件名文字分辨（:125,129）——对比场景传错图的纠错成本高

## 行业对标与差距

- **diffchecker.com**：图像对比 slider 滑块/并排/difference 反差/闪烁四种视图、像素级放大、分享链接。差距：**对比视图形态**——对方能"定位到哪不同"，本工具只能"看到一片红"。
- 借鉴优先级：偏移微调对齐 > 滑块/并排视图 > 差异区域框列表 > 阈值重算防抖+分片 > 抗锯齿忽略 > 报告导出。

## 可拓展性

- 短期（1 周）：阈值 input 防抖 150ms + compute 分片 yield；结果舞台加 max-height（60vh）内滚
- 中期（1 月）：滑块对比与并排视图 Tab；方向按钮 ±1~10px 偏移补偿后重算；差异连通域框选+列表点击定位
- 远期：对齐算法（简单模板匹配自动找最优偏移）；对比报告 PNG（热力图+占比+区域框）一键导出

## 优化处方（验收标准）

1. **偏移微调**：新增"上/下/左/右 ±1px、±10px"对齐按钮，对齐后重算。→ **验收：B 图人为右移 1px 后点"左移 1px"，差异占比从 >90% 降至 <1%**
2. **对比视图 Tab**：热力图 | 滑块 | 并排 | 闪烁。→ **验收：滑块模式拖动手柄在同一视口内左右揭开创，闪烁模式可设 500ms 周期**
3. **重算防抖+分片**：阈值 input 防抖 150ms，compute 按行分片让渡主线程。→ **验收：12MP 双图拖动阈值滑杆无冻结感，松手 300ms 内出新结果**
4. **差异区域框**：标记 ≥32×32 差异连通域并列表（坐标/尺寸/占比），点击滚动定位。→ **验收：两张 UI 截图的差异按钮被红框标出且点击列表项舞台滚动至该区域**
5. **宽高比警告**：宽高比不一致时显示黄条提示并改用等比居中缩放。→ **验收：3:4 与 4:3 双图触发提示且不再整幅形变**
