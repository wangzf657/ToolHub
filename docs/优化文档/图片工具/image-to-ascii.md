## 结论与优先级

**交互优化** · P0

判据：可用性 10/20 触发硬伤红线——成品在预览区本身就是错的（折行错位），hint 让用户"去等宽环境看"等于承认预览不可用。

## 扣分点明细

1. 【可用性-硬伤】ResultBox 用普通 textarea 承载等宽字符画（`ResultBox.vue:63-71` 无 `wrap="off"`、无 white-space:pre），面板 ~500px 宽下约 60 列即软折行，200 列输出整幅错位成乱麻——"预览即成品"不成立（ImageToAscii.vue:67，共性-根因2 家族）
2. 【可用性】结果区钉死 260px（:67 min-height="260px"），200 列高对比图数百行只能小窗内滚
3. 【功能】无彩色 HTML/图片输出：text-image.com 支持彩色 HTML 与字符画转 PNG，本工具只有单色纯文本
4. 【功能】无反相开关（:18-22）：暗底终端（深色主题）里灰阶关系整体反转不可用，需用户自行改装字符集
5. 【功能】无对比度/亮度/Gamma 前置调节（asciiFrom 直接按线性亮度映射，imageEngine.ts:626-627）——低对比照片生成一片中灰字符
6. 【功能】字符集锁 3 组，无自定义字符序列输入；picascii 支持自定义字符
7. 【可用性-共性】ImageToolBase 原图预览无高度上限（家族共性），竖图把结果区推到两屏外
8. 【灵魂】无"终端 80 列/推文/README"宽度预设，无示例图一键填充空态

## 行业对标与差距

- **text-image.com**：彩色 HTML/彩色字符画、图片输出（PNG）、自定义字符集、宽度细调。差距：**输出形态代差**（纯文本 vs 彩色/图片）+ 预览正确性。
- **picascii**：亮度/反相参数、直接出图。差距：灰阶控制。
- 借鉴优先级：wrap="off"+弹性高度 > 彩色 HTML 导出 > 反相与对比度 > 宽度预设 > 自定义字符集。

## 可拓展性

- 短期（1 周）：ResultBox 增加 `wrap="off"` 横滚模式；结果区弹性高度；40/80/120/200 宽度预设按钮
- 中期（1 月）：彩色 HTML 导出（每字符 span 着色）；亮度/对比度滑杆与反相开关；自定义字符集输入框
- 远期：字符画渲染为 PNG/带背景图 HTML（社交媒体直发）；字符动画（GIF 逐帧 ASCII）

## 优化处方（验收标准）

1. **结果区不换行**：ImageToAscii 传 `wrap="off"` 新 prop，textarea 白色等宽横滚。→ **验收：200 列字符画横向滚动逐行查看无折行错位，行首行尾字符纵向对齐**
2. **弹性高度**：结果区改 `calc(100vh - 340px)` 下限 420px。→ **验收：1366×768 下同屏可见 ≥28 行字符**
3. **彩色 HTML 导出**：新增"导出 .html"，每字符 `<span style="color:rgb(...)">` 按原像素着色。→ **验收：浏览器打开该 HTML 呈现可辨彩色字符画且色调与原图一致**
4. **反相 + 对比度**：反相开关与 ±50% 对比度滑杆参与映射。→ **验收：深色终端主题勾选反相后明暗关系正确；低对比图拉对比度后字符层次可辨**
5. **宽度预设**：40（README）/80（终端）/120/200（高清）四档按钮与滑杆联动。→ **验收：点击"终端 80"后滑杆同步 80 且 200ms 内重渲染完成**
