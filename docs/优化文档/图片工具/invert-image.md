## 结论与优先级

**交互优化** · P2

判据：能力达成且实时预览，扣分集中于三 slug 共用的"身份稀释"与默认态；60 分与 grayscale-image（60）/adjust-brightness（61）同档。

## 扣分点明细

1. 【可用性-个性】页面身份稀释：desc 承诺"负片效果"（registry.ts:39），落地页却是五根通用调色杆、反相排第 5（AdjustImage.vue:50-54）——主参数层级与 grayscale-image 同病
2. 【交互】载入默认 invert=0（:14）：反相工具打开后图片仍是原色，第一眼无法确认工具生效；合理默认是 100%
3. 【功能】无反相独有玩法：正片负冲（黑白+反相叠加）、胶片底片翻印（橙色片基补偿）零预设零引导
4. 【灵魂】引擎死代码：`imageEngine.ts:284` 的表达式赋值立即被 :285 覆盖，属无效运算——功能无损但反映该引擎路径缺测试
5. 【可用性-共性】无按住看原图：强度 20~40% 的轻微偏色靠记忆不可判（ImageToolBase 无对比机制）
6. 【可用性-共性】竖图预览无高度上限（ImageToolBase.vue:61-64），下载按钮沉到流内底部（:143-151，共性-根因 4）
7. 【性能】全分辨率逐像素重算无降采样预览（imageEngine.ts:274-297，共性-根因 2 同族事实）

## 行业对标与差距

- **Photopea**：反相是调整层（非破坏、可挂蒙版局部反相）+ 底片数字化有专门色罩补偿。差距：非破坏与局部反相能力代差。
- **Polarr**：长按对比、直方图、预设滤镜墙。差距：反馈闭环。
- 借鉴优先级：默认即反相 > 按住看原图 > 正片负冲预设 > 预览降采样。

## 可拓展性

- 短期（1 周）：本 slug 载入默认 invert=100；反相滑杆置顶；按住看原图
- 中期（1 月）：预设 chips（标准负片/正片负冲/底片翻印补偿）；滑杆数值输入+双击归零

## 优化处方（验收标准）

1. **默认即反相**：本 slug 载入图片后 invert 自动置 100 并渲染。→ **验收：拖入彩色图 300ms 内预览呈负片，滑杆显示 100%**
2. **主参数置顶**：本 slug 下"反相强度"排第一，其余四杆收进"微调"折叠区。→ **验收：首屏第一根滑杆为反相强度**
3. **按住看原图**：预览左上角"按住对比"按钮。→ **验收：按住显示原图，松开恢复反相态**
4. **预设档位**：加"标准负片/正片负冲（黑白+反相）"chips。→ **验收：点击正片负冲后输出呈青红交叉反差色调**
5. **清理引擎死代码**：删除 imageEngine.ts:284 无效赋值。→ **验收：typecheck 与 npm run test 通过，invert 输出像素不变**
