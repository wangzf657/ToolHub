## 结论与优先级

**交互优化** · P1（预览缺失按 P0 快赢登记）

判据：引擎层认真（中位数统一/超限预警/进度），但"拼接结果看不见+顺序黑箱"是本工具最大体验断层。

## 扣分点明细

1. 【可用性-硬伤】无结果预览：run() 直接 canvasToBlob→notice 横幅（MergeImagesLong.vue:90-93,151-156），用户必须下载打开才能确认顺序/缩放/间距——拼接工具的核心确认环节缺失（模式 F"成败只靠横幅"，M-11 同族缺陷）
2. 【交互-共性】排序体验差：FileDrop 仅 ↑↓ 单步移（FileDrop.vue:57-64）+假拖拽手柄（GripVertical 不可拖，:98）；10+ 张截图调序成本随数量指数增长
3. 【可用性-个性】列表无缩略图：文件行只有名称+大小（FileDrop.vue:97-102），聊天截图全叫 Screenshot_2024xx 无法辨认——与缺陷 1 叠加成"黑箱流水线"：排得对不对、拼出来啥样，两头都看不见
4. 【功能】无"按文件名排序"快捷键、无拖拽排序（HTML5 draggable 改造路径现成）
5. 【功能】"建议分段拼接"停留在 toast 文案（:69），无自动分段输出多张的能力
6. 【交互】间距/最大边长是 number input 无滑杆：试间距要"输入→拼接→下载→打开"循环，无预览导致每次试错全量重跑
7. 【灵魂】输出文件名固定"长图拼接.png"（:103）不从首图派生；选完文件无"预计长图约 N px 高"预估
8. 【可用性-共性】Cookie 横幅首访遮挡底部结果横幅（M-01 同款）

## 行业对标与差距

- **ezgif**：拼接前逐项缩略图+顺序拖拽+输出即时预览。差距：**确认环节代差**——对方拼完可直接看图微调，本工具直接黑箱下载。
- **PicCollage / iOS 长截图拼接类 App**：拖拽排序+实时拼版预览。差距：排序交互代差。
- 借鉴优先级：结果预览区 > 列表缩略图 > 拖拽排序 > 间距滑杆+预览联动 > 分段拼接。

## 可拓展性

- 短期（1 周）：结果预览（outBlob createObjectURL 挂 img，限高容器内滚动可放大）；间距/最大边长滑杆化
- 中期（1 月）：FileDrop 缩略图（家族级改造，merge/collage/batch 全族受益）；HTML5 拖拽排序；分段拼接输出 zip
- 远期：拼接参数模板（聊天记录 1080px+0 间距 / 论文截图 900px+8px 间距一键预设）

## 优化处方（验收标准）

1. **结果预览**：完成后 notice 下方展示长图预览（max-height 480px 容器内滚动，点击放大）。→ **验收：拼接 3 张图后无需下载即可在页面内滚览整图**
2. **列表缩略图**：FileDrop 文件行加 48px 缩略图。→ **验收：10 张截图列表每行可见图片内容**
3. **拖拽排序**：文件行支持 HTML5 拖拽换位（↑↓ 保留）。→ **验收：第 3 行拖到第 1 位后顺序即时更新且 hint 同步**
4. **参数滑杆+预览联动**：间距 0~100 滑杆，改动后 300ms 内更新预览。→ **验收：拖动间距滑杆预览实时变化，无需重新拼接**
5. **分段拼接**：超限时提供"自动分段"选项（每段 ≤10000px）。→ **验收：8 张共 16000px 长图自动分段为 2 个文件打包下载**
