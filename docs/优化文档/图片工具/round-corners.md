## 扣分点明细

1. 【功能-个性】仅整体半径单一参数（RoundCorners.vue:33-36）：缺四角独立（CSS border-radius 语义）——聊天气泡（右上小圆角）、票据单角等场景无法表达；9elements 标杆即四角手柄拖拽
2. 【功能】无预设档：iOS 图标圆角（≈22.4%）、海报 8/12/16px 等高频值需手拖试凑
3. 【交互】滑杆无数值输入：radius 只能拖（:35），要 48px 得拖到位看 label；step=1 无百分比语义
4. 【功能】无与边框组合：圆角+描边（border op，imageEngine.ts:214-220 已存在）是头像卡配图高频组合，目前必须 image-border→下载→本工具→再下载 两次往返
5. 【可用性-共性】预览无高度上限（ImageToolBase.vue:61-64）+ 控件在预览后（:141-152）：大图时下载按钮首屏外
6. 【灵魂】无粘贴即处理（FileDrop.vue 无 paste 监听）、无半径记忆（下次仍默认 24）
7. 【美观】滑杆区 max-width:420px（RoundCorners.vue:33）与全宽预览不对齐，宽屏下控件孤悬左侧、右侧大片空白

## 行业对标与差距

- **9elements fancy border-radius**：四角手柄可视化、随机生成、直接复制 CSS。差距：**参数表达力代差**——对方表达任意 border-radius，本工具只表达一个数字。
- **CSS 生成器三件套**：预设+实时输出。差距：对开发者缺“复制 CSS 半径值”输出。
- **站内接力现状**：圆角+边框组合需两工具两次下载往返（见扣分点 4），建议与 image-border 处方同批交付组合能力。
- 借鉴优先级：四角独立 > 预设 chips > 数值输入 > 圆角+边框组合。

## 可拓展性

- 短期（1 周）：预设 chips（8/16/24/48/胶囊/iOS 图标）+ 数值输入；半径记忆 localStorage
- 中期（1 月）：四角独立滑杆组（可视化手柄）；"圆角+描边"组合开关（复用 border op）
- 远期：与 image-border、circle-crop 合并为"图片外形容器"工具组（圆角/圆形/边框/底色一次完成）

## 优化处方（验收标准）

1. **预设与数值**：滑杆旁加数值输入（0~maxR）与 6 个预设 chips，点击即生效。→ **验收：点击"胶囊"后输出与滑杆拉满一致**
2. **四角独立**：进阶开关展开 tl/tr/bl/br 四滑杆。→ **验收：tl=64 其余 0 时仅左上角为圆角**
3. **组合描边**：加"同时加描边"复选（宽度+颜色），一次导出圆角+描边 PNG。→ **验收：导出图外缘为描边色、四角仍透明**
4. **首屏可达**：预览 canvas max-height:min(60vh,640px)。→ **验收：3000×4000 图载入后下载按钮 768 视口首屏可见**
5. **小尺寸回看**：结果区加 48/64px 缩略回看（圆角在小尺寸下的观感）。→ **验收：导出前可见 64px 缩略效果且圆角比例一致**
