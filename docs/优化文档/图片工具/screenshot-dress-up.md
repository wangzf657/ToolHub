## 结论与优先级

**交互优化 + 需拓展** · P1

判据：三壳六背景的骨架可用，但与 shots.so 的参数自由度（地址栏/渐变/阴影/倍率）差距是功能面缺失而非打磨问题。

## 扣分点明细

1. 【功能-个性】浏览器壳地址栏硬编码 `https://toolhub.example` 且不可编辑（:83）——套壳后展示假域名；shots.so 核心交互即"点击改地址栏文字"
2. 【美观-疑似问题】说明文字白色 rgba(255,255,255,.92)（:121）在 solid-light #f1f5f9 浅背景（:25）上不可读——成品直接报废
3. 【功能】背景仅 6 个硬编码渐变/纯色（:20-27），无自定义色值/渐变角度；shots.so 支持任意双色渐变与纯色拾取
4. 【功能】阴影锁死一组 `0 24px 60px rgba(0,0,0,.3)`（:110,117,119）且无开关/强度滑杆——浅色产品照需要柔和阴影、深色背景需要无阴影，均不可配
5. 【交互】圆角/留白为 number 步进输入（:67,69），无滑杆与即时数值反馈，拖不出手感
6. 【功能】导出倍率锁 2x（:43 pixelRatio:2）——贴网页排版要 1x、retina 演示要 3x，均无选择
7. 【功能】手机壳为通用刘海 bezel（:87-89,117-118），浏览器壳无深色/浅色变体，无平板/编辑器窗型
8. 【灵魂】无画布比例预设（公众号头图 900:383、小红书 3:4、推文 16:9）与示例截图一键填充空态

## 行业对标与差距

- **shots.so**：明/暗浏览器窗、平板/手机多壳型、自定义渐变背景、阴影四滑杆、地址栏即点即改、1-3x 倍率、自动裁切比例。差距：**参数自由度代差**——对方把"配图调性"做成了可调参数，本工具只给了 6 个固定组合。
- **Screenshot.rocks**：背景图片/纯色、设备框库、圆角阴影分离调节。差距：同上，且无背景图支持。
- 借鉴优先级：地址栏可编辑 > 背景自定义（起止色+角度）> 阴影滑杆+开关 > 导出倍率 > 壳型库 > 比例预设。

## 可拓展性

- 短期（1 周）：地址栏可输入（留空隐藏 addr）；说明文字按背景亮度自适应深浅色；圆角/留白改滑杆
- 中期（1 月）：自定义渐变编辑（双取色器+角度）；阴影强度/开关滑杆；1x/2x/3x 倍率选择；深/浅浏览器壳变体
- 远期：画布比例预设+自动裁切；壳型库（平板/编辑器/终端窗）；背景图片上传

## 优化处方（验收标准）

1. **地址栏可编辑**：浏览器壳 addr 改为可输入文本，留空则隐藏地址栏。→ **验收：输入 example.com 后导出 PNG 地址栏显示该文字；留空导出无地址栏**
2. **说明文字自适应**：按背景平均亮度切换深/浅字色。→ **验收：选 solid-light 背景后 caption 为深灰且对比度 ≥4.5:1**
3. **背景自定义**：6 预设 + 自定义起止色取色器与 0~360° 角度滑杆。→ **验收：任意双色渐变实时反映在舞台与导出图中**
4. **阴影可调**：强度滑杆（0~80px blur）+ 开关。→ **验收：拖动滑杆舞台实时变化；关闭后导出图无投影痕迹**
5. **倍率选择 1x/2x/3x**。→ **验收：同一构图 3x 导出像素宽为 1x 的 3 倍且文字不模糊**
