## 扣分点明细

1. 【功能-个性】无方形优先裁剪：朋友圈九宫格的隐含前提是方格（每片 1:1），非方图按原尺寸 floor 分割直接切出长方形片（imageEngine.ts:419-420）——用户被迫先去 crop-image 绕一圈；PhotoSplit 类 App 默认中心方裁
2. 【可用性-个性】余数裁切不居中：`Math.floor` 从原点分割，右/下边缘直接丢弃（imageEngine.ts:419-420），主体不在几何中心时切图重心偏移；提示语（SplitGrid.vue:98）只说"会被裁掉"未说明裁哪边
3. 【性能-个性】缩略图同步 toDataURL：每次行列变更对每片执行全尺寸 PNG 编码（SplitGrid.vue:47），无进度反馈、滑杆拖动卡顿
4. 【功能】无留白模式：竞品普遍有"格间留白/白边"风格（九宫格更精致），本工具只有无缝切分
5. 【功能】无格式选择：锁死 PNG（:57）——摄影图九宫格 PNG 体积数倍于 JPG，经微信压缩后反而更糊
6. 【交互】切片无序号角标：缩略图不显示 1~9 序号（:95），发图顺序只能下载后凭文件名核对
7. 【灵魂】无整除提示：1080×1080 完美切分不提示；非整除时不给"建议先裁剪至 N×N"并一键跳 crop-image
8. 【可用性-共性】FileDrop 假拖拽手柄（本工具单文件不受影响，家族共性记录）

## 行业对标与差距

- **PhotoSplit / Grid Post**：方形裁剪+留白风格+切片序号角标+直接分享 Instagram。差距：**社交场景贴身度**——对方为发图流程做全，本工具止步于"切完给 zip"。
- **ezgif（裁剪系参照）**：切分预览+格式/质量可选。差距：输出格式弹性。
- 借鉴优先级：方形优先开关 > 缩略图异步编码+序号角标 > 留白模式 > JPG 选项 > 整除提示。

## 可拓展性

- 短期（1 周）：缩略图改 blob URL 异步生成（消除 toDataURL 卡顿）；切片序号角标；"方形优先"开关（中心裁剪后再切）
- 中期（1 月）：留白间距模式（格间白边计入每片）；PNG/JPG+质量选择；非整除时"去裁剪"一键跳 crop-image 带回参数
- 远期：社交尺寸预设（朋友圈/小红书/微博 1:1、4:5）；Web Share API 直接分享切片

## 优化处方（验收标准）

1. **方形优先**：新增开关（默认关），开启后先中心裁剪为最大正方形再切分。→ **验收：1920×1080 图开启后输出 9 片 360×360 且主体居中不偏移**
2. **异步缩略图**：切片预览改 blob URL 异步生成。→ **验收：12MP 图 3×3 切分时行列滑杆拖动预览 <300ms 出齐且无可感卡顿**
3. **序号角标**：每片缩略图左上角显示 1~9。→ **验收：角标序号与 zip 内文件名编号一一对应**
4. **留白模式**：间距 0~20px 滑杆（白边计入每片）。→ **验收：间距 8px 时每片四周含白边且九片拼回与原图对齐**
5. **JPG 选项**：格式切换 PNG/JPG+质量。→ **验收：JPG 0.9 时 9 片总体积 ≤ PNG 方案的 1/2**
