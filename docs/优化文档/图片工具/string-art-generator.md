## 结论与优先级

**交互优化** · P1

判据：算法与进度反馈合格，核心缺口是"钉位顺序"这一跟做交付物的可读性（分步化）与参数自由度。

## 扣分点明细

1. 【可用性-个性】钉位顺序把全部连线用顿号串成单行文本（:127 `${a+1} → ${b+1}，`），1200~3000 线在 150px 高 ResultBox 内滚动成一团乱码——"按顺序缠绕"的核心交付物不可读，跟做时无法定位当前步
2. 【功能】钉数锁 3 档 chip（:158 120/180/240），竞品 288 钉/4000 线自由组合（StringArtGenerator.cc）
3. 【功能】无编号框模板/分步导出：Michael Crum 版输出带钉位编号的框模板与分步骤序列，本工具只有裸 SVG+长文本
4. 【可用性】生成中只有进度条无预览（:170），SVG 在完成后一次性 v-html（:172-174）——等数秒才知道效果不佳，只能盲调参数重算
5. 【功能】采样画布仅 200×200（S=200，:21-23），人脸五官细节损失明显；无质量/速度档位（竞品普遍 400+ 采样）
6. 【功能】无 PNG 导出（:136-141 仅 SVG/TXT），社交分享需自行转格式
7. 【功能】无物理参数：画框直径/钉间距/用线总长估算，DIY 备料全靠自己算
8. 【灵魂】无示例图一键填充；深色照片残差低效果差时无"建议换亮色/反相"引导（:56 仅按 255-亮度计残差）

## 行业对标与差距

- **StringArtGenerator.cc / StringAr.com**：288 钉/4000 线自由参数、模板下载、分步跟做指南。差距：参数上限与步骤可读性。
- **ThreadArtGenerator.com**：CMYK 彩色弦线模式（可打印彩色弦线画）。差距：只有单色黑线。
- 借鉴优先级：顺序分步化（逐行+分组）> 生成中增量预览 > 自由钉数 > PNG 导出 > 物理参数估算 > 彩色模式。

## 可拓展性

- 短期（1 周）：顺序 TXT 改逐行+每 50 步分组；生成中每 10% 增量追加线段预览；取消按钮（复用 runId）
- 中期（1 月）：钉数滑杆 80~400；SVG 光栅化 2x PNG 导出；画框直径输入→钉间距/用线量估算卡
- 远期：彩色弦线（CMYK 多线层）；物理模板 PDF（带编号钉位环形图）打印直出

## 优化处方（验收标准）

1. **顺序分步化**：TXT 每行一条 `0042 → 0187`（换行分隔），每 50 步插入空行分组，ResultBox 内同格式展示。→ **验收：1200 线输出逐行可读、可打印勾选，第 N 步可在 10 秒内定位**
2. **生成中预览**：每完成 10% 将已定线段追加渲染到 SVG。→ **验收：生成过程可见弦线逐步累积，完成后无整幅重绘闪烁**
3. **自由钉数**：滑杆 80~400 步进 8（保留 3 快捷 chip）。→ **验收：任意钉数（如 277）生成成功且 SVG 钉点数一致**
4. **PNG 导出**：SVG 光栅化 2x PNG。→ **验收：导出 1600×1600 PNG 与 SVG 视觉一致且线条无锯齿**
5. **物理参数卡**：输入画框直径 cm，输出钉间距与用线总长估算（线段长×线数×1.1 缠绕系数）。→ **验收：直径 40cm/240 钉时钉间距 ≈5.2mm、线总长有数值与口径说明**
