## 扣分点明细

1. 【功能】无倍率预设：设计师高频诉求"1x/2x/4x"（相对 SVG 原始尺寸），现只有裸数字输入（:88）——CloudConvert/Squoosh 导出面板均有倍率档
2. 【功能】仅单文件：`:multiple="false"`（:79），一批图标要转 PNG 得逐个拖入；家族其他 imgcvt 均支持 50 张批量，体验倒挂
3. 【健壮性】宽度无上限：仅 `Math.max(16, width||1024)` 下限保护（:23），输入 100000 时 canvas 超限静默失败，按钮恢复可点但无任何错误提示——疑似缺陷（失败被 catch 后 toast 依赖 message 为空）
4. 【功能】无背景填充选项：透明 SVG 只能出透明 PNG，需要白底/纯色底的用户（如微信头图）得再跑别的工具
5. 【交互】预览无缩放：`c.style.maxWidth='100%'`（:48），超大尺寸输出在预览区被压小，无法 1:1 核对细节清晰度——"栅格化清不清晰"恰是本工具的核心疑问
6. 【边界】SVG 无 width/height 且 viewBox 缺失时回退 512px 基准（imageEngine.ts:85-86），倍率结果可能与用户直觉不符且无提示

## 行业对标与差距

- **SVGOMG / CloudConvert**：宽度或倍率双模式+预设档+批量队列+结果列表逐张下载。差距：批量与倍率档。
- **Squoosh**：导出前后并排对比、放大镜核对压缩伪影。差距：本工具"清不清晰"全靠下载后自己放大看。
- 借鉴优先级：**倍率预设按钮组 > 1:1 预览切换 > 批量 > 背景色选项**。

## 可拓展性

- 短期（1 周）：宽度输入旁加 1x/2x/3x/512/1024/2048 快捷按钮；宽度上限校验（≤16384）并 toast 报错
- 中期（1 月）：批量多文件（复用家族结果列表行）；背景色填充开关
- 远期：与 image-resize 类工具联动，栅格化后直接进调整管线

## 优化处方（验收标准）

1. **倍率预设**：宽度输入右侧加「1x / 2x / 3x」按钮，点击后宽度=原始宽×倍数并立即重栅格。→ **验收：拖入 512 宽 SVG 点 2x，输出尺寸显示 1024×(比例高)，预览同步更新**
2. **宽度上限与报错**：输入 >16384 时按钮禁用并提示"宽度超出浏览器画布上限"。→ **验收：输入 99999 后按钮置灰、出现红色提示文案**
3. **1:1 核对**：预览区加「适配 / 1:1」切换，1:1 时容器内滚动。→ **验收：输出 2048 宽时切 1:1 可滚动查看原始像素**
4. **批量**：accept 多文件，逐个栅格后进入家族结果列表（缩略图+逐张下载+ZIP）。→ **验收：拖入 3 个 SVG 生成 3 行结果可分别下载**
5. **背景填充**：加「透明/白色/自定义色」三选。→ **验收：选白色后预览棋盘格消失、导出 PNG 透明区为白**
