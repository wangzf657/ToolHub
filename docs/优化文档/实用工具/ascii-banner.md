## 结论与优先级

**交互优化 + 需拓展** · P1

判据：无可用性硬伤；核心差距是字体库量级（拓展）+ 截断/字符集不透明（交互）。

## 扣分点明细

1. 【交互】12 字符上限静默截断：`slice(0, 12)`（textEngine.ts:575）在引擎层悄悄丢弃第 13+ 字符，输入框无 maxlength、无字数计数器、无提示（AsciiBanner.vue:49-51 仅标签文字提及"最多 12 个字符"）——用户输入"TOOLHUB 2026"不会知道后半段丢了
2. 【功能】字体库单薄：仅 1 种 5×5 自绘字体，对照 patorjk TAAG 的 figlet 600+ 字体（Big/Slant/Standard/Doom…）与宽度/字距选项（引擎 `space` 参数 textEngine.ts:574 存在但 UI 未暴露）
3. 【口径】中英文支持名不副实：汉字字形只有"中/文"两个（textEngine.ts:570-571），输入"百宝工具箱"4 个字里 2 个出"?"（textEngine.ts:579 fallback），标签"英文数字为主"（:49）未覆盖此预期落差；且未显示"以下字符不受支持"清单
4. 【功能】无样式变体：无轮廓/实心切换、无多行横排、无阴影/渐变填充（TAAG 单页即 600 字体×即时切换）
5. 【交互】fill 与字形耦合的边界未披露：选 fill='*' 时若文本本身含 '#'/'*' 等标点字形，视觉混淆无提示（ASCII 值语义上 '#' 是字形 '*' 是填充）
6. 【灵魂】不支持"复制为 C 代码块/Markdown 代码块"格式包裹——本工具最大场景就是贴 README/代码注释，一键带 ``` 围栏是现成的贴心细节
7. 【交互】下载文件名固定 ascii-banner.txt（:40）不可改；无字符画宽度/行数显示

## 行业对标与差距

- **patorjk TAAG**：600+ figlet 字体单页切换、宽度自适应换行、字符集覆盖全 ASCII、导出多种格式。差距：**字体广度代差**——对方是字体画廊，本工具是单字模。
- **figlet 生态**：全 Unicode 字体（含中文 figlet 字体）、字距/宽度参数。差距：中文字符集几乎为零。
- 借鉴优先级：截断显性化（计数器+maxlength）> 字体库扩充（先 5 款经典 figlet 字体）> 不支持字符提示 > 复制为代码块 > 字距参数。

## 可拓展性

- 短期（1 周）：input 加 maxlength=12+实时"剩 N 字"计数；输出区底部列出"未渲染字符：百 宝 工"提示；复制按钮加"复制为 Markdown 代码块"次选项
- 中期（1 月）：引入 figlet 字体数据（懒加载纪律，先 Big/Slant/Standard/Small/Shadow 5 款，约 100KB 级）；暴露引擎 space 字距参数
- 远期：字体画廊模式（左侧字体列表+右侧预览，TAAG 式布局）；中文点阵字体（16×16 宋体点阵自绘 3500 常用字约 200KB 数据）

## 优化处方（验收标准）

1. **截断显性化**：输入框 maxlength=12，右侧实时显示"N/12"。→ **验收：输入第 13 个字符无法键入且计数器准确；粘贴超长文本自动截到 12 且计数为 12/12**
2. **未支持字符提示**：字符画下方列出被渲染为"?"的字符清单。→ **验收：输入"AB百"时提示"未支持：百"，纯英文输入时无提示**
3. **字体扩充**：新增 ≥5 款 figlet 字体（懒加载），切换 chips 即时重绘。→ **验收：切换字体后预览行高/字形变化，首次切换加载时间 <1s 且页面无卡顿**
4. **复制为代码块**：主复制旁提供"复制为 ``` 围栏"次选项。→ **验收：粘贴到 Markdown 编辑器渲染为等宽代码块，字符对齐无错位**
5. **宽度显示**：预览区头部显示"5 行 × N 列"。→ **验收：输入 TOOLHUB 显示 5 行 × 49 列（7 字形 ×（5 列字宽+2 列间距））**
6. **自定义填充**：fill chips 旁加自定义字符输入（单字符）。→ **验收：输入 @ 后字符画实心位全部变为 @ 且五个预设 chips 取消激活态，清空输入恢复 █ 激活**
