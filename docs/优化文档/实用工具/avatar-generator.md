## 结论与优先级

**交互优化** · P1

判据：可用性无硬伤；核心扣分在精确 seed 语义落差、格式选项缺失（仅 PNG 无 SVG）与参数自由度，均为单点改造。

## 扣分点明细

1. 【灵魂-语义落差】精确 seed 永不渲染：批量种子按 `${seed}-${i+1}` 拼接（:46），输入"alice"得到的是 alice-1~alice-8，与 placeholder"同一 seed 同一头像"（:113）和说明文案（:124）承诺的确定性语义不符——用户为用户系统挑头像时恰恰想要"输入 alice 就得到 alice 的那张"
2. 【功能】无风格专属参数：DiceBear 各风格支持翻转/旋转/概率/配色等 options（createAvatar 第二参 :35 只传 seed+size），Playground 的核心玩法（调参数看变化）完全缺席
3. 【功能】无背景色/圆角/透明底选项：.backgroundColor 与 radius 是 DiceBear 内建能力，头像进 Navbar/评论区时圆底与品牌底色是高频诉求
4. 【功能】只导出 PNG：SVG 源文件不可下载不可复制（svgToPng :61-74 单向转换）——SVG 无损缩放+改色是头像接入的正道，svgText 就在内存里（:47）却无出口
5. 【交互】触发时机不一致：风格/尺寸 change 自动重渲染，种子编辑却要手动点按钮（:114），改完种子顺手换尺寸会"意外"生效新种子
6. 【可用性】批量下载 8 张 PNG 串行渲染无进度（:87-99），慢网/低端机上仅按钮 disabled，无"第 N 张"反馈
7. 【功能】单风格单批次：不能同屏对比多风格（换风格即覆盖），选风格需来回切换记忆对比
8. 【可用性】随机种子用 Math.random（:57）——非密码学场景无碍，但与站内"随机家族"的 crypto 口径不统一（random-number/dice-roller 均 crypto）

## 行业对标与差距

- **DiceBear Playground**：30+ 风格画廊、每风格参数面板（翻转/配色/背景/圆角实时预览）、SVG+PNG 双下载、API URL 直出。差距：**参数自由度代差**（options 全在前端库能力范围内，属真差距非天花板）。
- **Boring Avatars**：marble/beam/pixel 等几何风格、渐变底+确定性变体、极简 API。差距：风格审美宽度（可后续扩充 collection 内其他系列）。
- 借鉴优先级：精确 seed 预览 > SVG 下载/复制 > 背景色与圆角 > 风格参数面板 > 多风格同屏对比。

## 可拓展性

- 短期（1 周）：批次第 1 张直接渲染精确 seed（其余 -2~-8）；加"下载 SVG/复制 SVG 代码"按钮；种子输入 Enter 即生成
- 中期（1 月）：背景色/圆角/翻转参数接入 createAvatar options；批量下载加进度（第 N/8 张）；风格画廊模式（一次展示 3 风格×3 变体）
- 远期：扩充 DiceBear collection 其余风格（ needModel 式首用提示避免体积）；与 name-generator 互链（起名→同名 seed 头像）成"角色包"工作台

## 优化处方（验收标准）

1. 精确 seed 入批：生成批次含输入原值一张，标注"这是 alice 的头像"。→ **验收：输入 alice 点生成，网格中存在 seed 显示为"alice"（无 -1 后缀）的一张**
2. SVG 出口：单张卡 hover 出"PNG/SVG"双下载，头部加"复制 SVG 代码"。→ **验收：下载的 SVG 文件可直接在浏览器打开且与预览一致**
3. 外观参数：新增背景色 picker 与圆角滑杆（0-50%），实时重渲染。→ **验收：改背景色后 8 张预览即时变色，PNG/SVG 导出与预览一致**
4. 触发统一：种子输入 Enter 或 change 均自动生成（防抖 300ms）。→ **验收：输入新种子后不点按钮，800ms 内网格自动刷新**
5. 批量进度：全部下载时按钮显示"3/8"式进度。→ **验收：8 张下载过程中进度数字递增，完成后 toast 提示**
