## 扣分点明细

1. 【功能】标准不可选：固定中国切点（bmi<24 正常/<28 超重，registry.ts:153），WHO 标准（25/30）与日本/亚洲其他切点无法切换——看英文体检报告或出境场景对不上号
2. 【文案不一致】desc 写"计算身体质量指数与 WHO 分类"（registry.ts:141），实现与 label 是中国标准（:153 分类逻辑、:157"分类（中国标准）"）——宣传口径与实际不符，信任损耗
3. 【功能】无年龄/性别输入：WHO 官方对 5-19 岁用生长曲线百分位而非成人切点，本工具对儿童直接套成人标准且无任何提示（note 仅写"中国成人标准" :161，但无年龄拦截）
4. 【灵魂】无"离正常体重差 X kg"行动化提示（偏瘦用户最想要这句）；无 BMI 标尺色带（12~35 刻度上指针在哪档）
5. 【交互】无记忆：身高是慢变量，每次复测却要重输（家族共性，CalcTool.vue:10 无持久化）；无 lb/in（海外华人场景）
6. 【站内分裂】calorie-calculator（registry.ts:906）、tdee-calculator（:1363）、ideal-weight-calculator（:976）同属健康家族，零互链——算完 BMI 的自然下一步是"该吃多少卡/理想体重多少"
7. 【可用性】输入无范围校验：身高 3cm 或 300cm、体重 1kg 都照算出结果（registry.ts:145-146 fields 无 min/max，CalcFieldInput.vue:44-46 支持但未配置），极端值结果不质疑输入
8. 【交互】主结果"BMI 指数"旁无参考范围 hint（registry.ts:156 只有纯数字），18.5~23.9 的正常区间藏在 note 里，用户要自己对照

## 行业对标与差距

- **WHO BMI 计算器**：成人/儿童青少年分册（儿童用年龄-性别百分位）、标准出处引用、多语言。差距：**口径分册**——对方对未成年人给的是正确工具，本工具给的是错误静默。
- **Calculator.net BMI**：公英制切换、年龄性别输入、BMI 图表定位、与理想体重/BMR 计算器互链。差距：单位覆盖与家族互链。
- 借鉴优先级：**desc 改口（最低成本）> 标准 Tab（中国/WHO）> 年龄拦截提示 > 互链 tdee/ideal-weight > 记忆身高**。

## 可拓展性

- 短期（1 周）：desc 与 note 口径统一；身高记忆；结果行单值复制
- 中期（1 月）：中国/WHO 标准 Tab；年龄字段 + <18 岁提示行；BMI 标尺色带（纯 CSS 可做）
- 远期：与 tdee/ideal-weight/calorie 整合"健康计算中心"（BMI→BMR→TDEE→食谱一条链）

## 优化处方（验收标准）

1. **文案一致**：desc 改为"按中国成人标准分类"或实现中真正加 WHO 选项。→ **验收：页面文案与实际采用切点一一对应**
2. **标准切换**：加"中国 | WHO"Tab，切点分别为 24/28 与 25/30。→ **验收：BMI=25.0 时中国档显示"超重"、WHO 档显示"正常"，切换 300ms 内生效**
3. **年龄拦截**：新增年龄字段，<18 岁时结果区出现"未成年人请使用儿童生长曲线，成人标准不适用"提示行。→ **验收：年龄填 12 时提示行可见且主结果行带此 hint**
4. **行动化提示**：体重偏离健康区间时显示"距正常范围还需减/增 X.X kg"。→ **验收：身高 175、体重 85 时显示"减 9.4 kg 进入正常区间"（按 18.5~24 区间计算）**
5. **站内互链**：结果区底部加"基础代谢 TDEE →""理想体重 →"链接。→ **验收：点击跳转对应工具页且透传身高体重**
