## 结论与优先级

## 扣分点明细

1. 【可用性】空态误导值：age/h/w 全空时 Number('')=0 直接进公式（registry.ts:923-937 无守卫），初始页面显示"基础代谢 BMR 5 千卡/天 / 目标热量 7 千卡/天"且 primary 高亮——与 mortgage-calculator.md 扣分 1（空态 ¥0.00）同族缺陷；站内 tdee-calculator 已有守卫先例（registry.ts:1380），修复零成本
2. 【实用价值-站内重复】tdee-calculator（registry.ts:1363-1395）与本工具同一 Mifflin 公式、同一 5 档活动系数；差异仅本工具多"目标三选"乘数（-20%/维持/+15%，:919-921）vs 对方"±300 千卡"三行（:1387-1389）；两入口零互链零合并，营养素建议还互相矛盾（本工具蛋白 30%/碳水 40%/脂肪 30%，:933-935；对方蛋白 30%/脂肪 25%/碳水 45%，:1390）
3. 【功能】无公式选择：Katch-McArdle（需体脂率，健身人群精度更高）缺席——站内已有体脂率计算器可联动透传；BMI 对照行亦缺席
4. 【功能】目标只给终值：-20% 乘数折算成"每周约减 0.5 kg"的推导行缺席，tdeecalculator.net 对 cutting/bulking 给逐档热量表
5. 【家族共性】无输入记忆、结果不可单值复制（CalcTool.vue:10、:55-66）——"每天该吃多少千卡"恰是最常被截图发聊天的结果
6. 【可用性】无范围校验：年龄填 3 或 120 照算（CalcFieldInput.vue:44-46 未配 min/max）；儿童/孕妇本不适用 Mifflin 公式，note（registry.ts:938）未披露适用人群边界
7. 【灵魂】无预填示例：对比家族内 mortgage 的 30%/4.2% 预填（registry.ts:72-74）与 tdee 的 age 30 默认（:1369），本工具初始即"7 千卡"空态，第一印象最差
8. 【功能】无三餐分配：目标热量只有总量，无早/午/晚分配建议行（对标产品输出每餐热量），用户仍需自行拆分

## 行业对标与差距

- **tdeecalculator.net**：BMR/TDEE/BMI/宏量目标一体，cutting/bulking 双目标逐档热量表，公式可切（Mifflin/Katch-McArdle）。差距：**目标规划维度**——对方是"增减脂热量规划器"，本工具是单值快算。
- **Omnicalculator**：每个参数附公式出处与中间步骤。差距：本工具有公式名（registry.ts:938）但无中间量展开。
- **站内 tdee-calculator（registry.ts:1363-1395）**：同公式兄弟入口，±300 千卡三档+一行式宏量。差距：两入口零互链且宏量口径矛盾（30/40/30 vs 30/25/45）。
- 借鉴优先级：**与 tdee-calculator 二合一（含守卫）> 公式选择（联动体脂率）> 逐档热量表 > 预填示例 > 单值复制**。

## 可拓展性

- 短期（1 周）：补空值守卫（照抄 tdee-calculator registry.ts:1380 写法）；字段加 suffix 与 min/max；结果行单值复制
- 中期（1 月）：与 tdee-calculator 合并为"热量工作台"（维持/减脂/增肌三档对比 + 宏量分配口径统一）；体脂率联动 Katch-McArdle
- 远期：接入 food-calorie-lookup 形成"吃多少→吃什么"闭环（目标千卡 → 三餐示例分配）

## 优化处方（验收标准）

1. **空值守卫**：age/h/w 任一为空时 compute 返回"请填写年龄、身高与体重"引导行。→ **验收：清空任一字段后 300ms 内显示引导行，不再出现"目标热量 7 千卡/天"**
2. **二合一或差异化**：保留两工具则本工具定位"目标规划"（补 ±250/±500 千卡逐档表）、tdee 定位"基础代谢"，并互相链接、统一宏量口径。→ **验收：两工具底部互链可见；同参数下两页营养素建议一致或各自 note 披露差异**
3. **范围校验**：age min 2 max 100、h min 80 max 250、w min 20 max 300。→ **验收：键入年龄 0 或 150 时输入框标红且不进计算（CalcFieldInput 已有 min/max 通道）**
4. **预填示例**：age 30、h 170、w 65、轻度活动、维持为初始值。→ **验收：打开页面即见合理 BMR/TDEE/目标热量，无空态误导值**
5. **单值复制**：目标热量行 hover 复制纯数字。→ **验收：复制后剪贴板为形如 1786 的整数**
6. **三餐分配行**：结果区新增早/午/晚分配行（默认 30/40/30）。→ **验收：目标 1786 千卡时显示 536/714/536 千卡三档**
