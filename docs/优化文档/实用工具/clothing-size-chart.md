## 结论与优先级

**需拓展 + 交互优化** · P1（"查询表"被装进"计算器"壳的形态错位是主病灶）

判据：本工具本质是查询表（用户扫读比较），calcDef 行卡片形态让对照效率打折；存量数据（连衣裙/内衣/童装/肩宽）未开放属功能子集悬殊（需拓展）。

## 扣分点明细

1. 【功能-核心】存量数据被藏三分之二：SIZE_CHARTS 实有 7 类（utilData.ts:98-172，含连衣裙/内衣罩杯/童装身高档），registry 只映射男/女 × 上/裤 4 类（registry.ts:1846-1848 硬编码 cat 查找）——童装是亲子海淘高频需求，数据就在引擎里却进不了 UI
2. 【可用性-形态错位】对照表退化成行卡片：结果按 intl 码一行一条纵向堆叠（registry.ts:1850-1853），胸围/腰围藏在句中，用户比"XL 和 2XL 腰围差多少"要逐行读句——对照表的基本盘是**横向表格扫读**
3. 【功能】肩宽字段被丢弃：SIZE_CHARTS 每行含 shoulder 数据（utilData.ts:102-106），registry 拼串只用 chest/waist（registry.ts:1852）——落肩/垫肩版型敏感的用户拿不到现成数据
4. 【灵魂-个性】推荐与对照表脱节：primary 推荐行（registry.ts:1854）与下方 5 行对照无视觉联动（无高亮/无锚点），"推荐 M"后还要自己在卡片堆里找 M——查询工具自己给的答案自己不指路
5. 【交互】空态零信息：身高/体重默认 ''（registry.ts:1837-1838），打开页面结果区只有"请填写身高与体重"一行（registry.ts:1844）——预填 170/65 即可展示完整对照+推荐（loan-calculator.md 处方 3 同款改法）
6. 【功能】无反向查询与罩杯：只能"身高体重→码"，不能"S 码→对应身高体重"（购二手/代购验码场景）；内衣类（utilData.ts:152-161 已有罩杯口径）整类缺席
7. 【交互】家族共性：无输入记忆（CalcTool.vue:10-40 无 localStorage）、结果行不可单值复制（CalcTool.vue:55-66 仅展示）——海淘比价场景复制"欧码 48"是高频动作
8. 【实用价值】鞋码断联：shoe-size-converter 独立工具存在且本页零互链——"海淘尺码"场景鞋码与衣码天然连用

## 行业对标与差距

- **sizeguide.net**：男/女/童全类目、国际 20+ 国家尺码双向换算、鞋码衣码一站式、表格化呈现。差距：**类目覆盖与表格形态代差**——对方是尺码数据库，本工具是两张裁剪过的卡。
- **UNIQLO 官方尺码指南**：按商品版型（修身/合身/宽松）分别给表、表格高亮推荐、厘米/英寸切换。差距：版型维度与表格高亮交互。
- 借鉴优先级：结果改横向表格 + 推荐行高亮 > 开放连衣裙/内衣/童装三类 > 肩宽列补回 > 预填示例 > shoe-size-converter 互链。

## 可拓展性

- 短期（1 周）：品类下拉补"连衣裙/内衣/童装"三档（数据已有，仅改 registry 映射）；结果行加 shoulder；预填 170/65
- 中期（1 月）：CalcTool 结果区支持 def 声明 table 形态（本工具为首例，行→表格渲染 + primary 行高亮）；反向查询 Tab；与 shoe-size-converter 互链
- 远期：品牌版型系数（修身/宽松 ±1 档切换）；身高体重输入改滑杆即时联动；calcDef 家族"表型工具"通用形态沉淀（与 periodic-table 等查询类工具复用）

## 优化处方（验收标准）

1. **表格形态**：结果区改为 6 列横向表格（国际码/中国/欧码/胸围/腰围/肩宽），recommended 行高亮 accent 底色。→ **验收：打开即见完整表格，推荐行与"S~2XL"各列对齐可横向扫读，肩宽列有值**
2. **开放存量品类**：品类下拉补齐连衣裙（女）/内衣（女）/童装三档。→ **验收：选择"童装"后显示身高 90~160 五档表格；选择"内衣"显示罩杯口径行**
3. **预填示例**：身高 170、体重 65 为初始值。→ **验收：打开页面无需输入即见推荐行"XL"与完整对照表**
4. **反向查询**：表头国际码列可点击，点"XL"反向给出身高体重建议区间。→ **验收：点击 XL 行后出现"约适合身高 175~180cm / 体重 70~80kg"提示行**
5. **家族互链**：页面底部"查鞋码 →"链接 shoe-size-converter 并透传性别。→ **验收：点击后鞋码页性别已按本页选择预置**
