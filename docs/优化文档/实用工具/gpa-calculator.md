## 结论与优先级

**需拓展 + 交互优化** · P1

判据：相比 Calculator.net 缺累计 GPA/多制式/百分制直输（制式级缺失）；移动端行布局疑似溢出需实测确认后定级。

## 扣分点明细

1. 【功能】只有美制 4.0 letter 制（GpaCalculator.vue:13-18）：无百分制成绩直输（中国教务最常见的"85 分算几绩点"）、无 4.5/5.0 制（部分高校在用）、无北大式百分制分段算法——留学申请者可用，国内保研绩点场景对不上
2. 【功能】无加权算术平均分输出：申请系统普遍要求"加权平均分 %"，按学分加权求平均是一行计算，工具不输出
3. 【功能】无累计/学期 GPA 分轨：Calculator.net 支持"过去累计 GPA+本学期课程合成新 GPA"；本工具只能全部重录
4. 【交互】无记忆：courses 仅初始两行示例（:21-24），无 localStorage——几十门课录完刷新全丢，痛感大于 calcDef 家族的表单工具
5. 【可用性-疑似】课程行挤压：course-row 无 flex-wrap（:87-90），课程名 input flex:1.4 的 min-content 约 170px，390px 面板四元素总需求约 407px 大于可用约 296px，疑似横向溢出（HoursCalculator.vue:76-80 已示范 flex-wrap 正解，本组件未跟进）
6. 【交互】新增行默认成绩 A（:38）：乐观偏置使用户漏改时 GPA 虚高；应默认留空并在统计中排除
7. 【代码卫生】空 watcher（:46 `watch(courses, () => {})`）与导入未用的 toast（:20、:47 `void toast`）为死代码
8. 【功能】无批量导入：不能粘贴课程清单文本批量生成行，几十门课只能逐行手选成绩下拉

## 行业对标与差距

- **Calculator.net GPA**：letter/百分制双输入、学期+累计双轨合成、可含无学分课程、结果分享。差距：**制式与分轨代差**——对方覆盖"任何学校任何算法"，本工具只覆盖美制 letter。
- **国内教务/北大算法参照**：百分制分段换算（90-100=4.0、85-89=3.7 等）+ 加权平均分并行输出。差距：中国场景口径整体缺席。
- **站内 grade-calculator（registry.ts:1040）**：单科加权总评工具。差距：与 GPA 无联动且两页面零互链，"总评→绩点"场景被割裂。
- 借鉴优先级：**百分制直输+算法切换 > 加权平均分行 > localStorage 记忆 > 累计 GPA 合成 > university-lookup 互链**。

## 可拓展性

- 短期（1 周）：courses 持久化 localStorage（key 前缀 toolhub）；行布局加 flex-wrap（照抄 HoursCalculator.vue:76-80）；点击 GPA 复制数值；新增行默认留空
- 中期（1 月）：4.0/4.5/5.0 算法切换+百分制直输（加权平均分并行输出）；目标 GPA 反推行（"还差几门 A 才能拉到 3.5"）
- 远期：累计 GPA 分轨（导入上学期结果合成）；与 university-lookup 互链（按学校预设算法）

## 优化处方（验收标准）

1. **记忆**：courses 持久化 localStorage。→ **验收：录入 5 门课后刷新页面数据完整保留**
2. **百分制直输**：成绩列支持 letter 或 0-100 分双模式，按所选算法换算。→ **验收：85 分在北大 4.0 分段算法下计 3.7，且加权平均分 85.3 同时可见**
3. **行布局修复**：course-row 加 flex-wrap，窄屏课程名独占一行。→ **验收：390×844 下无横向溢出、课程名完整可编辑**
4. **复制**：点击 GPA 大数字复制数值并出现 1.5 秒对勾反馈。→ **验收：剪贴板为形如 3.42 的数值**
5. **累计 GPA**：新增"过去累计 GPA/学分"输入并与当前课程加权合成。→ **验收：累计 3.2×100 学分 + 本学期 3.8×20 学分显示 3.30**
6. **批量导入**：支持粘贴"课程名 分数 学分"多行文本一键生成课程行。→ **验收：粘贴 2 行文本生成 2 行课程且总学分正确累计**
