## 结论与优先级

**交互优化 + 需拓展** · P1

判据：负数小计是疑似功能缺陷须修（perDay 先 push 后 clamp 的顺序问题）；日期/加班/工资三维度缺席使其相比 Time Card 计算器仍是"片段工具"。

## 扣分点明细

1. 【疑似功能缺陷-可用性】休息>时长时段显示负数小计：sumHours 在 clamp 前把 mins 推入 perDay（dateEngine.ts:142 push、:143 才 Math.max(0,mins)），行内小计经 formatMinutes 输出"-1 小时 -30 分钟"（HoursCalculator.vue:45；formatMinutes:148-152 对负数 Math.floor 得 −1 小时）——与总计行"该段按 0 计"（dateEngine.ts:143）自相矛盾
2. 【功能】无日期维度：行标签只有"第 N 段"（HoursCalculator.vue:36），真实工时表是"周一 09:00-18:00"；按日小计列与跨周累计全部缺席
3. 【功能】无加班拆分：劳动场景"8h 内正常+超出 1.5 倍加班"是工时计算高频问题，无阈值字段也不输出正常/加班两行
4. 【功能】无工资换算：时薪 × 总工时的预估工资行缺席（Calculator.net Time Card 标配）；兼职/时薪工算完工时马上要算钱
5. 【交互】无记忆与导出：每周考勤表重录一遍；结果仅展示（:55-62）不可复制/导出 CSV
6. 【灵魂】无常用班次预设：朝九晚六午休 1h 等一键填 absent；行复制（"同上一段"）也缺席
7. 【交互】误删行无撤销：删除按钮直接 splice（HoursCalculator.vue:26），手滑删段后需整行重填
8. 【功能】无多周累计：只能算当前列表总和，无"本周合计 vs 上周"对比视图

## 行业对标与差距

- **Calculator.net Time Card**：按周一~周日逐日填班+每日常规/加班拆分+时薪与加班倍率+周工资合计。差距：**从"段计时"到"周考勤"的代差**——对方输出工资单，本工具输出总分钟数。
- **站内 shift-schedule-calculator（registry.ts:1934）**：倒班排班工具。差距：排班与实绩工时两页面零互链，考勤场景被割裂。
- 借鉴优先级：**负数小计修复 > 时薪工资行 > 加班阈值拆分 > 日期/星期标签 > CSV 导出**。

## 可拓展性

- 短期（1 周）：修 perDay 负数（dateEngine.ts:142-143 clamp 后再 push）；休息上限校验（≤段时长）；行复制按钮
- 中期（1 月）：星期标签+按日小计分组；时薪与加班倍率字段，输出正常/加班/工资三行；CSV 导出
- 远期：与 shift-schedule-calculator 合并"排班考勤工作台"（排班 → 实际工时 → 工资核算闭环）

## 优化处方（验收标准）

1. **修负数小计**：perDay push 前对 mins 做 Math.max(0, mins)。→ **验收：09:00-10:00 休息 90 分钟的段小计显示"0 小时 0 分钟"，总计仍正确**
2. **休息校验**：休息分钟超过段时长时行内提示"休息时长超过工作时长"。→ **验收：该行出现提示文案且小计以 0 计**
3. **工资行**：新增时薪（默认空）与加班倍率（默认 1.5）字段，输出正常工时/加班工时/预估工资三行。→ **验收：时薪 30、单段 10h、阈值 8h → 工资 = 30×8+30×1.5×2 = 330**
4. **星期标签**：每行可选星期，总计区按星期分组小计。→ **验收：两行同标"周一"时显示周一合计且与总计一致**
5. **记忆+导出**：rows 持久化 localStorage；总计行复制按钮。→ **验收：刷新保留；复制得形如 42.5 的纯数字**
6. **撤销删除**：删除行后 5 秒内提供撤销入口。→ **验收：删一行出现撤销按钮，点击后该行数据原样恢复**
