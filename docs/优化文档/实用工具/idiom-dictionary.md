## 结论与优先级

**交互优化 + 需拓展** · P1（接龙是 desc 对用户的明确承诺，属功能缺口而非锦上添花）

判据：可用性 11/20 无硬伤但家族壳钉高/截断计数两处扣分；相比汉典缺接龙/部首检索等功能面差距明显。

## 扣分点明细

1. 【功能-承诺未兑现】`registry.ts:1580` desc 写"支持成语接龙与随机抽读"、keywords 含"接龙"，但 `IdiomDictionary.vue` 全文仅透传 DatasetLookup（:4 注释"首条成语接龙在下方扩展"后再无下文）——**对用户是虚假宣传级缺口**，接龙恰是此类工具的灵魂玩法
2. 【可用性】列表 `max-height:480px` 钉死（`DatasetLookup.vue:122`，共性-根因 2 家族），查"一"字头等宽泛结果需在小窗内长时间滚动
3. 【可用性】搜索截断 80 条但计数文案 `匹配 ${results.length} 条`（:99）把截断数当命中数展示，无"共 X 条，仅显示前 80"披露（家族共性）
4. 【交互】无收藏/最近查询记录：查过的成语下次要重搜（compare 汉典可收藏字词）
5. 【灵魂】空态列表头"最近 50 条"（:99）实为 JSON 文件顺序前 50 条（首条"阿鼻地狱"），与"最近"语义不符
6. 【性能】8.27MB 数据集无分片/无 Worker 解析、无加载进度百分比，弱网首用体验依赖一句 sizeHint（`IdiomDictionary.vue:7`"约 8MB，首次加载需数秒"——披露诚实，体验仍未兜底）
7. 【交互】搜索框无回车直达语义：输入后仍需目视列表自选，"回车展开第一条精确命中"缺失（`DatasetLookup.vue:89` input 无 keyup 处理）；无 Ctrl+K 聚焦类快捷键

## 行业对标与差距

- **汉典**：部首/笔画/拼音多路检索、字词收藏夹、逐字释义联动、出处古籍可点。差距：检索维度与收藏体系。
- **成语词典网**：接龙玩法（尾字接首字）、分类专题（生肖/数字/褒贬）、每日一词。差距：接龙即流量钩子，本站已宣传未实现。
- 借鉴优先级：**接龙模式（兑现承诺）> 结果计数诚实化 > 收藏/历史 > 部首笔画检索**。

## 可拓展性

- 短期（1 周）：接龙模式（输入尾字 → 列出以其开头的成语，数据就地可算）；计数文案改为"命中 X 条 · 显示前 80"
- 中期（1 月）：收藏本（localStorage `toolhub` 前缀）+ 最近查询；褒贬/生肖/数字标签专题筛选；每日成语（按日期 hash 取一条）
- 远期：与 hanzi-stroke-order/poem-search 组成"语文学习工作台"交叉入口；成语出处古籍名跳转全文检索

## 优化处方（验收标准）

1. **接龙模式**：搜索框旁加"接龙"Tab，输入任一成语后按尾字（忽略多音字取主音+文字双路）列出可接成语，点击即接续。→ **验收：输入"一鸣惊人"列出 ≥5 条"人"字头成语，点击其中一条后列表切换为其尾字接续链，可无限接力**
2. **计数诚实化**：DatasetLookup 空查询/命中提示区分"命中 X 条（显示前 80）"。→ **验收：搜索"一"显示"命中 80+ 条 · 显示前 80"，不再出现把 80 当全量的表述**
3. **收藏与历史**：每条目加收藏星标，搜索框下方出现最近 10 条查询 chip。→ **验收：收藏"守株待兔"后刷新页面仍在；点击 chip 即回填搜索**
4. **列表弹性高度**：`.list` max-height 改 `calc(100vh - 340px)` 下限 480px。→ **验收：1366×768 下同屏可见 ≥8 条完整条目，无需页面滚动**
5. **回车直达**：输入完整成语后回车自动展开第一条精确命中并滚动到可视区。→ **验收：输入"一鸣惊人"回车后该条处于展开态且位于视口上半部，模糊命中不触发**

> 家族共性声明：处方 2/4（计数诚实化、列表弹性高度）属 DatasetLookup 壳层改造，xiehouyu-lookup / poem-search / phonetic-lookup / garbage-classifier 四工具同享，应在壳组件一次落地、五份档案同步勾销。
