## 结论与优先级

**需拓展 + 交互优化** · P1

判据：无绝对硬伤但模板库存/撤销/持久化三支柱缺失（需拓展），清空不可撤销与儿童触控规格不达标（交互优化，对照 whiteboard.md 同病）。

## 扣分点明细

1. 【可用性-个性】清空/换模板不可撤销且无确认：reset 直接 :key 重渲染抹色（KidsColoring.vue:56-62），点任意模板 chip 即刻抹掉全部已涂色（:88）——对照 whiteboard.md 扣3"清空不可撤销"同病；儿童误触的代价场景里这是最痛的一刀
2. 【功能-核心差距】无撤销栈：fill 直改元素 inline style（:50-54），涂错只能用白色覆盖（:11 充当事实橡皮），连一步回退都没有
3. 【功能-核心差距】模板库仅 6 款（:17-48）：HelloKids 单主题即上千线稿，"亲子手工首选"（registry.ts:1660）的承诺与 6 款库存不匹配；无主题分组与难度分级
4. 【可用性】触控规格不达标：色板 26px（:112）、mini 按钮 28px（:115）远低于移动端 44px 触控下限——"家长友好大按钮"的产品设定未落实，儿童手指误触率高
5. 【灵魂】零持久化：已涂色存 DOM inline style（:50-54），刷新/误退全丢，无"我的画廊"；UTL-6b 内容资产不持久化家族空白
6. 【交互】打印涂色卡口径含糊：hint 教"打印可做涂色卡"（:98），但 print 输出的是**当前已上色**状态（:66,:121 print CSS）——想给二孩打印空白线稿必须先点清空毁掉手头作品；缺"打印空白线稿/打印我的作品"双入口
7. 【功能】无自由绘制与取色器：仅封闭区域填色，画不了云朵/草地等自创内容；11 色无浅色系（粉/浅蓝/浅绿），儿童审美高频色缺席
8. 【灵魂】无完成激励：不检测涂满、无庆祝/音效反馈——儿童产品的留存钩子完全缺位（对照 sudoku-solver.md 完成庆祝标准）

## 行业对标与差距

- **HelloKids（hellokids.com）**：数千线稿按主题/难度检索、在线填色与打印空白线稿双轨、作品保存。差距：**内容库存与"打印空白卡"代差**——对方是涂色平台，本工具是涂色 demo。
- **站内 whiteboard（whiteboard.md，50 分）**：已有撤销/重做按钮与导出实践，其扣3/扣4 教训（清空不可撤销、无持久化）在本工具原样复发——画布家族应共享"撤销栈 + localStorage 草稿"两件套。
- 借鉴优先级：撤销 + 清空确认 > 打印空白线稿入口 > 模板库扩充 > 44px 触控放大 > 作品画廊持久化。

## 可拓展性

- 短期（1 周）：填色操作栈（最近 20 步）+ 清空/换模板确认弹窗；色板/按钮放大至 44px；打印拆双入口
- 中期（1 月）：原创 SVG 扩至 30+ 款按主题分组；作品按模板存 localStorage 画廊（缩略图 + 续涂）；补浅色系与取色器
- 远期：涂满检测 + 庆祝动效（与 lucky-wheel 的仪式感标准看齐）；与 whiteboard/er-diagram-editor 组建画布家族共享撤销栈引擎

## 优化处方（验收标准）

1. **撤销 + 确认**：填色操作入栈（≥20 步），清空/切换模板前弹确认。→ **验收：涂 3 个区域后点其他模板出现确认弹窗，取消后颜色保留；Ctrl+Z 回退单步填色**
2. **双打印入口**：工具条拆"打印空白线稿"与"打印我的作品"。→ **验收：两按钮分别输出无色线稿与已涂版本，打印过程不影响当前画布状态**
3. **触控放大**：色板 ≥40px、按钮高度 ≥44px。→ **验收：390×844 视口下单手可准确点选任意色板（浏览器触控模拟无误触）**
4. **作品持久化**：按模板存 localStorage（模板 id + 填色映射），进页检测到草稿提示恢复。→ **验收：涂色后刷新出现恢复提示，接受后色彩完整还原**
5. **模板库一期**：扩至 ≥24 款并按"动物/交通/节日"分组。→ **验收：分组 chips 可见且每组 ≥6 款，切换模板不抹掉当前作品（转存草稿）**
