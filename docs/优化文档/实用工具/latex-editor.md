## 结论与优先级

**需拓展 + 交互优化** · P1

判据：无硬伤；与 latexlive 的差距集中在符号输入效率与导出选项（均为纯前端可达），属拓展主线。

## 扣分点明细

1. 【交互-核心差距】模板/符号插入在文本末尾：`tex = tex + '  ' + t.tex`（:72）不感知光标位置——写到一半想插个分式，结果拼接在整段末尾需手动剪切；latexlive 的符号面板插入在光标处是基本素养
2. 【功能-核心差距】无符号键盘面板：希腊字母/上下标/关系符/积分求和/箭头矩阵等分类点选是公式编辑器的效率核心（latexlive 左侧符号库 20+ 分类），本工具只有 12 个整式模板，零起点用户连 `\alpha` 都打不出
3. 【可用性】错误修复无闭环：throwOnError 后只展示 KaTeX 消息截断（:41），无「最近一次正确版本回退」「常见错误提示」（如漏 } 括号高亮），用户只能盲猜
4. 【功能】导出选项缺失：PNG 固定 pixelRatio 3、透明底（:56），无字号缩放、无白色底切换、无 SVG 矢量导出——贴深色 PPT 是高频翻车现场
5. 【交互】无草稿持久化：tex 无 localStorage，精心调好的长公式误刷新全丢（对照站内 ephemeral-notepad 的存稿实践）
6. 【功能】displayMode 切换不清爽：行内/独立公式 checkbox（:76）对非 LaTeX 用户语义不明，应给两种预览并排或自动判断
7. 【灵魂】能力边界未告知：KaTeX 支持宏列表与 MathJax 差异（化学方程、某些环境）无说明，报错时用户不知道是「写错了」还是「不支持」
8. 【交互】无历史/多公式管理：单公式页面，多题场景（一张卷 8 个公式）只能逐个生成逐个下载，无公式收藏列表

## 行业对标与差距

- **latexlive.com**：左侧 20+ 分类符号库（点击插光标处）、KaTeX/MathJax 双引擎切换、字号/底色/透明可选、公式图片识别（云，架构边界）、一键复制图片。差距：**符号输入效率与导出自由度代差**——对方是「不会 LaTeX 也能点出公式」的面板流，本工具要求用户会写 TeX。
- **Overleaf**：公式环境自动补全、错误跳转到行。差距：编辑器级错误定位（架构天花板内可做「首个可疑 token 高亮」的轻量版）。
- 借鉴优先级：符号面板（光标处插入）> SVG/底色导出选项 > 错误回退 > 草稿保存 > 与 markdown-to-image 公式联动。

## 可拓展性

- 短期（1 周）：模板点击改为光标处插入（textarea selectionStart）；tex 草稿 localStorage；错误文案附「已恢复上次正确公式」回退链接
- 中期（1 月）：分类符号面板（3~5 组高频符号起步）；导出选项（字号/白底/透明切换）；Ctrl+Enter 快捷导出
- 远期：与 markdown-to-image（开发工具）打通「公式 → 文章插图」管道；KaTeX 宏支持范围说明页；手写识别标注「需云端」的架构边界

## 优化处方（验收标准）

1. **光标处插入**：模板/符号点击插入 textarea 当前光标位置，插入后光标停在插入段末尾。→ **验收：光标置于 `E=mc^2` 中间时点「分式」，`\frac{a}{b}` 出现在该位置而非文末**
2. **符号面板**：预览区上方加「希腊/关系符/箭头」三组符号条，点击即插。→ **验收：不看文档仅点符号条可拼出 α+β≥γ 的合法公式**
3. **导出选项**：新增字号（1x/2x/3x）与底色（透明/白/主题色）选择。→ **验收：选白底 2x 导出的 PNG 在深色 PPT 中完整可读且尺寸翻倍**
4. **错误回退**：语法出错时展示错误信息+「恢复上次正确公式」按钮。→ **验收：改坏公式出现红字提示，点击回退后预览恢复且 textarea 内容同步**
5. **草稿保存**：tex 实时写入 localStorage。→ **验收：输入复杂公式刷新页面内容完整**
