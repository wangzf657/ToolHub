## 结论与优先级

**需拓展 + 交互优化** · P1

判据：相比网易房贷缺"三通道+双方式"核心决策面（子功能缺失明显）；空值零结果属可用性瑕疵（未到不可读硬伤）。

## 扣分点明细

1. 【可用性】空值零结果误导：房价留空时 compute 无守卫直接以 Number('')=0 进 loanPayment（registry.ts:77-80），结果区显示"每月月供 ¥0.00/首付 ¥0.00"——CalcTool 的"请先完整填写"引导只在结果含 NaN/Infinity 时触发（CalcTool.vue:25-28），0 是合法值拦不住
2. 【功能】只有等额本息：无双方式对比、无商贷/公积金/组合贷三通道（registry.ts:76-90 单一调用 loanPayment）——国内购房决策第一问"公积金还是商贷、本息还是本金"本工具一概答不了
3. 【功能】无还款明细/图表/提前还款（家族共性，loan-calculator 同病）；站内 amortization-calculator（registry.ts:1189）已有双通道逐月明细+Excel 导出，本工具零互链
4. 【交互】首付只能填比例不能填金额、无"按月供承受力反推可买总价"入口；无 LPR/固定利率选择提示
5. 【灵魂】家族共性：无输入记忆（CalcTool.vue:10 values 无持久化）、结果行不可单值复制（CalcTool.vue:55-66）
6. 【美观】宽屏表单拉散 + 右侧 300px TrustSidebar 压缩面板（共性-根因 3）
7. 【可用性】输入无范围校验：首付比例填 200% 或负数时贷款额为负仍照算，月供显示负数人民币（registry.ts:78-79 无 clamp；CalcFieldInput.vue:44-46 支持 min/max 但 fields 未配置）
8. 【口径】"购房总支出"= 首付 + 本息合计（registry.ts:86）不含契税/中介/装修，label 无 hint 说明口径，易被当成"买房全部要花的钱"

## 行业对标与差距

- **网易房贷计算器**：商贷/公积金/组合贷三通道、等额本息/本金双对比、按总价或总价反推双入口。差距：**贷款方式覆盖代差**——对方回答"该怎么贷"，本工具只回答"等额本息月供多少"。
- **Calculator.net Mortgage**：含税费保险摊销、年度余额图表、可调年数滑杆。差距：时间维度与持有成本全景。
- 借鉴优先级：**组合贷/双方式对比 > 空值守卫 > 明细表互链（透传参数）> 首付金额/比例双输入**。

## 可拓展性

- 短期（1 周）：空值守卫返回引导行；结果区底部互链 amortization-calculator 并透传参数
- 中期（1 月）：等额本金切换+双方案对比行（月供差/利息差）；公积金利率字段与组合贷两列月供
- 远期：与 loan/amortization 合并为"购房贷款工作台"（方案对比 + 明细 + 图表），calcDef 保留快算入口

## 优化处方（验收标准）

1. **空值守卫**：price 为空时 compute 返回"请填写房价"引导行。→ **验收：清空房价后 300ms 内结果区显示引导行，不再出现 ¥0.00**
2. **双还款方式**：加"等额本息 | 等额本金"切换并排显示月供与利息差。→ **验收：切换后利息总额行更新且等额本金利息 < 等额本息**
3. **组合贷**：新增公积金贷款额与利率（默认 3.1%）字段，输出商贷/公积金两列月供与合计。→ **验收：公积金额填 60 万时合计月供 = 两部分之和，且与网易房贷同参数误差 <1 元**
4. **明细互链**：结果区底部"查看逐期还款计划表 →"跳 /t/amortization-calculator。→ **验收：点击后明细页自动带入等额的金额/利率/年限**
5. **家族处方**：结果单值复制 + localStorage 输入记忆（见 loan-calculator.md 处方 2/5）。→ **验收：刷新后字段保留；复制"每月月供"得纯数字**
