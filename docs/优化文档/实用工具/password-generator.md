## 结论与优先级

**交互优化 + 需拓展** · P1

判据：可用性无硬伤；与 Bitwarden 的差距集中在 passphrase 模式与熵值/破解时长叙事，均为纯前端可实现。

## 扣分点明细

1. 【灵魂】熵值计算了却不展示：strengthOf 的 bits 只用于分档（PasswordGenerator.vue:39-51），卡片上看不到"128 bits""破解需 X 年"——1Password/Bitwarden 生成器的核心说服力恰在此；同站检测工具已有现成 crackTime 口径（PasswordStrength.vue:33-49）却未复用
2. 【功能】无 passphrase（词组密码）模式：Bitwarden 标杆为"密码/词组"双模式，人类可记的高熵方案完全缺失
3. 【功能】未保证所选字符类至少出现一次：四类全选时仍可能整串无数字，而强度条按"实际出现类别"回算（:41-44）恰好掩盖这一波动
4. 【交互】滑杆/复选框变更不触发重生成（无 watch），调整选项后看到的是旧参数结果，易误复制旧密码
5. 【交互】无"复制全部/导出 txt"：批量 50 条（初始化账号场景）只能逐条点小图标
6. 【功能】无历史记录与"已用/弃用"标记，刷新即丢，生成过的密码不可追溯
7. 【安全-轻微】取字符用 `pool[n % pool.length]`（textEngine.ts:692）存在模偏差，未做拒绝采样——同站 random-number 已实现拒绝采样（RandomNumber.vue:37-41），家族口径不一
8. 【交互】与 password-strength-checker 无组件内互链；相关工具按注册表顺序取前 3（ToolPage.vue:44-46），"生成↔检测"场景配对不保证

## 行业对标与差距

- **Bitwarden Password Generator**：密码/词组双 Tab、每类最少配额、生成即显强度与"1 万亿年才破解"级文案、清空历史。差距：熵叙事与 passphrase 是代差（纯前端可补）。
- **1Password**：滑杆拖动实时刷新、易混字符分组说明、"避免歧义"默认勾选。差距：实时刷新与默认值取向。
- 借鉴优先级：熵值+破解时长展示 > passphrase 模式 > 选项实时重生成 > 每类配额 > 复制全部。

## 可拓展性

- 短期（1 周）：卡片补 bits 数值并复用 checker 的 crackTime 文案；选项变更防抖自动重生成；加"复制全部/导出 txt"
- 中期（1 月）：passphrase 模式（内置词表，注意懒加载纪律与体积）；每类至少一个的采样保证；最近 20 条历史（localStorage）
- 远期：与 password-strength-checker 合并为"密码工作台"（生成侧↔检测侧同屏互证，一页覆盖注册改密场景）

## 优化处方（验收标准）

1. 每条密码展示"熵 X bits · 暴力破解约 Y"（口径与 checker 一致）。→ **验收：生成 16 位四类全选密码，卡片可见 ≥100 bits 与"亿年"级时长文案**
2. 新增词组模式：3-6 词 + 连字符/数字可选。→ **验收：切换模式可生成"云舟-泽川-42"类词组，熵按词表大小回算并显示**
3. 选项联动重生成：滑杆/勾选变更 200ms 内自动刷新列表（防抖）。→ **验收：拖动长度滑杆时列表密码长度实时等于新值**
4. 每类配额：勾选的字符类各自至少出现 1 次。→ **验收：长度 4、四类全选连续生成 100 次，无"缺类"样本**
5. 列表头部加"复制全部 | 导出 txt"。→ **验收：50 条一键复制后粘贴进编辑器为 50 行**
