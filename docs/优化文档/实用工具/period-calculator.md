## 扣分点明细

1. 【可用性-硬伤（隐私）】单条历史无法删除：历史管理区 `v-if="history.length > 1"`（:130）——只保存过 1 次的用户看不到任何删除入口，经期日期这类隐私数据在 localStorage `toolhub-period`（:20）中无 UI 出口可清除；隐私工具应永远提供"一键抹除全部本机数据"
2. 【可用性】无"今天"标记：日历网格（:151-156）不区分过去/未来，也不高亮当天——用户最想问"今天是安全期吗"，却要在网格里手工对位；过去日期还与未来同色回溯渲染（:68 `diffDays >= 0` 起全部着色），"预测"与"回溯"视觉无区分
3. 【交互】月数标签与渲染不符：选"1 个月"实际渲染 2 个完整月网格（:59 `totalMonths = monthsAhead + 1`），选"3 个月"渲染 4 个——口径未在 UI 说明
4. 【功能】无平均周期学习：历史存了最近 12 条（:33）却只用于回填（:36-40），不计算近几次周期均值/方差来修正预测——对标 Flo/美柚的核心智能（周期越记越准）缺失，当前预测精度永远等于手填值
5. 【功能】无记录纵深：无流量/症状/情绪记录（Flo 标配），工具定位为一次性推算器而非追踪器——desc 只承诺推算（registry.ts:1184），属定位选择而非缺陷，但记录深度决定回访价值
6. 【可用性】免责声明位置弱：医学免责为结果区底部 12px muted 小字（:158），健康类工具的免责应前置到输入区（对照 finance 工具的"计算口径"前置规约，AGENTS.md 联动点）
7. 【美观】星期起始列为周日（:149），中文月历惯例多为周一起始，且无配置；安全期格子无底色仅灰字（:185），图例绿色与其呈现不一致（图例有色块、日历里安全期无色块）
8. 【交互】跨时区隐患：列偏移用 `new Date(c.date).getDay()`（:152）按 UTC 解析 ISO 串，在负时区会偏移一天——目标用户为东八区无感，列为工程卫生项

## 行业对标与差距

- **Flo**：今日状态大卡（"今天是经期第 3 天"）+周期洞察（平均周期自动学习）+症状追踪+预测准确度提示。差距：**"今天"状态卡**是零成本高价值的第一步；智能学习是纵深差距。
- **美柚**：经期的中文语义化表达（安全期四段分色+易孕窗口标注）、社区与科普内容。差距：科普缺席——"安全期不安全"的医学提示本工具仅一句免责，节奏法失败率（典型使用 ~24%）未告知，口径严谨性可再进一步。
- 借鉴优先级：今日标记+状态卡 > 一键抹除数据 > 单条记录可删 > 周期均值学习 > 免责前置 > 节奏法可靠性科普。

## 可拓展性

- 短期（1 周）：今日格子加描边+图例；历史区改为始终显示（含单条）+「清除全部记录」红色按钮（带确认）；免责声明复制到输入区顶部；月数标签注明"含当月"
- 中期（1 月）：末次月经+历史自动求近 6 次平均周期并提示"是否采用均值 X 天"；"今天状态卡"（第 X 天/经期中/易孕窗口）；周一起始切换
- 远期：症状/流量记录（纯本地）；预测可信度分级（周期方差大时自动降级提示"偏差可能较大"）；与 lunar-calendar 组成日历中台

## 优化处方（验收标准）

1. 隐私出口：历史管理区始终显示（去掉 length>1 条件），底部加「清除全部记录」按钮（二次确认后清空 localStorage `toolhub-period`）。→ **验收：仅 1 条历史时可见删除按钮；点击清除后刷新页面历史为空**
2. 今日定位：日历中当天格子加 accent 描边+角标"今"，结果区顶部加状态行"今天是周期第 X 天（经期第 Y 天/安全期）"。→ **验收：打开页面无需滚动即可读到今天的状态一行**
3. 免责前置：输入区顶部显示医学免责条（内容含"安全期避孕失败率高，不作为避孕依据"），结果区底部保留现有 hint。→ **验收：填写参数前免责已可见**
4. 周期学习：保存第 3 条及以上历史时，计算相邻两次 start 差值的均值，toast 提示"检测到近 N 次平均周期 X 天，是否采用"。→ **验收：录入 3 条不同周期记录后提示出现，采纳后周期输入框更新为均值**
5. 月数口径：预测月数选项改为"当月+1/3/6 个月"或渲染数与标签一致。→ **验收：选"1 个月"时网格恰好 1 个整月（若首月为部分月则注明）**
