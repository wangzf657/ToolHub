## 结论与优先级

**交互优化 + 需拓展** · P1（详情可达性是单点改造快赢；深度属性是拓展主轴）

判据：可用性 12/20——详情卡位置造成"点了没反应"错觉（点击后视口内无变化）；与 ptable.com 的属性深度差距明确可追。

## 扣分点明细

1. 【可用性】详情卡位于表格 DOM 之后（`PeriodicTable.vue:86`），1366×768 下 10 行网格约 500px 高+图例区，点击元素后详情落在折叠线以下且无 scrollIntoView——用户首次点击普遍误以为"点了没反应"
2. 【功能】属性深度不足：无电负性/原子半径/密度/电子构型（逐层仅逗号串 :45）/丰度/ discovered-by，熔沸点仅开尔文无 °C 换算开关（:46-47）——化学作业场景查"水银多少度融化"要自己换算
3. 【功能】无温度-相态交互：ptable.com 的滑杆看"室温下谁是液体"是周期表最经典的探索交互，本工具类别着色静态呈现
4. 【可用性】搜索无命中引导：多命中时仅 dim 其余（:36,:74），无"第一个命中高亮/自动弹出详情"，搜"Fe"后仍需目视扫全表
5. 【注册】needModel: true（`registry.ts:1618`）导致 ToolPage 显示"部分能力首次使用需下载模型"徽章（`ToolPage.vue:67`）——15KB 本地 JSON 谈不上"模型"，措辞吓退用户（同类：university/garbage/poetry 均过度声明，家族共性）
6. 【移动端】min-width 700px 横滚（:101）+ 详情卡同样要横滚寻找，小屏体验断裂（附加维度重扣）
7. 【交互】图例筛选与搜索不可组合提示：`dim` 只降低透明度（:106），命中元素在角落时仍需全表目视寻找，无"点击 dim 区外元素自动聚焦"的辅助动线

## 行业对标与差距

- **ptable.com**：温度滑杆全表相态实时变色（固态蓝/液态绿/气态红）、电子轨道逐层可视化、属性全量（20+ 项）、点击元素全屏详情页。差距：**相态探索与属性深度**——对方让周期表"可实验"，本工具只让它"可查阅"。
- **RSC 周期表**：每元素视频/用途/来源科普、按发现年代轴筛选。差距：科普内容层（属内容运营型差距，纯前端可实现）。
- 借鉴优先级：**详情弹层/scrollIntoView > 摄氏度换算 > 相态滑杆 > 电子构型逐层 > 属性扩充**。

## 可拓展性

- 短期（1 周）：点击元素详情改为表格右下固定面板或弹层（大屏），移动端 scrollIntoView；熔沸点加 °C 双单位显示
- 中期（1 月）：数据补电负性/半径/密度字段（公开数据静态可得）；相态滑杆（按温度判断三态着色，熔沸点数据已在）；搜索命中自动弹出第一个详情
- 远期：电子轨道 SVG 逐层动画；元素详情页化（/t/periodic-table?el=Fe 深链）；与 mol-viewer 类工具联动

## 优化处方（验收标准）

1. **详情可达**：桌面端详情卡固定在图例右侧同屏渲染（max-width 420px 已有，改挂载位置）；移动端点击后 `scrollIntoView({behavior:'smooth'})`。→ **验收：1366×768 点击任意元素详情卡完整出现在首屏内；390×844 点击后 600ms 内详情滚动进入视口**
2. **双温标**：熔沸点显示"3380 K（3107 °C）"双值。→ **验收：铁的熔点同时给出开尔文与摄氏度，null 值显示"—"**
3. **相态滑杆**：顶部温度滑杆 -200~6000 K，随温度把元素着色为固/液/气三态色。→ **验收：25°C（298 K）下汞/溴显示液态色，100°C 时水位置（若收录）或 373K 附近碱金属铯呈现液态色，拖动即时全表刷新**
4. **搜索引导**：搜索命中 ≥1 时自动弹出第一个命中元素的详情并高亮。→ **验收：输入"Fe"后铁的详情卡自动打开，其余元素 dim**
5. **needModel 语义修正**：注册表移除 periodic/university/garbage/poetry 四项的 needModel 标记（本地 JSON 不属"模型"）。→ **验收：四工具页不再出现"首次使用需下载模型"徽章，首屏 hint 保留体积说明**

> 对齐目标备注：ptable.com 的相态滑杆与轨道可视化均为纯前端可实现（熔沸点数据已在 periodic.json 内），不存在架构天花板；处方 1~3 一周内可全部落地。
