## 扣分点明细

1. 【功能-核心差距】无自定义字符集输入框：hex（0-9a-f）、base64、base58 等密钥常用字母表必须借助外部映射；RandomKeygen 的价值即在"按密钥类型出格式"，本工具只有四类勾选（RandomString.vue:55-59）
2. 【功能】无前缀/分组模板：API key 场景常见 `sk-live-xxxx`、UUID 式 8-4-4-4-12 分组、每 4 字符加连字符，均不支持
3. 【交互】初始空态不自动生成（挂载时无 generate() 调用），首屏结果框空置，与同家族 password-generator（:36）、random-number（:53）、dice-roller（:67）行为不一致
4. 【安全-轻微】取字符用模索引（textEngine.ts:692）未做拒绝采样，与 random-number 的拒绝采样口径（RandomNumber.vue:37-41）不一致；密钥场景虽影响可忽略，但"密码学随机源"的宣传下应统一实现
5. 【功能】无唯一性保证与碰撞提示：500 条短串（如 6 位）可能重复，无检测无标注
6. 【可用性】无逐条复制：结果只有整窗复制，取第 N 条需手工选取（对比 UuidGenerator.vue:83 支持点击单行复制）
7. 【功能】无熵/组合数展示：length=24、池 62 时约 142 bits 的说服力信息完全缺席
8. 【交互】与 password-generator 边界模糊：同引擎同选项，用户分不清该用哪个；页内无"需要人类可记密码？去密码生成器"的场景分流

## 行业对标与差距

- **RandomKeygen**：按密钥类型（WPA 密钥/512 位加密密钥/CodeIgniter 密钥等）一键出对应格式与长度，即点即换。差距：**"场景化预设"代差**——对方按用途组织，本工具按字符类组织。
- **CyberChef**：随机字节→hex/base64/自定义字母表的管道化生成。差距：字母表自由度（本工具连一个自定义输入框都没有）。
- 借鉴优先级：自定义字符集 > 场景预设（hex 32/64、API key 模板）> 逐条复制 > 唯一性校验 > 熵展示。

## 可拓展性

- 短期（1 周）：挂载自动生成一次；结果区加逐行点击复制；加 hex-only 与 base64 两个预设按钮
- 中期（1 月）：自定义字符集输入框（实时校验重复字符）；前缀/分隔符模板（`{prefix}-{token}`、4-4 分组）；唯一性检测与熵值展示
- 远期：与 password-generator 划清边界——本工具定位"机器 token"（hex/base64/模板），密码工具定位"人类凭证"（含 passphrase），互链分流

## 优化处方（验收标准）

1. 自定义字符集：新增输入框，勾选项与自定义内容合并为最终池。→ **验收：输入 0-9a-f 并只勾数字，生成 32 位串与 `/^[0-9a-f]{32}$/` 全量匹配**
2. 场景预设按钮：hex-32 / hex-64 / API-Key（sk- 前缀+48 位）。→ **验收：一键点 API-Key 后每行为 `sk-` 开头 51 字符**
3. 挂载自动生成：进入页面即出 10 条默认结果。→ **验收：首屏 ResultBox 不为空，点"批量生成"前即可复制**
4. 逐行复制：每行 hover 出现复制图标，点击复制该条。→ **验收：点击第 3 行后剪贴板内容等于第 3 行文本**
5. 唯一性与熵：底部显示"池 X · 每条约 Y bits · 本批无重复"。→ **验收：500×24 默认配置下显示"无重复"且 Y≈143**
