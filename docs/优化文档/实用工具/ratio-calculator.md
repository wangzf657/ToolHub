## 结论与优先级

**交互优化 + 需拓展** · P1

判据：可用性无硬伤；但"任意三值求第四值"这一品类核心能力只实现一半（不能解 A/B），对照 Calculator.net 功能差距直接。

## 扣分点明细

1. 【功能-主短板】只能解 C 或 D：compute 固定要求 a、b 非零必填（registry.ts:860,864-865），"2:? = 6:9"（求 B）无法求解——Calculator.net 的核心即任意三格求第四格
2. 【可用性】A/B 为 0 静默无解：填 a=0、b=5、c=3 时化简与求解行都不出现，只显示"填写 A、B 以及 C 或 D 之一"（registry.ts:860,866），未说明"比例两项均需非零"的数学边界
3. 【功能】四数全填无判定：a/b/c/d 都填时只输出化简行（registry.ts:859-862），不回答"C:D 与 A:B 是否相等、误差多少"——验证配比恰是该工具的另一主场景
4. 【功能】无多组连比与场景预设：a:b:c 三项连比、黄金比例 1:1.618、摄影 3:2 等常用比无一键入口（registry.ts:848-853）
5. 【灵魂-口径缺失】无 note：化简用 gcd 取整（registry.ts:861 Math.round）、求解公式 D=b×c/a（registry.ts:864）未披露，AGENTS.md 口径要求未满足
6. 【交互】结果不可复制：化简比"3:4"与求解值不能一键复制（CalcTool.vue:55-66 无复制按钮），配方/施工场景需手抄
7. 【灵魂】四个裸字母 label 无单位语义：用户填"图上 3cm : 实际 9km"这类带单位比例尺时无任何引导（label 仅 A/B/C/D，registry.ts:849-853）

## 行业对标与差距

- **Calculator.net Ratio Calculator**：`a:b = c:x` 双行四格，任意填三格自动解第四格 + 化简 + 小数比值同显。差距：**未知数位置自由度（本工具固定锁死 A/B）**。
- **Omnicalculator Ratio Calculator**：支持三分连比化简与按总数分配（如按 2:3:5 分 100 元）。差距：连比与分配场景为零。
- 借鉴优先级：任意三值求第四值 > 等式判定行 > 比例分配（按比例分总额）> note 口径。

## 可拓展性

- 短期（1 周）：A 或 B 可求解（B=a×d/c、A=b×c/d 等三组合）；A/B 为 0 时明确提示"比例项不能为 0"；补 note
- 中期（1 月）：四数全填输出"相等/不相等（比值差 x）"判定；按比例分配总额行；化简结果复制按钮
- 远期：与 aspect-ratio-calculator、fraction-calculator（registry.ts:1437）组成"比例与分数计算组"，共享化简引擎

## 优化处方（验收标准）

1. **任意三值求第四值**：四格中任填三格（含 A 或 B 留空）即解出空格。→ **验收：A 留空、B=3、C=6、D=9 时输出"A（2:3 = 6:9）= 2"**
2. **零值提示**：A 或 B 为 0 时显示"比例项不能为 0"。→ **验收：a=0 时出现明确提示行而非仅有引导语**
3. **等式判定**：四数全填时输出"6:9 与 2:3 相等（比值均为 0.6667）"或"不相等（差 0.05）"。→ **验收：2:3 与 6:10 时判定行显示"不相等"并给出差值**
4. **补口径 note**：注明"D = B×C÷A、C = A×D÷B，化简按整数 gcd"。→ **验收：页面底部出现口径行**
5. **单位引导**：label 下方 hint 示例"如地图比例：图上距离 : 实际距离"。→ **验收：空态时可见示例 hint 文案**
6. **按比例分配**：新增"总额"可选字段，按 A:B 分配。→ **验收：2:3 分配 100 元时输出"40.00 / 60.00"且两份之和恰为 100**
