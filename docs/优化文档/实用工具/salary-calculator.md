## 扣分点明细

1. 【可用性-假结果】金额为空开屏五行 ¥0.00：compute 无守卫，Number('')=0 正常参与除法（registry.ts:775-789），NaN 守卫（CalcTool.vue:25-28）不触发；对照 sales-tax-calculator 的 `if (!amt) return [提示]`（registry.ts:699）
2. 【功能-口径】无 21.75 法定月计薪天数口径：月工时按 (hours×days×52)/12≈173.33h（registry.ts:780），而国内法定月计薪天数 (365−104)/12=21.75 天（174h，日薪=月薪/21.75 是加班费/缺勤扣款法定口径）；note（registry.ts:791）只讲 52 周不提 21.75，两口径结果差约 0.4%，涉及加班费计算时会有争议
3. 【功能】无税后联动：站内个税计算器（registry.ts:197）与五险一金计算器（registry.ts:242）都在同分类，本工具五行全为毛口径且零互链，"年薪 30 万到手多少"这一最高频问题断链
4. 【交互】无工作制度预设：双休（5 天）/大小周/单休（6 天）是国内薪酬讨论高频词，每周天数靠手填数字（registry.ts:773）
5. 【灵魂-假零值】开屏主结果"月薪 ¥0.00"（primary 行，registry.ts:787）观感差，无预填示例
6. 【交互】结果不可复制单值：offer 比较要抄时薪数字进表格，无复制按钮（家族共性，CalcTool.vue:55-66）
7. 【功能】无年薪含年终奖口径：13 薪/年终奖几个月是国内 offer 标配字段，Calculator.net 支持奖金并入年薪折算

## 行业对标与差距

- **Calculator.net Salary Calculator**：五周期换算 + 每周小时/每年工作日自定义 + 税前税后同屏 + 假期折算。差距：**税后维度与工作日历口径**。
- **个税管家/51 个税**：税前→五险一金→个税→到手四段式明细，支持年终奖单独计税。差距：到手金额计算链路，本工具停在第一段。
- 借鉴优先级：空态守卫 > 21.75 口径切换 > 与个税/五险一金工具互链（透传年薪）> 双休/单休预设 > 年终奖字段。

## 可拓展性

- 短期（1 周）：空态守卫 + 预填示例（如 15000/月）；"双休/大小周/单休"快捷 chip
- 中期（1 月）：21.75 法定口径切换；底部互链个税/五险一金计算器并透传月薪
- 远期：与 income-tax-calculator、social-insurance-calculator 组成"薪酬工作台"（毛→金→税→手四段流水）

## 优化处方（验收标准）

1. **空态守卫**：金额为空时结果区显示"请输入金额"。→ **验收：打开页面无 ¥0.00 行，输入金额后五行结果出现**
2. **口径切换**：新增"月计薪口径"select（52 周/月÷12 与 21.75 天法定）。→ **验收：年薪 120000、8h×5 天时 21.75 口径时薪 ≈57.47，52 周口径 ≈57.69，note 说明两者适用场景**
3. **工作制预设**：天数字段旁加"双休/大小周/单休"chip。→ **验收：点击"单休"后 days=6 且周薪/年薪立即更新**
4. **互链透传**：结果区底部"算税后到手 →"跳 /t/income-tax-calculator 并携带月薪。→ **验收：改金额后点击链接，个税页自动带入同一金额**
5. **单值复制**：时薪/月薪行 hover 复制纯数字。→ **验收：复制"时薪"行后剪贴板为形如 57.69 的数字**
6. **年终奖口径**：新增"年终奖（月数）"字段，并入年薪折算。→ **验收：月薪 15000、年终奖 2 个月时年薪显示 210000 并在 note 说明含奖金口径**
