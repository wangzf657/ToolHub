## 结论与优先级

**交互优化** · P1

判据：无硬伤；核心缺口是键盘/手势换色通道与修复模式的预期管理（含安全警示），均属单点改造。

## 扣分点明细

1. 【可用性】换色无键盘通道：keydown 未监听（全文无 keydown），验机时手持设备/坐在屏前最自然的「空格/方向键下一色」不可用，只能伸手指点击屏幕中心（每次点击都会短暂出现光标干扰观察）
2. 【灵魂-预期管理】闪烁修复模式定位含糊：60ms 纯色/黑交替（:29-33）对真坏点（晶体管损坏）无任何物理修复作用，对「亚像素卡死」的证据级有效案例也集中在 JScreenFix 式长时间随机噪点激励——本模式既无时长控制（无 5/10 分钟计时）也无成功率说明，「安慰剂」属性应诚实标注而非仅一句括号小字（:63）
3. 【安全】无光敏性癫痫警示：60ms（约 8Hz）全屏红黑高频闪烁落在光敏敏感频段，行业惯例（游戏/闪光内容）应前置警示——现文案只谈坏点不谈人（:73）
4. 【功能】无检测记录回路：逐色检查时发现可疑点无法标记（哪个色哪个位置），多色往返时全靠人脑记忆；deadpixeltest 类标杆提供网格参考图辅助定位
5. 【交互】无自动循环：无「每色 5 秒自动轮播」选项——挂机验机（边看别的事边等）场景缺席，timer 机制已有（:30）仅用于闪烁
6. 【可用性】退出路径单一：覆盖层上只能 Esc 或先点「退出测试」按钮（:59-61），自定义色下 Esc 焦点在 fullscreen API 的兼容性未处理，部分浏览器 Esc 不退出覆盖层
7. 【交互】idx=-1 魔法值：「显示自定义色」直接置 idx=-1（:68）后「切换纯色」按钮行为变成 -1→0，状态机不透明
8. 【功能】无灰阶/渐变测试：背光不均（banding）与 mura 检测需要渐变图，纯色谱覆盖不了；「屏幕检测」desc 涵盖面与实际能力有落差

## 行业对标与差距

- **deadpixeltest.org**：全屏纯色+方向键/空格切换、点击定位标记、灰阶渐变图、多语言指引。差距：**操作通道与检测图型代差**——对方让「手不离键完成全谱检查」，本工具手必须离开键盘。
- **JScreenFix**：随机噪点像素激励 10 分钟+官方自述「多数情况有效、少数无法修复」的诚实预期管理。差距：修复功能的**证据披露**——对方把局限写明白，本工具的「闪烁修复」更像一键开关（:63）。
- 借鉴优先级：键盘换色 > 修复模式时长+成功率说明+癫痫警示 > 网格定位图 > 自动轮播 > 灰阶渐变。

## 可拓展性

- 短期（1 周）：keydown 空格/方向键换色；修复模式前置癫痫警示文案；提示文字隐藏开关
- 中期（1 月）：自动轮播（间隔可选）；修复模式 5/10 分钟计时与结束提示；灰阶渐变图测试
- 远期：坏点标记模式（点击标记+色卡回顾清单）；与屏幕录制类工具组成「显示质量工具集」

## 优化处方（验收标准）

1. **键盘换色**：覆盖层监听 Space/→ 下一色、← 上一色。→ **验收：全屏后不触碰鼠标连按空格可循环 6 色+自定义**
2. **修复模式预期管理**：开启时展示说明卡——「对真坏点无效；亚像素卡死可尝试持续 5~10 分钟；光敏敏感者勿用」，附可选时长。→ **验收：勾选闪烁修复后出现说明卡与「5 分钟」倒计时选项**
3. **自动轮播**：新增「自动循环（每色 N 秒）」开关。→ **验收：设 5 秒后无需操作自动遍历 7 色并循环**
4. **网格定位图**：新增「网格参考」色卡（暗色细网格叠加）。→ **验收：开启后可见 8×8 暗格线辅助定位可疑点坐标**
5. **提示隐藏**：覆盖层提示文字可点击隐藏（3 秒无操作自动隐藏）。→ **验收：验屏拍照时提示文字不残留画面**
