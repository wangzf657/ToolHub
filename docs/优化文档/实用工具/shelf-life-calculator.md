## 结论与优先级

**需拓展 + 交互优化** · P1（批量清单是把"算术玩具"变成"管货工具"的分水岭）

判据：单件计算正确且口径严谨（54 分中段）；但真实需求是"一批东西哪些先过期"，无批量/无清单使实用价值封顶，临期阈值口径未披露影响可信度。

## 扣分点明细

1. 【功能-核心差距】无批量模式：真实场景是清理冰箱/药柜一次查十几件（StillTasty/FoodKeeper 均以"查一件→存清单"为动线），本工具一次只算一件（registry.ts:1903-1910 三字段），算第二件覆盖第一件——calcDef 单表单形态锁死了高频用法
2. 【可用性-口径黑盒】临期阈值写死 7 天：`days <= 7`（registry.ts:1924）且 note 未披露——商超临界食品惯例按总保质期分档（≥1 年→到期前 45 天等），一罐保质期 18 个月的奶粉"剩 10 天"在本工具不算临期，与用户直觉冲突且无解释
3. 【功能】无"以某日为准"：状态按 Date.now() 硬算（registry.ts:1923），无法回答"下周三这瓶酸奶还能带去野餐吗"；且结果不随日期自动刷新（watch 仅监听输入，CalcTool.vue:40），挂后台过夜后"剩余 N 天"静默过期
4. 【功能】无开封后（PAO）模式：化妆品"开封后 12M"是另一套计时（note :1930 只口头提醒），无"开封日 + 开封后月数"第二表单——对标品类工具的标准第二模式
5. 【交互】无清单保存：算过的到期日无法留存对照（CalcTool 全家无 localStorage，家族共性；UTL-6b 内容资产不持久化家族）——"管货"工具连清单都没有
6. 【交互】生产日期无快捷键：date input 手选，无"今天/昨天/一周前"快捷 chips（刚买的东西 90% 在近几天）——录入摩擦集中在最高频路径
7. 【美观】状态语义色未用足：过期/临期/正常三态仅靠 ⚠ 前缀与 primary 切换（registry.ts:1924-1927），CalcTool 行底色体系（CalcTool.vue:88-94）支持 accent 但无 danger/中性双色——扫一眼分不清绿（安全）红（过期）
8. 【实用价值】商品库缺席：StillTasty 按"品类 → 常见保质期"反查（用户不知道保质期时可查），本工具必须已知保质期——"这瓶酱开了多久了"的无标注场景接不住

## 行业对标与差距

- **StillTasty**：按品类给常见保质期（冷藏/冷冻/开封后三维）、"仍然能吃吗"问答动线、个人清单。差距：**数据库反查与清单动线代差**——对方回答"这东西能放多久、还能吃吗"，本工具只做用户给的算术。
- **USDA FoodKeeper**：官方品类保质期 + 提醒（日历集成，云端能力天花板，纯前端可做 localStorage 清单替代）。差距：品类库与提醒。
- 借鉴优先级：批量清单（本地保存 + 按到期日排序标色）> 临期阈值披露并分档 > "以某日为准"输入 > 开封后模式 > 品类保质期速查（与 food-calorie-lookup 同型可复用其数据架构）。

## 可拓展性

- 短期（1 周）：临期阈值分档（按总保质期 ≥1 年→45 天 / ≥6 月→20 天 / 其余→7 天）并写入 note；生产日期加"今天/昨天"chips；状态行语义色（过期红/临期黄/正常中性）
- 中期（1 月）：批量清单模式（商品名 + 生产日期 + 保质期多行，localStorage 存，按剩余天数升序）；"以某日为准"可选输入；开封后计时第二 Tab
- 远期：品类常见保质期速查库（复用 food-calorie-lookup 的数据集架构与 DatasetLookup 模式）；清单导出/分享文本

## 优化处方（验收标准）

1. **临期分档**：阈值按总保质期分档（≥365 天→45 天；≥180 天→20 天；其余→7 天），note 同步披露口径。→ **验收：生产 2025-11-01 + 保质期 18 个月，今日剩余约 40 天时状态行显示"⚠ 临期"**
2. **批量清单**：新增清单模式：多行（名称/生产日期/保质期/单位），自动按剩余天数升序并标色。→ **验收：录入 5 件后清单按最早到期排序，过期行红底、临期行黄底，刷新后清单保留**
3. **以某日为准**：可选"评估日期"字段（默认今天），状态按评估日计算。→ **验收：评估日填下周三后，"剩余 N 天"按该日重算且原实时结果不受影响**
4. **快捷日期**：生产日期旁加"今天/昨天/一周前"三个 chips。→ **验收：点"昨天"后日期输入自动填入昨日且结果即时刷新**
5. **状态语义色**：过期行 danger 红、临期行警示黄、正常行中性。→ **验收：三态在同一清单中并排时颜色一眼可辨，暗色模式下对比度仍达标**
