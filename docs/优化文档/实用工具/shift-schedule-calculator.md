## 结论与优先级

**需拓展 + 交互优化** · P1（月历排班表视图是从"计算器"升级为"工具"的关键一步）

判据：单日查询引擎正确但交付形态过薄（对比标杆的月历交付属子功能悬殊，需拓展）；0 起锚点序号与班制覆盖不足是明显交互摩擦。

## 扣分点明细

1. 【功能-核心差距】无月历排班表：查询任意日期只能改 query 反复提交（registry.ts:1944-1954 单日 compute），而"这个月我哪天休息"才是倒班者的原始问题——calendar-printer 已有现成月历网格组件可参照（CalendarPrinter.vue:101-111），按班次填色即得，属引擎已支持、UI 未搭桥
2. 【功能-核心差距】班制覆盖窄且不可自定义：SHIFT_MODELS 仅三种（utilLife.ts:67-71），缺"做二休二""上四休三""五班二倒"等民间高频循环；无自定义周期编辑器（输入班次序列 + 天数即可生成 model，数据结构 ShiftModel 已支持任意 cycle）
3. 【可用性-个性】0 起锚点序号反人性：字段标签"锚点当天是第几班（从 0 开始）"（registry.ts:1941）要求工人理解程序员口径再口算"白班是第 0 班"——应为班次名下拉（早/中/夜），引擎 anchorIdx 由映射转换
4. 【灵魂】结果缺倒班语境：只回"那天上什么班 + 周期位置"（registry.ts:1950-1954），无"距下个轮休还有 N 天""本月共 X 个夜班"——夜班数量直接影响倒班者健康关注，是品类标杆 App 的标配统计
5. 【美观】班次无色彩语义：白班/中班/夜班/轮休四种结果同款卡行样式（CalcTool.vue:55-66 无状态色机制），月历化后更需要四色图例——当前扫一眼认不出"夜班"
6. 【功能】无导出/分享：结果无法存图/打印/ics 订阅（家人对班表的高频需求），月历视图落地后应连带 PNG/打印（calendar-printer 的 print CSS 与 toPng 可直接复用）
7. 【交互-家族共性】无输入记忆：锚点日期+班次是每人固定参数，CalcTool.vue:10-40 无 localStorage——每个倒班者都是"一次性配置、长期查询"的用户，刷新即丢配置最伤
8. 【实用价值】节假日不叠加：note 口头免责（registry.ts:1956），推算结果不标"该班次恰逢法定节假日/调休"——chinaCalendar 数据源已在站内（calendar-printer 同源），叠加显示成本极低

## 行业对标与差距

- **When I Work（云 SaaS）**：整月排班网格、拖拽换班、班次色彩、推送提醒（协作/推送属云端天花板，不要求对齐）。差距：**月历交付与色彩体系**——其"个人月视图"形态纯前端完全可做。
- **站内 calendar-printer（calendar-printer.md，63 分）**：月历网格 + 农历节假日标注 + 打印导出全家桶——本工具的月历化改造应直接复用其渲染与导出件，两工具形成"日历家族"。
- 借鉴优先级：月历排班视图（复用 calendar-printer 网格）> 锚点改班次名下拉 > 班次四色语义 > 自定义周期编辑器 > 月度夜班统计。

## 可拓展性

- 短期（1 周）：锚点字段改班次名下拉（映射 anchorIdx）；结果区加"距下个轮休/下个早班 N 天"一行；锚点+班制 localStorage 记忆
- 中期（1 月）：月历视图（按 query 月渲染整月格子，班次四色填充，复用 CalendarPrinter 网格与导出）；自定义周期编辑器（班次名+天数序列）；节假日角标叠加
- 远期：多班组对比（家人/工友班表叠加对照）；ics 导出订阅（云日历打通）；与 calendar-printer/lunar-calendar 组"日历家族"共享 chinaCalendar 数据层

## 优化处方（验收标准）

1. **锚点班次下拉**："第几班"数字输入改为班次名 select（随班制动态生成选项）。→ **验收：三班倒时下拉为早班/中班/夜班，选"夜班"后查询结果与手填 anchorIdx=2 完全一致**
2. **月历视图**：query 日期旁加"查看整月"切换，渲染当月网格按班次四色填充（早/中/夜/休）。→ **验收：整月视图与单日查询同日结果一致（抽查 3 天），夜班格一眼可辨**
3. **班次语义色**：四种班次配固定色（白/蓝/深蓝/绿灰）并带图例，暗色模式校验。→ **验收：月历视图底部有图例，暗色模式下四色对比度均达 4.5:1**
4. **自定义班制**：加"自定义循环"入口，输入逗号分隔序列（如"白,白,休,夜,夜,休"）。→ **验收：自定义"白,白,休"后锚点推算与手动数日一致，周期位置显示 3 天循环**
5. **月度统计**：月历视图底部汇总行"本月早班 X / 中班 X / 夜班 X / 休 X"。→ **验收：汇总数与格子逐个清点一致；切换班制后数字即时更新**
