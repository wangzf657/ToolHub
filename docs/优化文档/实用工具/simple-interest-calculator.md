## 结论与优先级

**交互优化 + 需拓展** · P1

判据：开屏显示 ¥0.00 假结果属可用性明显缺陷（非硬伤但误导）；功能相对 Calculator.net 与站内复利兄弟均有代差。

## 扣分点明细

1. 【可用性-假结果】空态静默零值：p/r/t 任一为空时 Number('')=0 参与乘法，开屏即显示"利息 ¥0.00 / 到期本息和 ¥0.00 / 年利息 ¥0.00"（registry.ts:749-757 无守卫；对照 loan-calculator registry.ts:52 的 `if (!v.p || !v.r || !v.y) return [提示]` 写法）
2. 【功能】期限仅支持年（registry.ts:747），无天/月单位切换——消费贷、押金类短息场景需用户自己换算小数年，易错
3. 【功能】无反求方向：已知目标利息求利率/期限不可行（Calculator.net 支持四变量互求），金融比价场景常见
4. 【功能】无单利 vs 复利对比：站内 compound-interest-calculator（registry.ts:630-656）就在隔壁却零互链，"同样条件下差多少"是理解单利概念的最好教具，双双缺席
5. 【交互】三字段全空且无预填示例（registry.ts:745-747 default ''），开屏第一印象是 ¥0.00 而非可改的示例（对照 mortgage-calculator 默认利率 4.2/年限 30，registry.ts:73-74）
6. 【灵魂】无计息天数口径（实际天数/360 或 365，银行按日计息的标准问题），note（registry.ts:758）只给公式不涉口径
7. 【交互】结果不可复制、无历史记录（家族共性）

## 行业对标与差距

- **Calculator.net Simple Interest Calculator**：本金/利率/期限/利息四变量任意三求一 + 期限按年月日混合输入 + 与复利结果同屏对比。差距：**反求与单位维度**。
- **站内复利计算器**：复利频率选择、每月追加、近三年余额明细（registry.ts:637-655）。差距：本工具连输入单位 flexibility 都没有，形成"复利比单利好用"的站内倒挂。
- 借鉴优先级：期限单位切换（年/月/天）> 空态守卫 > 单利复利对比行 > 反求利率 > 与复利工具互链。

## 可拓展性

- 短期（1 周）：空态守卫引导行 + 预填示例（10000/3.5%/1）；期限加"年/月/天"select
- 中期（1 月）：反求利率/期限方向；"同条件复利对照"行（复利频率=年）+ 与 compound-interest-calculator 互链
- 远期：与 compound-interest-calculator 合并为"利息计算工作台"（单利/复利/定投三 Tab）

## 优化处方（验收标准）

1. **空态守卫**：任一字段为空时结果区显示"请填写本金、年利率与期限"。→ **验收：打开页面或清空任一字段时无 ¥0.00 结果行**
2. **期限单位**：新增单位 select（年/月/天），月按 /12、天按 /365 折算。→ **验收：本金 10000、利率 3%、期限 3 月时利息 75.00**
3. **预填示例**：默认 10000/3.5/1。→ **验收：打开页面即见三行非零结果，可在此基础上改数**
4. **单利复利对照**：结果区加一行"同条件按年复利：¥xxx（差 ¥xx）"。→ **验收：期限 > 1 年时复利对照值大于单利利息**
5. **互链**：结果区底部加"算复利 →"跳 /t/compound-interest-calculator。→ **验收：点击后目标页打开且本金利率字段语义一致**
6. **结果单值复制**：利息/到期本息和行 hover 显示复制按钮。→ **验收：复制"利息"行后剪贴板为形如 350.00 的纯数字（无 ¥ 前缀）**
