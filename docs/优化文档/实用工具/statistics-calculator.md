## 扣分点明细

1. 【功能】只有样本口径：方差/标准差固定 ÷(n−1)（registry.ts:1229），无样本/总体切换，仅 note 披露（:1250）——全检数据（总体口径）与抽样数据共用同一答案，2,4,4,4,5,5,7,9 两口径 σ 分别约 2.138 与 2.0，质检验收单上差异敏感
2. 【功能】无加权平均：学分绩点、金额加权场景缺权重维度；average-calculator.md 扣分点 4 已登记该需求，本工具作为其合并去处同样没有，合并后需求仍悬空
3. 【功能】分位数仅 Q1/Q3（registry.ts:1235-1236）：无自定义百分位（运营岗 P90/P95 常用）；取整插值法与 Excel PERCENTILE 结果可能不同，note 披露了方法但无方法选择
4. 【可用性】结果行不可单值复制：均值/标准差无法一键进 Excel/聊天（CalcTool.vue:55-66，家族共性；loan-calculator.md 扣分点 3 同源）
5. 【可用性】长结果行可读性：极差行拼"a − b = c"、Q1/Q3 行拼三值加 IQR 括号（registry.ts:1244-1245），窄屏换行后"哪个数对应哪个指标"需要回数
6. 【灵魂】无解析回显：粘贴混入文字（如"88, abc, 92"）被静默过滤（registry.ts:1222），"已解析 N 个、丢弃 M 个"提示行缺失，用户不知数据被洗掉了
7. 【灵魂】无数据可视化：排序条/箱线图缺失——Calculator.net 逐值回显、Omnicalculator 即时直方图，本工具八行文字没有分布"形状感"
8. 【交互】无输入记忆与历史：QC 复测每日粘新数据，昨日结果无法回看（CalcTool.vue:10 无 localStorage，家族共性）

## 行业对标与差距

- **Calculator.net Mean/Median/Mode Calculator**：样本/总体单选、逐值回显表、全套描述统计一表出。差距：口径切换与数据回显。
- **Omnicalculator Descriptive Statistics**：直方图/箱线随输入即时绘制、异常值提示。差距：可视化代差——对方给"分布形状"，本工具只给"六个数字"。
- 借鉴优先级：样本/总体切换 > 单值复制 > 加权平均 > 解析回显 > 箱线图。

## 可拓展性

- 短期（1 周）：样本/总体切换；结果行单值复制；解析回显行（与 average-calculator.md 处方 3 同口径）
- 中期（1 月）：加权平均（数值+权重两栏）；自定义百分位输入；与 average-calculator 互链或 301 合并落地
- 远期："统计工作台"（描述统计+加权+直方图/箱线图），吸纳 average-calculator 全部场景，成为站内统计唯一入口

## 优化处方（验收标准）

1. **样本/总体切换**：结果区上方加口径 Tab，默认样本口径。→ **验收：数据 2,4,4,4,5,5,7,9 时样本 σ≈2.138、总体 σ=2.0，切换 300ms 内生效且 note 同步更新口径说明**
2. **单值复制**：结果行 hover 出现复制按钮。→ **验收：点击均值行复制按钮后剪贴板为形如 5 的纯数字**
3. **解析回显**：结果区首行显示"已解析 N 个数字（丢弃 M 个无法识别项）"。→ **验收：粘贴"88, abc, 92"时显示已解析 2、丢弃 1**
4. **承接合并**：落实 average-calculator.md 处方 5。→ **验收：/t/average-calculator 页面底部可见指向本工具的入口（或该 slug 301），两页口径说明一致**
5. **加权平均**：新增可选"权重列表（与数据一一对应）"字段。→ **验收：数值 80/90 配权重 3/2 时加权均值显示 84**
