## 结论与优先级

**交互优化 + 需拓展** · P1

判据：无硬伤；方向键导航与铅笔标记是数独交互的及格线（数独 App 标配），计时/存档/打印属拓展主线。

## 扣分点明细

1. 【交互-核心】无方向键跨格导航：81 个独立 input 仅靠 Tab/鼠标点选（模板 :111-120 无 keydown 处理），填盘效率低——数独 App 的「方向键移动 + 数字键直填」是肌肉记忆级标配
2. 【功能-核心差距】无铅笔标记：候选数批注（角标小数字）是中高难度的必需功能（sudoku.com 标配），当前只有单值格子，硬难度靠脑内记忆候选数劝退普通玩家
3. 【可用性】已给数与手填数无视觉区分：cellCls 输出 given 类（:83）但样式表无 .given 规则（:126-138 只有 conflict/br-left/br-top）——死类；「检查哪步填错了」与「还原题目」都无从下手
4. 【灵魂·疑似功能缺陷】生成同步阻塞无反馈：newGame 里 busy.value=true 与同帧 false（:22-34），spinner 永不可能渲染；hard 挖洞卡顿时页面僵住无任何提示
5. 【功能】无计时与统计：无局时、无难度胜场记录——数独产品的留存钩子完全缺失
6. 【功能】无存档/打印：刷新丢局；「出题给孩子」无打印布局（棋盘+可选答案页），utilExt 引擎完全支持
7. 【交互】撤销缺失：填错只能改写或清空整局（clearAll :62-68 清全部），无单步回退（Ctrl+Z）
8. 【交互】提示策略朴素：hint 填「第一个与解不同的格」（:52 findIndex 扫描序），不挑「候选数最少」的最优提示格，也不解释为什么——教学价值打折；完成时仅一行绿字（:122）无庆祝（对比 lucky-wheel 的仪式感标准）

## 行业对标与差距

- **sudoku.com**：方向键/触屏双导航、铅笔标记一键切换、错误计数与高亮、计时+每日挑战、提示带解释、完成庆祝动画。差距：**游戏感代差**——对方是「玩得下去的数独」，本工具是「算得对的数独」。
- **sudoku-solver.com**：题目粘贴导入（81 字符串）、逐步求解动画（展示每步推理）、候选数可视化。差距：求解器的**教学演示**能力——对方展示「怎么解」，本工具只给「解是什么」。
- 借鉴优先级：方向键导航 > 铅笔标记 > 计时+存档 > given/手填视觉分层 > 逐步推理提示。

## 可拓展性

- 短期（1 周）：棋盘 keydown 方向键移动焦点（2×9 宫界跳跃）；given 加底色区分；生成改 setTimeout 异步化让 spinner 真实显示
- 中期（1 月）：铅笔标记模式（空格切换候选角标）；计时器+最佳记录 localStorage；81 字符串题目导入导出
- 远期：打印布局（题目页+答案页）；hint 解释文案（「第 5 宫只剩候选 7」推理说明）；完成庆祝动画（与站内互动类共享）

## 优化处方（验收标准）

1. **方向键导航**：棋盘监听 ArrowKeys 移动焦点，跨宫界正常跳转。→ **验收：方向键从任意格四向移动均可达目标格，Tab 顺序不受影响**
2. **视觉分层**：已给数用深色粗体+浅灰底，手填数用 accent 色。→ **验收：新局中题目数字与手填数字一眼可辨；打印对比度下均可读**
3. **生成异步化**：newGame 用 setTimeout 包裹，hard 难度生成期间 spinner 真实可见。→ **验收：点「新一局（困难）」后按钮出现旋转图标直至棋盘刷新**
4. **铅笔标记**：数字键长按/右键进入标记态，角标显示候选小数字。→ **验收：标记 2/5/7 后格子角标显示三个候选，填入正式值后标记清除**
5. **计时与存档**：开始计时+局时显示，棋盘状态 localStorage 自动存档。→ **验收：中途刷新后棋盘与计时（暂停态）完整恢复，「新一局」才重置**
