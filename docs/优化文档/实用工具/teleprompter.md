## 结论与优先级

**交互优化** · P1（含 2 处疑似功能缺陷，建议优先修复验证）

判据：可用性 8/20 因「暂停即从头」与「快捷键承诺落空」触发明显摩擦红线；滚动中调速缺失是与标杆的核心差距。

## 扣分点明细

1. 【可用性-硬伤·疑似 Bug】"暂停/继续"实为"暂停/从头"：控制条播放钮 `live ? exit() : start()`（:82），而 start() 无条件 `pos = 0`（:19）——口播录到一半停顿一下再继续，台词直接跳回开头，对提词器是致命行为
2. 【可用性-疑似 Bug】快捷键不存在：hint 写明「空格暂停/继续，Esc 退出」（:75），但脚本区（:1-61）无任何 keydown/addEventListener——空格按了没反应，Esc 仅在原生全屏时由浏览器退出全屏，覆盖层 `.stage.full`（:96）仍固定在页面上
3. 【交互-核心】滚动中不可调速：speed 只能改面板里的数字输入框（:69），全屏播放中控制条无 +/- 调速钮——真人语速与预设速度不匹配是提词器使用中最高频的调整动作，标杆产品均支持播放中滑杆调速
4. 【功能】文稿不保存：textarea 内容纯内存（:6），刷新/误退即丢口播稿——这是用户精心准备的资产，最低应 localStorage 自动存草稿；无多稿管理
5. 【灵魂】无朗读时长估算：按字数/速度可估算滚动总时长并显示「约 X 分 X 秒」，帮口播者对齐视频时长；当前要靠人肉掐表
6. 【交互】参数输入原始：速度/字号用 number 输入框（:69-71）而非滑杆，移动端调参要唤键盘；无记忆（速度/字号每次回默认 60/26）
7. 【美观】中文台词用 mono 等宽字体（:79）观感生硬，且无行间距/文字阴影（户外强光下对比度）选项
8. 【功能】无倒计时与遥控：无 3-2-1 起播倒计时（开录对齐）；无"手机当遥控"（另一设备扫码控制翻页/调速），录制者本人无法隔空操作

## 行业对标与差距

- **提词全能王/大提词器**：悬浮窗模式（录制 App 时浮在相机上方）、播放中调速滑杆、语速跟读（PromptSmart 语音识别驱动，属云端/本地模型架构天花板）、多稿库+文件夹、遥控器模式（另一台手机扫码控制）。差距：**播放中调速与草稿持久是单点可追差距**；悬浮窗与语音跟随超出纯页面能力（天花板），可诚实标注并给出"分屏+全屏"最佳实践。
- **PromptSmart**：语音跟随逐句滚动（说到哪滚到哪）。差距：属架构天花板，纯前端可用 Web Speech API 做试验性跟读（Chrome 可用），中期可探。
- 借鉴优先级：修复继续=从头 Bug > 空格/Esc 快捷键兑现 > 播放中调速钮 > 草稿自动保存 > 朗读时长估算。

## 可拓展性

- 短期（1 周）：start() 增加"从暂停处继续"分支（pos 归零仅在非暂停态）；window keydown 绑定 Space/Esc 兑现 hint；speed/fontSize 写 localStorage 记忆；文稿 500ms 防抖自动存草稿
- 中期（1 月）：控制条加 ±20px/s 调速钮与进度微调（上/下一段）；字数→时长估算文案；滑杆替换数字框；多稿管理（命名+列表+切换）
- 远期：Web Speech API 试验性"语音跟随"模式（识别到句尾关键词再滚下一句，注明浏览器兼容边界）；URL 参数分享文稿（encode 进 hash，隐私文案声明）

## 优化处方（验收标准）

1. 修复继续逻辑：暂停（live=false）后点播放从当前 pos 继续滚动，仅首次启动或手动「重头」按钮才归零。→ **验收：滚动至 30% 处暂停→继续，画面从暂停处续滚不回顶；「重头」按钮单击后回到 0%**
2. 快捷键兑现：window 级 keydown，Space 切换播放/暂停（preventDefault 防滚屏）、Esc 退出覆盖层（含原生全屏时先退全屏再退覆盖层）。→ **验收：全屏中按空格立即暂停且页面不滚动，按 Esc 一次回到编辑面板**
3. 播放中调速：控制条增加「− / +」按钮（步进 20px/s），当前速度以数字显示在两钮间。→ **验收：全屏滚动中连按 + 两次，速度数字变 100 且目测明显加快，无需退出全屏**
4. 草稿持久：textarea input 防抖 500ms 写 localStorage（key 前缀 toolhub），进页恢复上次文稿并显示「已恢复上次草稿」hint。→ **验收：粘贴 500 字稿后刷新，内容原样恢复**
5. 时长估算：面板实时显示「全文约 X 字 · 预计滚动 X 分 X 秒」（按当前速度与行高计算）。→ **验收：调整速度滑杆，估算秒数同步变化且与实际滚动计时误差 ≤10%**
