## 结论与优先级

**交互优化 + 需拓展** · P1

判据：效果闭环成立但能力面窄（文字样式/抠图交互/输出分辨率三项均低于纯前端可达水平），对照 Photopea 的自由蒙版有明显拓展空间。

## 扣分点明细

1. 【可用性-个性】导出分辨率锁死 720×480：原图统一 cover 到舞台尺寸（:33-40），3000px 原图经 toBlob 输出仍是 720×480（:87-96），海报成品放大即糊
2. 【可用性-个性】舞台固定 4:3 强制裁切（W=720/H=480，:22-23）：3:4 竖幅人像上下被裁约 28%——"人像海报"主场景首图先被砍
3. 【功能-个性】抠图种子固定取四角 5×5 平均色（utilExt.ts:38-48）：主体贴边或背景多色时无法手动点选种子，只能调全局容差盲试；且无"只看前景/背景"蒙版预览辅助判断
4. 【功能】文字锁死白色 Arial Black 900、只能居中（:62-68）：无颜色/字体/字距/描边，浅色背景上白字直接不可读
5. 【功能-疑似问题】多行拆分 `split('\n')`（:66）永远不触发——输入是单行 `<input>`（:107），多行文案是死代码
6. 【交互】字号 number 输入 `@change` 才生效（:109），输入过程不实时预览；文字与容差改动全靠 compose 重绘无过渡
7. 【灵魂】无示例图一键填充、无"按住看原图"对比（家族共性缺失项）、无歌词海报/签名档等模板预设
8. 【美观-共性】面板 top≈250px 装饰税（共性-根因1）、右侧 300px TrustSidebar 压缩面板（共性-根因3）

## 行业对标与差距

- **Canva**（云）：文字效果模板一键出图、字库/字距/描边全可调、成品任意分辨率下载。差距：文字样式能力与输出质量代差。
- **Photopea**（纯前端）：任意分辨率、图层蒙版手动修边缘、文字自由定位。差距：纯色键自动化 vs 手动可控性——本工具应补"自动优先+手动兜底"。
- 借鉴优先级：手动种子点+蒙版预览 > 原分辨率导出 > 文字样式（颜色/描边）> 适配原图比例 > 模板预设。

## 可拓展性

- 短期（1 周）：原分辨率导出（文字按缩放系数换算重绘）；文字颜色与描边选项；蒙版预览开关
- 中期（1 月）：画布点击选种子色重抠；文字拖拽定位；输出比例预设（小红书 3:4、朋友圈 1:1）
- 远期：人像分割模型（transformers.js，标 needModel）替代色键，主体不贴边也能抠；多文字图层堆叠

## 优化处方（验收标准）

1. **原分辨率导出**：合成移到原图尺寸画布，文字字号按 scale 系数换算。→ **验收：3000×2000 输入导出 PNG 为 3000×2000 且文字边缘无锯齿**
2. **舞台适配原图比例**：舞台按原图宽高比（上限边 1280px）而非固定 4:3。→ **验收：3:4 竖图载入后舞台为 3:4，人物头顶与下巴不被裁**
3. **蒙版预览**：新增"只看前景 / 只看背景"切换。→ **验收：抠图瑕疵可直接目视，配合容差滑杆 3 次内调准**
4. **文字样式**：颜色选择器 + 可选描边/阴影。→ **验收：浅色天空背景选黑字或白字加描边后，文字区对比度 ≥4.5:1**
5. **点击种子抠图**：Alt+点击画布任一点以该处颜色为种子重新 flood-fill。→ **验收：上天空下墙面的双色背景图分别点选后，两侧背景均被抠除**
