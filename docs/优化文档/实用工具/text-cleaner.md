## 结论与优先级

**交互优化 + 需拓展** · P1

判据：可用性 12/20 无硬伤；但"不可见字符"是 textcleaner.net 的头号卖点而本工具缺席，属明确功能拓展项。

## 扣分点明细

1. 【功能-拓展】不可见字符清理缺席：spaces 只处理 `[ \t\f\v]`（textExt.ts:55），零宽空格 \u200B、BOM \uFEFF、NBSP \u00A0、软连字符 \u00AD 全部保留——网页/Word/Excel 复制文本最常见的隐形污染恰是这些，粘进表单/数据库后引发"看起来一样却匹配不上"的经典事故；textcleaner.net 把 invisible characters 列为核心功能
2. 【功能】无预设组合：九项按需手勾，"净化网页复制"（HTML+Emoji+压缩空格+去空行）这一最高频组合需点 4 个开关，无一键预设
3. 【可用性】清理前后无对比：无 diff 高亮、无"删除了 X 个空格/Y 个空行/Z 个隐形字符"统计——清洗了多少全靠输出字符计数反推（TextTool.vue:124）
4. 【可用性】选项条不折叠（TextTool.vue:67 `.text-opts` 家族共性）叠加九开关后选项区约占 90px，44px 输入区与 180px 输出区（M-06）挤压主工作区
5. 【功能】标点正则不含 NBSP 与中文省略号外的部分符号（textExt.ts:41 PUNCT_RE 未列 ‥﹍等冷门符），"去除标点"承诺有小概率漏网且无口径披露
6. 【交互】无"全选/全不选"快捷，九项逐个点；默认只有压缩空格开启（registry.ts:1506 default:true），首用者粘贴带 HTML 的文本若无检查会得到半清洗结果
7. 【灵魂】无清洗历史/无前后快照切换（对照 textcleaner.net 的 before/after 并排视图），误清洗后想撤销只能重粘原文
8. 【家族共性】无快捷键、swap 仅"用输出替换输入"单向（TextTool.vue:117），无真正前后互换

## 行业对标与差距

- **textcleaner.net**：不可见字符清理（核心卖点）、清理前后字数/词数/行数统计并排展示、常见预设。差距：**隐形战场缺席**——可见字符九项做得齐，不可见字符零覆盖。
- **站内 word-counter**：统计维度齐全（M-09）。差距：清洗完想验证效果需跳转另一个工具手动粘贴，两页零联动。
- 借鉴优先级：**不可见字符开关（含计数回显）> 净化网页预设 > 前后统计对比 > 选项分组折叠**。

## 可拓展性

- 短期（1 周）：加"不可见字符"开关（\u200B\uFEFF\u00A0\u00AD 正则）＋"删除了 N 个隐形字符"回显；预设按钮组（净化网页/纯文本化/去格式）
- 中期（1 月）：清理统计面板（各项删除计数）；与 word-counter 联动（清洗后一键送统计）；选项分组（空白类/字符类/内容类）
- 远期：清洗规则自定义链（拖拽排序的规则管道，向 CyberChef 配方靠拢）；规则保存为个人预设（localStorage）

## 优化处方（验收标准）

1. **不可见字符开关**：新增第 10 项"清除不可见字符"，覆盖 \u200B/\uFEFF/\u00A0/\u00AD。→ **验收：粘贴含 ZWSP 的文本开启后输出无隐形字符（正则 \u200B 校验为 0 命中），摘要行显示"清除隐形字符 N 个"**
2. **净化网页预设**：选项条上方加"净化网页复制"按钮，一键勾选 HTML+Emoji+压缩空格+去空行。→ **验收：点击后四开关状态同步，粘贴带标签文本 300ms 内出清洗结果**
3. **前后统计对比**：结果首行显示"清理前 N 字符 → 清理后 M 字符（删除 K 项）"。→ **验收：K = N−M 且与各分组删除计数之和一致**
4. **选项分组**：九+1 开关按"空白/字符/内容"三组折叠呈现，默认展开空白组。→ **验收：1366×768 下选项区 ≤56px 高，输入区上移无遮挡**
5. **口径披露**：note 行说明标点正则覆盖范围与执行顺序。→ **验收：工具页可见"先去 HTML 再去标点，执行顺序不可调"说明**
