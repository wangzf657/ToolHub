## 结论与优先级

**交互优化 + 需拓展** · P1（计数诚实化是快赢；详情字段与收藏对比决定它能否进志愿场景）

判据：可用性 11/20——"命中 300 所"的假计数属信息可信性问题；功能 10/20 相对掌上高考缺口悬殊。

## 扣分点明细

1. 【可用性-假计数】`results` 先 `filter` 后 `slice(0,300)`（`UniversityLookup.vue:31-36`），hint 直接展示截断后的 `results.length`（:54）——不筛选时显示"命中 300 所"而库里实际 855 所，且无任何"已截断"披露；筛选后命中 <300 时计数恰好正确，用户无从察觉
2. 【可用性】卡片网格 `max-height:520px` 钉死（:75，共性-根因 2），855 所全量浏览需在小窗滚 ~4.5 屏
3. 【功能】卡片不可点击、无详情：无院校代码/批次/办学层次/隶属/官网/所在地市，与 desc 承诺的"高考"关键词（registry.ts:1630 keywords 含'高考'）支撑的场景需求断裂
4. 【功能】数据面仅公办本科 855 所（universities.json 实测），民办/专科/中外合作全缺——desc"公办本科名单"披露诚实但"全国高校查询"的工具名承诺了更大的面
5. 【交互】无收藏对比圈：家长核心动作"圈出候选 6 所再比较"无任何支撑，复制校名是唯一留存
6. 【注册】needModel: true（registry.ts:1632）→ ToolPage 显示"需下载模型"徽章（`ToolPage.vue:67`），65KB 名单谈不上模型，措辞过重（家族共性：periodic/garbage/poetry 同病）
7. 【功能】筛选维度缺"所在地市/隶属（部属/省属）/层次（一本/二本）"：跨省择校与"只看部属"是名单题的常见变体，现仅省份一级粒度

## 行业对标与差距

- **掌上高考**：院校详情页（代码/批次/分数线/专业组/排名）、收藏对比、按分荐校。差距：**详情纵深与决策工具链**——对方是决策系统，本工具是名录。
- **阳光高考平台**：官方名单权威口径、招生章程原文、公示专栏。差距：权威附件与公示层（内容运营型，纯前端可外链）。
- 借鉴优先级：**计数诚实化 > 卡片详情（代码/层次/官网）> 收藏对比圈 > 数据面扩容（民办/专科）**。

## 可拓展性

- 短期（1 周）：计数文案改"命中 X 所（显示前 300）"；needModel 降级为普通数据提示措辞；985/211/双一流徽章分色
- 中期（1 月）：数据补层次/隶属/所在地市/官网字段并做点击详情展开；收藏圈（localStorage）+并排对比视图
- 远期：扩容民办/专科/中外合作名录（静态 JSON 可承载）；与站内分数类计算工具（grade/gpa）组"学业工作台"交叉入口

## 优化处方（验收标准）

1. **计数诚实化**：hint 区分总命中与展示数："命中 855 所 · 显示前 300（可继续筛选缩小范围）"。→ **验收：不筛选时显示命中 855；任选一省后计数与卡片数一致（<300 时不再出现截断字样）**
2. **卡片详情**：点击卡片展开（或右侧弹层）显示层次/隶属/地市/官网链接。→ **验收：点"郑州大学"可见双一流/省部合建/河南郑州/官网域名四项信息，卡片高亮保持选中态**
3. **收藏对比圈**：卡片星标收藏，页首"已选 N 所"条展开并排对比表（省份/层次/标签三列）。→ **验收：收藏 3 所后对比表横向并排 3 列，刷新不丢，可一键清空**
4. **弹性网格**：`.grid` max-height 改 `calc(100vh - 360px)` 下限 480px。→ **验收：1366×768 全量浏览时网格占满主视口，无需页面级滚动**
5. **筛选维度扩容**：数据补 city/subordinate 字段后筛选行加"隶属"下拉（部属/省属）。→ **验收：选"部属"后剩余卡片均含"部属"属性，与省份筛选叠加结果正确**

> 备注：本工具为自研筛选壳（非 DatasetLookup），处方 1/4 的计数与高度改造需在本组件内独立落地，不随 DatasetLookup 壳层处方勾销；needModel 过度声明见 periodic-table 处方 5 一并处理。
