## 结论与优先级

**需拓展 + 交互优化** · P1

判据：相比 uuidgenerator.net 的版本与格式矩阵差距悬殊（需拓展）；格式勾选重生成属明显交互缺陷。

## 扣分点明细

1. 【交互-个性缺陷】格式开关重掷骰子：勾选"大写/去掉连字符"触发 generate（UuidGenerator.vue:62-63）生成**全新随机值**，已复制的旧 UUID 与列表失联——formatOne（:18-22）本是纯格式化函数，正确做法是对当前批次重排版；对比 uuidgenerator.net 格式选项只改呈现
2. 【功能-核心差距】仅 v4：无 v7（时间有序，数据库索引友好，2024 起 RFC 9562 标准代际）、无 v1（MAC/时间）、无 v3/v5（命名空间哈希，幂等生成）、无 nil UUID——desc 只承诺 v4 属诚实，但作为"UUID 生成器"品类缺半个工具箱
3. 【可用性】列表 max-height:420px 钉死（:115-120），属家族共性-根因 2；1000 条批量场景在 768 高视口约 1/3 小窗内滚动，无弹性高度无虚拟滚动
4. 【功能】无格式变体快捷出口：花括号 {uuid}、URN urn:uuid:、紧凑无连字符、上引号等一键切换缺失；无"复制为 JSON 数组/SQL IN 子句"场景化格式——uuidgenerator.net 的 braces/uppercase 批量选项是标配
5. 【功能】无校验/解析反向模式：粘贴 UUID 验证合法性、解析版本位与 variant 位（第 13 位 hex 即版本）是同类站点的另一半入口
6. 【交互】无前缀/分隔符：某些主键场景需要 `id_xxxx` 或 CSV/TSV 分隔输出，只能导出后手改
7. 【灵魂】无确定性模式（v5 由 namespace+name 派生即天然确定）与历史记录；"生成类灵魂三件套"（确定性复现/历史/格式变体切换）仅命中挂载自动生成一项
8. 【可用性】1000 条 DOM 全量渲染（v-for :83-88 无虚拟化），低端机滚动卡顿
9. 【交互】重新生成/改数量无确认机制：误触"生成"即丢整批 1000 条（若已部分复制使用则无法找回）

## 行业对标与差距

- **uuidgenerator.net**：多版本入口（v1/v4 等）+ 批量生成页（数量/大写/花括号/去连字符格式选项，只改呈现不重掷）+ 单条校验页。差距：**版本矩阵与"格式≠重生成"的语义代差**。
- 借鉴优先级：格式选项与生成分离 > v7/v5 版本 > 场景化复制（JSON/SQL）> 校验解析模式 > 弹性高度/虚拟滚动。

## 可拓展性

- 短期（1 周）：勾选格式改为对当前批次重新 formatOne（不重生成）；列表改弹性高度 `calc(100vh - 320px)` 下限 480px；加花括号/URN 格式 chips
- 中期（1 月）：v7（时间戳+随机位，crypto 实现 ~30 行）与 v5（namespace+name，crypto.subtle SHA-1 可实现）版本选择；校验模式 Tab（粘贴解析版本/格式/合法性）；复制为 JSON 数组/SQL 子句
- 远期：与 random-string-generator 合并"ID 中心"（UUID 各代/hex token/nanoid 同屏），统一 crypto 采样口径与批量导出

## 优化处方（验收标准）

1. 格式与生成分离：勾选大写/去连字符仅对现有列表重排版，数值不变。→ **验收：生成 5 条→复制第 1 条→勾选大写→列表第 1 条与剪贴板内容一致（仅大小写/连字符差异）**
2. 版本选择：新增 v4/v7 下拉。→ **验收：v7 输出首 8 位随生成时间单调递增（同毫秒内除外），版本位字符为"7"**
3. 场景化复制：加"复制为 JSON 数组/SQL IN(...)"按钮。→ **验收：5 条 UUID 一键得到合法 `["…","…"]` 数组与 `('…','…')` 子句文本**
4. 校验模式：粘贴框解析版本位/variant/是否合法。→ **验收：输入 v4 与 v7 各一条，显示"版本 4/版本 7"；输入畸形串显示"不合法"**
5. 弹性高度：列表 `calc(100vh - 320px)`、下限 480px。→ **验收：1366×768 下同屏可见 ≥12 行，页面滚动与列表滚动分离**
