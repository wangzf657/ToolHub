## 扣分点明细

1. 【可用性】下载按钮出屏（推算）：预览区固定高 382px（WifiQr.vue:38 canvas 320 / :113 min-height 220 实际被内容撑高 / :118 stage padding 10×2 / :109 area padding 20×2），叠加表单区与面板 top 250px（共性-根因 1），"下载 PNG"推算 top≈824——**1366×768 下不可见**，且 Cookie 横幅首访将进一步遮挡（M-01 同款）；比 M-10（qr-code-generator top=710 贴底缘）更严重
2. 【功能】无 SVG 导出与复制图片：只有 PNG 下载（:97-101），印立牌需矢量、贴聊天需剪贴板粘贴，两路全缺
3. 【功能】无宾客卡/立牌模板：草料 WiFi 模板可打"WiFi 名称+密码+二维码"一张 A6 卡，本工具只出裸码——差一个模板层（纯前端 canvas 排版可实现）
4. 【交互】无扫码自检：生成后无法确认"扫出来真的能连"（站内 /t/qr-code-scanner 无互链）；家族共性——兄弟工具分裂互链靠 ToolPage 注册表前 3（ToolPage.vue:44-46）基本不可达
5. 【灵魂】密码框永远明文（:81 无 type="password" 切换）：会议室/前台场景旁人易见密码
6. 【功能】纠错锁定 M 无说明（:38 errorCorrection: 'M'）：WiFi 码不打 Logo 用 M 合理，但用户不知道为何不可调
7. 【可用性】WEP 选项无风险提示（:73"旧设备"字样太弱）：WEP 已是不安全协议，应提示"仅兼容旧设备，建议升级路由器"
8. 【功能】SSID/密码长度无前置校验提示：SSID 最长 32 字节、WPA 密码 8~63 字符，超限只在生成异常时 toast（:45-46），不告诉用户"密码至少 8 位"这类可自查规则

## 行业对标与差距

- **草料二维码 WiFi 模板**：生成+宾客卡排版打印+扫码统计+活码。差距：宾客卡模板与扫码统计缺失（统计需后端属天花板；卡片模板纯前端 canvas 排版可实现，是真差距）。
- **QRCode Monkey**：颜色/边距/Logo 自定义。差距：本工具连颜色都不可调（引擎 QrOptions 支持 dark/light :3-9 未暴露，与 qr-code-generator 同款"引擎能力被藏一半"）。
- 借鉴优先级：**下载操作前置+复制图片 > 宾客卡模板 > 扫码自检互链 > 颜色暴露 > 密码明文切换**。

## 优化处方（验收标准）

1. **下载操作前置**：预览卡片内部底部紧贴"下载 PNG | 复制图片"操作行。→ **验收：1366×768 下按钮 top<680 完整可见，Cookie 横幅展开时仍不被遮挡；390×844 下首屏内可点**
2. **复制图片**：canvas.toBlob + navigator.clipboard.write。→ **验收：点击后可直接在微信聊天框 Ctrl+V 粘贴出二维码**
3. **宾客立牌卡模板**：可选"带说明卡"导出（WiFi 名称/加密/密码明文+二维码，A6 比例）。→ **验收：导出 PNG 含全部信息且二维码可扫，打印后客人无需任何口头说明即可连网**
4. **扫码自检**：生成后调用 scanQr 反扫画布，显示"已验证可识别"。→ **验收：默认生成即自动验证通过；人为输入含 `;` 的 SSID 验证仍通过（转义正确性回归测试）**
5. **密码可见性切换**：眼睛图标切换明文/密文，默认密文。→ **验收：默认输入显示圆点，切换后明文可见**
6. **长度前置校验**：密码 <8 字符（WPA）时即时提示"WPA 密码至少 8 位"，不生成无效码。→ **验收：输入 5 位密码时预览区出现规则提示且下载按钮不可用**
