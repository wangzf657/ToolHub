## 扣分点明细

1. 【灵魂】无猜谜模式：谜底默认可见（subs 为空时 head 只显谜面，但展开即见谜底 `XiehouyuLookup.vue:11`），"先猜后揭晓"的娱乐闭环缺失——对标站的核心玩法
2. 【功能】无主题分类（动物/人物/名著/谐音/数字），1.4 万条只能靠关键词捞，浏览型需求无入口（数据集无 cat 字段，需补充标注）
3. 【可用性】列表 `max-height:480px` 钉高（`DatasetLookup.vue:122`，共性-根因 2）+ 空查询只显前 50 条且文案"最近 50 条"（:99）名不副实（JSON 无时序概念，家族共性）
4. 【可用性】宽泛词命中截断 80 条，计数展示为截断数（:56,:99 家族共性）
5. 【交互】无收藏/最近查询：写作素材收集场景需要"攒一筐歇后语"的能力，复制全文是唯一留存手段
6. 【功能】谐音类歇后语（如"外甥打灯笼——照旧/舅"）无谐音标注，谜底双关意味丢失，解释力打折
7. 【交互】搜索框无回车直达第一条命中（`DatasetLookup.vue:89` 无 keyup 处理），写作场景"边写边查"的节奏被鼠标移动打断

## 行业对标与差距

- **歇后语大全类聚合站**：按首字笔画/拼音音序浏览、分类专题导航、猜谜答题模式、每日一条推送。差距：**浏览组织与玩法**——对方是"逛"，本工具只支持"查"。
- **汉典歇后语**：单条页面含出处考据与关联条目。差距：条目仅 r/a 两字段，无解释无出处，深度查询仍需跳外部。
- 借鉴优先级：**猜谜遮挡模式 > 分类导航 > 收藏夹 > 谐音标注**。

## 可拓展性

- 短期（1 周）：谜底遮挡开关（默认遮挡，点击卡片揭晓）；计数文案诚实化
- 中期（1 月）：为数据集补 cat/谐音标注字段（脚本预标注人工抽查）；分类 Tab 导航；收藏本与复制多选打包
- 远期：接龙式"歇后语接龙"游戏化（谜面接谜底关键词）；与成语词典共享收藏/历史基建

## 优化处方（验收标准）

1. **猜谜模式**：列表卡片谜底区域默认显示"？？点击揭晓"，点击后展开谜底并计入答对/猜错（自评）。→ **验收：默认状态下任何条目谜底不可见，点击揭晓后展开"谜底：框框套套"，刷新后默认恢复遮挡**
2. **分类导航**：数据集补分类字段后在搜索框下方渲染分类 chip 行。→ **验收：点击"动物"类 chip 后列表全部为动物类歇后语，与搜索框叠加过滤**
3. **计数诚实化**：空查询显示"共 14032 条 · 显示前 50"，命中显示"命中 X 条（显示前 80）"。→ **验收：搜索"猪"时计数 ≥100 条且有截断说明**
4. **收藏本**：卡片右上角星标收藏，页首"已收藏 N 条"入口可筛选查看并一键复制全部。→ **验收：收藏 3 条后入口显示 3，复制按钮输出的文本含 3 条谜面谜底**
5. **回车直达**：输入关键词回车自动展开第一条命中。→ **验收：输入"泥菩萨"回车后首条"泥菩萨过江"处于展开态（谜底遮挡开启时则为待揭晓态）**

> 家族共性声明：处方 3 的计数文案属 DatasetLookup 壳层改造（idiom-dictionary 档案已声明），本工具自身重点是处方 1/2/4——猜谜模式与分类导航为个性缺口。
