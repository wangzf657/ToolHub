## 扣分点明细

1. 【可用性】高轮次冻结：bcryptjs 主线程同步运算（:38 await 仅为 API 形态，实际 CPU 阻塞），13–15 轮数十秒内按钮/spinner 停摆、无进度无取消——预警文案（:73）在点击前，点击后零反馈
2. 【交互】双模不闭环：生成哈希后想"自证"需手动复制再粘到右栏哈希框（:100-108 与 :116-123 无联动），无"用此哈希验证"回填
3. 【功能】无哈希结构分解：$2b$ / cost / 22 位盐 / 31 位摘要四段不标注，新手不知道第 2 段"10"是什么（bcrypt.online 对格式有逐段说明）
4. 【功能】无版本选择：bcryptjs 3.0.3 固定输出 $2b$（`bcryptjs/index.js:96`），校验旧系统 $2a$/$2y$ 依赖 compare 兼容（可过 :67 错误文案也提及），但"生成指定版本"做不到（Devglan 可选版本）
5. 【交互】密码框 type=password 无显隐切换（:85,:118），本地工具里"看一眼输对了没"是合理诉求
6. 【功能】无推荐轮次口径：OWASP 建议随算力上调 cost（10 为常见基线，每 +1 轮耗时翻倍），工具无此口径，"该选几轮"无指导
7. 【灵魂】无"同一密码每次生成的哈希都不同（盐随机）但都能验证通过"科普——新手最常见困惑点零覆盖

## 行业对标与差距

- **bcrypt.online**：生成（可选 cost）+ 粘贴哈希校验双模、格式说明清晰。差距：哈希结构教学与版本兼容面（对方覆盖 $2a$/$2b$/$2y$ 说明）。
- **Devglan Bcrypt Generator**：可选 salt rounds 与 bcrypt 版本。差距：**版本级控制**；自定义盐属危险特性不必追。
- 借鉴优先级：**运算中进度反馈 > 一键回填验证 > 哈希分段标注 > 版本选择 > 轮次口径说明**。

## 优化处方（验收标准）

1. **一键回填验证**：生成结果旁加"去验证此哈希"按钮，点击切填右栏哈希框并聚焦密码框。→ **验收：生成→点击→右栏哈希框内容与生成值逐字符一致**
2. **运行时反馈**：轮次 ≥12 时生成期间显示"正在计算（约还需 N 秒）"估算。→ **验收：15 轮期间文案每秒更新，完成后实际耗时与估算误差 ≤30%**
3. **哈希分段标注**：hash-box 下方图例"$2b$ 版本｜10 轮｜22 字符盐｜31 字符摘要"分段对应。→ **验收：图例四段与生成哈希实际切分位置逐段吻合**
4. **轮次口径**：滑杆旁附"OWASP 建议 cost≥10；每提升 1 轮耗时约翻倍"。→ **验收：文案可见，且 10→11 轮实测耗时比在 1.8~2.2 倍区间与表述相符**
5. **版本选择**：生成选项加 $2a$/$2b$ 单选。→ **验收：选 $2a$ 生成哈希前缀为 $2a$，且两种版本都能被本工具 compare 正确验证**
6. **盐随机科普**：生成结果旁附一句"同一密码每次生成的哈希不同（盐随机），均可用 compare 验证"。→ **验收：连续生成两次同密码哈希值不同但验证均通过，且提示文案可见**
