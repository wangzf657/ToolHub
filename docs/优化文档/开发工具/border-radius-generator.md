## 结论与优先级

**需拓展 + 交互优化** · P1

判据：四值基础功能可用，但相比 9elements 缺八值/blob/拖拽手柄三件核心能力，功能差距悬殊（家族共性：CSS 生成器家族"可视化拖拽"短板的又一例证）。

## 扣分点明细

1. 【功能】无八值模式：CSS `border-radius` 支持斜杠语法分别控制水平/垂直半径，这是椭圆角/叶形/blob 的唯一入口，本工具只输出四值（`BorderRadius.vue:21`）——9elements 的灵魂形状全部无法实现
2. 【交互-家族共性】无角点拖拽手柄：行业标杆直接在预览盒四角拖手柄改半径，本工具是右侧四行滑杆逐一拖（:66-69）
3. 【功能】无 blob 随机生成器：随机八值一键出有机形状是 9elements 最强传播点，且纯前端零成本可实现
4. 【功能】仅 px 单位：无百分比（`border-radius: 50%` 的圆形/自适应胶囊必须用 %，滑杆上限 150px 在大盒上出不了圆）
5. 【交互】联动切换无过渡：取消联动后需手动逐角调，无"从当前值解锁"提示；预设仅 3 个且无形状语义（叶形/梭形/水滴缺位）
6. 【灵魂】smart 单值输出（:22-23）是好细节但无说明；预览盒固定 170×130，不能自定义尺寸比例
7. 【交互】无快捷键与数值手输：四滑杆 px 值同为只读 `<b>`（:66-69），想精确到 18px 只能拖
8. 【功能】无参数分享：形状参数不能入 URL，好的 blob 无法发给同事复现

## 行业对标与差距

- **9elements fancy border-radius**：八值斜杠语法、预览盒四角拖拽手柄（每角水平/垂直双向）、blob 随机生成+锁定部分角、百分比/像素切换、导出 CSS。差距：**形状表达能力代差**——对方是"形状生成器"，本工具只是"圆角数值器"。
- 借鉴优先级：**八值模式+拖拽手柄 > blob 随机 > 百分比单位 > 形状预设扩充**。

## 可拓展性

- 短期（1 周）：八值模式开关（每角拆水平/垂直双滑杆，输出斜杠语法）；百分比单位切换
- 中期（1 月）：预览盒四角拖拽手柄（pointer 事件，每角两个方向）；blob 随机+锁定；预设扩至 8+（叶形/梭形/水滴）
- 远期：与渐变/阴影生成器组成"CSS 视觉工作台"；预设形状库社区化（URL 分享形状参数）

## 优化处方（验收标准）

1. **八值模式**：加"高级（八值）"开关，四角各出水平/垂直双滑杆，输出 `border-radius: 60px 40px 30px 20px / 20px 30px 40px 60px;`。→ **验收：左上角水平 60/垂直 20 时预览呈不对称椭圆角且 CSS 含斜杠**
2. **角点拖拽手柄**：预览盒四角各放一个可拖手柄（八值模式下双向、四值模式下单向）。→ **验收：拖动右上角手柄后对应滑杆与 CSS 同步更新**
3. **blob 随机**："随机 blob"按钮生成随机八值（垂直值 30%~60% 区间），支持逐角锁定后再次随机。→ **验收：连点 5 次产生 5 个不同有机形状，锁定左上后随机仅变化其余三角**
4. **百分比单位**：px/% 切换，% 模式输出如 `border-radius: 50% / 12%`。→ **验收：% 模式 50% 时演示盒成正圆，拖宽盒子仍保持圆**
5. **预设扩充**：预设增至 8 个并按形状命名（直角/圆角/胶囊/叶形/梭形/水滴/blob-A/blob-B）。→ **验收：点击"叶形"直接得到对应八值组合且名称与形状对应**
6. **参数入 URL**：八值+单位写入查询参数，加载还原。→ **验收：带参链接打开后预览与 CSS 完全还原**
