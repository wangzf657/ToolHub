## 结论与优先级

**需拓展 + 交互优化** · P1

判据：单层功能可用但与 brumm 的多层+预设能力悬殊（家族共性：CSS 生成器家族"可视化拖拽 vs 手填/滑杆"短板本工具同样成立）；预览台亮底硬编码在暗色主题下属可用性瑕疵。

## 扣分点明细

1. 【功能】无多层阴影：brumm 支持任意层叠加并逐层调参，`box-shadow: A, B, C;` 才是现代精致 UI 的标配手法，本工具 CSS 拼接只支持一段（`BoxShadow.vue:25`）
2. 【功能】无预设库：Material Design elevation 6 级、brumm 柔和 5 级这类开箱阴影全缺席，新手连"好看阴影长什么样"都要自己摸索
3. 【交互-家族共性】预览盒不支持拖拽改 x/y 偏移——行业 top（brumm/shadow.page etc.）均为直接拖动盒子
4. 【可用性】预览台背景硬编码 `#f8fafc`（`BoxShadow.vue:98`）：暗色主题下突兀，且深色界面阴影（更依赖黑色分层）无法预览
5. 【交互】数值只读不能手输：四个滑杆的 px 值是 `<b>` 标签（:55-58），无法精确键入（如 y=63px）；blur 滑杆上限 100px（:57）无输入框突破
6. 【灵魂】演示盒底色固定纯白（:107），无法在品牌色/图片底上试阴影
7. 【功能】无 alpha 分离输出选项（如输出 `--shadow-color` CSS 变量方案，方便主题化）
8. 【灵魂】无常用阴影色快捷片：黑色 10%/20%/30% 三档 alpha 一键选（:59-66 要拖两次滑杆），brumm 用色相/明度滑杆一步到位

## 行业对标与差距

- **shadows.brumm.af**：多层阴影列表（增删/排序/逐层 5 参数+色相滑杆）、拖动预览盒改偏移、9 组精选预设一键载入、智能平滑（平滑梯度建议）。差距：多层能力与预设整体缺席，属代差。
- **Material elevation 阶梯**：6 级官方阴影参数是最佳空态教学素材。差距：无任何预设锚点。
- 借鉴优先级：**多层支持 > 预设库 > 拖拽偏移 > 预览底色切换 > 数值手输**。

## 可拓展性

- 短期（1 周）：预览台底色切换（亮/暗/自定义）替换硬编码；数值 b 改为可编辑 input
- 中期（1 月）：多层阴影列表（增删层+逐层参数折叠面板）；Material 6 级+柔和 5 级预设；拖拽偏移（pointer 事件换算 x/y）
- 远期：输出 CSS 变量方案（`--shadow-color` + color-mix）；与渐变/圆角生成器组成"CSS 视觉工作台"

## 优化处方（验收标准）

1. **多层阴影**：控件区上方加阴影层列表（默认 1 层，可加至 5 层），每层独立参数，CSS 逗号拼接。→ **验收：两层时输出形如 `box-shadow: 0 1px 2px rgba(...), 0 8px 24px rgba(...);` 且预览正确叠加**
2. **预设库**：预设 chip ≥11 个（Material 6 级+柔和 5 级），点击载入对应多层参数。→ **验收：点击"层次 4"后层列表、预览、CSS 三者一致**
3. **拖拽偏移**：预览台上直接拖动演示盒改 x/y（按住 Shift 吸附 5px）。→ **验收：拖动后两滑杆数值与 CSS 同步变化**
4. **预览底色切换**：亮/暗/自定义三选，移除硬编码 #f8fafc（:98）。→ **验收：暗色主题下选"暗"底后阴影可见且页面观感统一**
5. **数值手输**：四个 px 值改为可编辑输入框（范围 ±200/±200/0~400/-100~200，与滑杆双向绑定）。→ **验收：键入 y=63、blur=200 后预览与 CSS 立即生效**
