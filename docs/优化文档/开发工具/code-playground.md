## 结论与优先级

**交互优化 + 需拓展** · P1

判据：沙盒安全模型与 console 桥接是合格甚至优秀的工程底座（无硬伤），但 240px 预览窗＋纯手动运行的交互形态离"在线运行器"的预期形态（实时、可放大、可引库）有明显差距。

## 扣分点明细

1. 【可用性】预览区与控制台各钉死 240px（`CodePlayground.vue:162,169`），无弹性高度、无全屏切换——调一个 600px 高的页面布局只能在 240px 小窗里滚（共性-根因 2 在"预览即主结果"工具上的最痛实例）
2. 【可用性】三编辑器 min-height 150px（:99-107）且三栏各 ~286px 宽，无"左右分栏/上下堆叠"布局模式切换；jsFiddle 四栏可调是基本功
3. 【交互】无 Ctrl+Enter 运行、无自动运行开关（:47-59），playcode.io 输入即跑，本工具每次试验都要把视线挪回顶部按钮
4. 【可用性】报错行号是拼合 srcdoc 文档行号而非 JS 编辑器行号：`window.onerror` 的行参数（:37）包含 HTML 行数＋桥接脚本偏移，用户 JS 第 1 行报错会显示"第 20+ 行"，直接误导排障
5. 【功能】无 CDN 库快捷引入：想跑 Vue/jQuery 要自己手敲完整 `<script src>` 到 HTML 栏，jsFiddle 的 Libraries 面板一勾即用
6. 【功能】无模板/示例库：初始仅一份 Hello 示例（:8-10），无 Canvas/DOM 事件/fetch 示例一键载入，空态引导弱
7. 【交互】草稿仅单槽且手动（:70-84）：无自动保存、无多片段管理、无"导出 .html"（buildSrcdoc :45 现成可下载却没做）
8. 【灵魂】沙盒能力边界未文档化：opaque origin 下 localStorage 会抛 SecurityError、跨域 fetch 受 origin null 限制，notice（:125）只有一句"不访问本站数据"，用户撞错后无解释
9. 【UI-轻】控制台无时间戳、无条数徽章，200 条截断静默（:65）

## 行业对标与差距

- **playcode.io / StackBlitz / CodeSandbox**（云）：NPM 包即时安装、热更新不闪屏、多文件工程、控制台对象折叠检查——属云＋打包器**架构天花板**，纯 iframe 方案无法也不必复刻，UI 上应诚实标注能力边界。
- **jsfiddle.net**（纯 iframe 可及线）：四栏可调布局、Libraries 勾选 CDN、实时预览开关、Ctrl+Enter 运行、成果导出——这是本工具**应当对齐**的目标，目前差距集中在实时性与工作台布局两处。
- 借鉴优先级：**Ctrl+Enter＋自动运行 > 预览弹性高度/全屏 > CDN 快捷引入 > 模板库 > 导出 HTML**。

## 优化处方（验收标准）

1. **预览/控制台弹性高度**：默认 `calc(50vh - 100px)`、下限 320px，各配全屏切换。→ **验收：1366×768 下预览区 ≥400px 高；点全屏后覆盖含侧栏的整页**
2. **快捷运行**：编辑器 keydown Ctrl+Enter 触发 run；增加"自动运行"开关（400ms 防抖）。→ **验收：焦点在任一编辑器按 Ctrl+Enter 即重跑；开自动后停手 0.5s 内预览更新**
3. **CDN 快捷引入**：工具行加库勾选（Vue3/jQuery/lodash），勾选即向 head 注入固定版本 script。→ **验收：勾选 Vue 后代码调用 createApp 正常执行且控制台无 404**
4. **行号映射**：srcdoc 生成时记录 JS 起始行偏移，onerror 展示"JS 第 N 行"。→ **验收：JS 编辑器第 3 行抛错，控制台显示"第 3 行"**
5. **模板库**：工具行加"示例"下拉（Canvas 动画/DOM 事件/fetch/Storage 边界 4 例）。→ **验收：选 Canvas 模板后三栏载入对应代码且预览出现动画**
6. **导出 .html**：下载按钮输出 buildSrcdoc 去桥接版本。→ **验收：导出文件双击打开与预览区渲染一致**
