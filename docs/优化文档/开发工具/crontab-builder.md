判据：实时说明无硬伤（可用性 14/20）；缺复制按钮是明确交互缺口，勾选面板与表达式导入是与对标的功能面差距。

## 扣分点明细

1. 【交互】生成表达式不可复制：expr-card（`CrontabBuilder.vue:117-120`）只有展示无复制钮——构建器的最终交付物竟要手动划选，本批九工具中唯一的"结果不可复制"构建类工具
2. 【交互】反馈口径分裂：summary 实时（:50 computed）而"未来执行时间"要点按钮（:126），改配置后执行时间区残留旧值无失效提示，易把旧时间当新结果
3. 【功能】无勾选面板：小时/分钟用"模式下拉＋数字输入"表达，对标生成器直接铺 0-23 勾选格；"第 0、15、30、45 分钟"要手打逗号串（:103）
4. 【功能】无表达式导入：粘贴既有 cron 反推各字段模式的方向缺席，与 cron-explainer 之间无任何互链（双向闭环两端都断，见下节）
5. 【灵魂】range 模式 from>to 时静默输出 `*`（:44 三目 else 分支）：用户设 18-9 想表达跨零点区间却得到"每 X"，语义相反且无提示
6. 【功能-轻】星期字段 max=6（:32）而解读引擎支持 0-7（`CronExplainer.vue:95`），部分系统 7=周日写法在本构建器造不出；日/星期隐藏范围步长（:109-111）但 cron 语法 `1-15/2` 对日域合法，能力被无说明地砍掉
7. 【交互】预设仅 3 个且硬编码（:60-78），无"每月 1 号 0 点""每小时第 5 分钟"等高频扩展位

## 与 cron-explainer 的双向闭环：共享引擎，互不知晓

引擎侧已闭环——构建器 import 解读器的 explainCron/nextRuns（:4），说明文案与解读页同源✓。UI 侧零闭环：构建页无"粘贴表达式导入"，解读页无"拿去构建"入口（详见 cron-explainer.md 专节）。补齐顺序建议：表达式导入（构建页顶部输入框）> 两页互链按钮 > query 传参。

## 行业对标与差距

- **crontab.guru / bejson cron 生成器**：分/时/日/月/周勾选面板（点格即选＋全选/反选/工作时间快选）、生成即复制、日历校验。差距：**勾选一步直达 vs 下拉两步**＋复制闭环缺失。
- 借鉴优先级：**复制按钮（近零成本）> 勾选面板 > 表达式导入 > 执行时间实时化 > from>to 纠错提示**。

## 可拓展性

- 短期（1 周）：expr-card 加复制钮（toast 反馈）；执行时间随表达式防抖自动刷新（保留手动按钮）；from>to 行内警示
- 中期（1 月）：小时/分钟勾选面板档（紧凑下拉模式保留）；顶部"导入表达式"解析回填五字段；星期 0-7 补齐；预设扩充
- 远期：与 cron-explainer 组"Cron 工作台"（构建/解读/日历三 Tab）；下次执行月历打点；crontab 行上下文生成（环境变量＋日志重定向模板）

## 优化处方（验收标准）

1. **复制按钮**：expr-card 右上角加"复制"钮。→ **验收：点击后剪贴板为当前表达式（如 `*/15 * * * *`），按钮 1.5s 对勾反馈**
2. **执行时间实时化**：expr 变化 500ms 防抖自动刷新 runs(5)。→ **验收：分钟从每 15 改为每 5，执行时间列表 0.5s 内更新且与 summary 同步**
3. **导入表达式**：顶部输入框粘贴 `30 9-18 * * 1-5` 回车后五字段档位自动回显。→ **验收：回显后 summary 与 cron-explainer 解读同一表达式文案一致**
4. **勾选面板**：小时字段加"面板"档，0-23 勾选格＋全选/反选/工作时间快选。→ **验收：勾选 9、12、18 三格后表达式小时域为 `9,12,18`**
5. **range 纠错**：from>to 时该行出红色提示。→ **验收：日字段设 18-9 出现"起始 18 大于结束 9，已按每天处理"提示文案**
