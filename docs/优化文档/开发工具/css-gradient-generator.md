## 结论与优先级

**交互优化 + 需拓展** · P1（CSS 生成器家族三兄弟中功能最全的一个，但交互范式落后一代）

判据：功能可完成任务，但与 cssgradient.io 的"拖拽色标"存在交互代差（家族共性）；预设库/conic 缺失属功能悬殊。

## 扣分点明细

1. 【交互-家族共性】色标调整是"手填数字"范式：每行 color picker+文本+位置滑杆（`GradientGenerator.vue:63-69`），cssgradient.io 是在渐变预览条上直接拖色标圆点、双击空白处添加——后者才是行业灵魂
2. 【可用性】预览区 130px（:137-143）且被色标行压在中部；预览兼色标轨道后高度应为主视觉区
3. 【功能】无 conic-gradient：三类型只做两个（:17-19），锥形渐变是近年 UI 高频手法
4. 【功能】无预设库：cssgradient.io/uigradients 均带几十个开箱渐变，本工具每次从零配
5. 【功能】色标无独立透明度：原生 `input[type=color]` 不含 alpha，做淡出渐变（→transparent）必须手写文本框
6. 【功能】径向渐变锁死 `circle at 50% 50%`（:18）：无椭圆/尺寸/位置控制
7. 【交互】角度调节仅滑杆 step=5°（:56）：无数值输入、无角度盘拖拽，微调到 37° 这类值做不到
8. 【灵魂】加第 6 个色标被 toast 拒绝（:22）但不解释原因也不提供变通

## 行业对标与差距

- **cssgradient.io**：预览条即色标轨道（拖拽移动/双击添加/选中删除）、透明度独立滑杆、角度盘拖拽、十余个精选预设、CSS 多格式输出。差距：**核心交互范式代差**（拖拽 vs 手填）。
- **uigradients**：预设库+随机按钮。差距：灵感输入完全缺席。
- 借鉴优先级：**预览条拖拽色标 > 预设库 > conic 类型 > 色标透明度 > 角度盘**。

## 可拓展性

- 短期（1 周）：预览条化（色标圆点绝对定位可拖、双击添加）；角度数值输入框
- 中期（1 月）：预设库 ≥12 例 + 随机按钮；conic 类型；色标 rgba 透明度滑杆；SCSS/Tailwind 输出 Tab
- 远期：与 color-converter/box-shadow-generator 组成"CSS 视觉工作台"，色卡互通

## 优化处方（验收标准）

1. **预览条拖拽色标**：预览下沿生成色标轨道，圆点拖拽改 pos、双击添加、选中后 Delete 删除。→ **验收：拖动色标从 0%→60% 时预览与 CSS 同帧更新，松手后行内百分比同步**
2. **角度盘**：线性模式预览角上叠可拖角度手柄+数值输入框（0~360 步进 1）。→ **验收：拖手柄到任意角度 CSS 精确到 1°；输入 37° 后滑杆与手柄同步**
3. **预设库**：预设 chip 列表 ≥12 例（含淡出/霓虹/落日等），点击全量载入色标与角度。→ **验收：点击任一预设后色标行数量与颜色、预览、CSS 三者一致更新**
4. **conic 支持**：类型下拉加"锥形渐变"，输出 `conic-gradient(from Xdeg at 50% 50%, ...)`。→ **验收：锥形模式预览呈扇形扫描效果且复制可用**
5. **色标透明度**：每行加 alpha 滑杆（0~100），输出改 rgba()/hex8。→ **验收：第二色标 alpha 0 时预览末端透明淡出，CSS 输出含 rgba**
