## 结论与优先级

判据：可用性 8/20 触发硬伤红线（结果区不可读，M-01 实测 10.8 屏滚动量）；与 JSON Crack 的结构可读性存在代差。

## 扣分点明细

1. 【可用性-硬伤】输出 ResultBox `:style="{ minHeight, height: minHeight }"` 双重钉高 320px，无法撑满视口（`ResultBox.vue:69`、`JsonFormatter.vue:65`；实测 M-01/M-02：**1920×1080 大屏下依旧 320px/842px 面板，零增益**）
2. 【可用性】输入与输出独立滚动，对照检查长 JSON 时无法同步定位（`JsonFormatter.vue:63-65` 双 textarea 无 scroll 联动）
3. 【功能】无折叠树/结构视图——JSON Crack 的核心价值即"看清结构"，本工具只有纯文本
4. 【交互】粘贴 JSON 后仍需手动点击"格式化"，未提供"粘贴即处理"开关（`run()` 仅由按钮触发，`JsonFormatter.vue:55-57`）
5. 【灵魂】空态只有一句 placeholder"结果将显示在这里"，无示例 JSON 一键填充、无格式说明
6. 【灵魂】无快捷键（Ctrl+Enter 格式化、Ctrl+Shift+C 复制均未实现）
7. 【性能】同步主线程执行，1MB+ JSON 会冻结输入框且无任何进度提示
8. 【美观】`.grid-2` 到 ≤560px 才堆叠（`base.css:329-335`），768px 平板上双栏各 ~250px 近乎不可读
9. 【环境】Cookie 横幅首访遮挡底部"JSON 校验通过"结果条（M-01 截图证据）

## 行业对标与差距

- **JSON Crack**：图谱式结构树+节点折叠、JSONPath 即取即复制、大文件虚拟滚动、URL 分享快照。差距：**结构可读性代差**——对方让 JSON"可浏览"，本工具只让 JSON"可滚动"。
- **jsonformatter.org**：格式化+Tree 双视图 Tab 切换、行号栏、错误处行内红标并可点击跳转、本地历史记录。差距：错误修复闭环（本工具只报行列号，用户要自己去数行）。
- 借鉴优先级：**折叠树视图 > 错误行内跳转 > 粘贴即格式化 > 同步滚动 > 路径复制**。

## 可拓展性

- 短期（1 周）：输出区弹性高度（见处方 1）；粘贴即格式化开关；错误点击跳转输入对应行
- 中期（1 月）：折叠树 Tab（手写递归组件或引入轻量 tree，注意懒加载纪律）；Web Worker 化 jsEngine 大文件路径；最近 10 条历史记录（localStorage）
- 远期：与 json-visualizer、jsonpath-tester、json-diff 合并成"JSON 工作台"（模式 E），一个入口覆盖格式化/可视化/查询/对比

## 优化处方（验收标准）

1. **输出区弹性高度**：ResultBox 增加 `expand` 模式——默认 `calc(100vh - 330px)` 且下限 480px，提供"全屏"切换按钮（fixed 覆盖层）。→ **验收：1366×768 下 2000 行 JSON 无需滚动页面即可见 ≥28 行；点击全屏后覆盖含 TrustSidebar 的整页**
2. **粘贴即处理**：监听 paste 事件自动执行当前动作（默认开，选项区可关）。→ **验收：粘贴合法 JSON 后 300ms 内输出区出现结果，无需点击**
3. **错误行内跳转**：点击错误提示定位输入 textarea 对应行（按 \n 计数 scroll）。→ **验收：构造错误 JSON，点击提示后输入区 scrollTop 使错误行可见**
4. **折叠树 Tab**：输出区上方加"文本 | 树"Tab，树视图节点可折叠、可复制路径。→ **验收：3 层嵌套 JSON 树视图可逐层折叠，hover 节点显示复制路径按钮**
5. **同步滚动**：格式化成功后输入/输出按行号比例联动滚动（可关）。→ **验收：拖动输入区滚动条，输出区跟随比例移动**
