## 扣分点明细

1. 【功能-疑似缺陷】字符串引号策略不安全：仅含 `:` `#` `\n` 的字符串才加引号（`jsEngine.ts:99`）——`"3"` 输出 `v: 3`、`"2024-01-01"` 输出裸时间戳、空串 `""` 输出 `v:`（重解析为 null）；用站内 yaml-to-json 回转 `{"v":"3"}` 得到数字 3，**自家两工具往返即类型漂移**（YAML 1.1 下 "yes"/"on" 还会变布尔）
2. 【功能】手写序列化器未用 js-yaml dump（`jsEngine.ts:78-102`）：无 2/4 空格缩进选择、无 flow 风格 `{a: 1}`、无按键排序、无双引号风格
3. 【功能】值以 `-` `&` `*` `%` `@` 等指示符开头时同样裸输出（:99 不拦截），个别组合（如 `key: *a`）产生非法/歧义 YAML
4. 【可用性】双窗 180px 钉高（家族共性-根因 2，M-06）；深层嵌套 YAML 缩进在 180px 内无法总览
5. 【交互】无 .yaml/.yml 文件下载（TextTool.vue:130-133 仅复制），写 compose 文件要手工建文件
6. 【灵魂】主打 K8s/Compose 场景（registry.ts:85-86）却无对应示例片段一键填充；无键数/最大深度统计

## 行业对标与差距

- **Code Beautify（JSON to YAML）**：缩进宽度选项、键排序开关、行号、下载 .yml。差距：输出可控性。
- **jsonformatter.org**：JSON↔YAML 双向 Tab、错误行列高亮、往返一致（底层 js-yaml 全语法）。差距：**往返正确性**是代差——对方 dump 走标准引号策略，字符串永远不漂移。
- 借鉴优先级：**安全引号化（数字/布尔/日期样字符串与空串加引号）> .yaml 下载 > 缩进选项 > k8s 示例**。

## 可拓展性

- 短期（1 周）：引号安全兜底（正则判数字/布尔/日期样字符串与空串即加引号）；示例填充（compose 服务片段）；.yaml 下载
- 中期（1 月）：缩进宽度/flow 风格/排序键选项；"重解析预警"清单（列出将被改写类型的值）；大文件 Worker
- 远期：接 js-yaml dump（懒加载纪律）替换手写序列化器，与 yaml-to-json 共用一套引擎保证往返等价

## 优化处方（验收标准）

1. **安全引号化**：匹配 `^-?\d+(\.\d+)?$`、`^(true|false|yes|no|on|off|null|~)$`（忽略大小写）、ISO 日期样、空串的字符串一律加双引号。→ **验收：`{"v":"3","d":"2024-01-01","e":"","f":"yes"}` 输出四个值均带引号，经 yaml-to-json 回转后 JSON.stringify 深度相等**
2. **下载 .yaml**：输出区加"下载 .yaml"。→ **验收：下载文件 UTF-8 无 BOM，内容与预览一致**
3. **示例填充**：加"填入 Compose 示例"按钮（services/volumes/ports 片段）。→ **验收：点击后输入含嵌套数组样例，输出 YAML 可直接被 compose config 接受的结构**
4. **弹性高度**：双窗 `calc(100vh - 330px)` 下限 480px。→ **验收：1366×768 下 60 行 YAML 输出同屏 ≥20 行**
5. **重解析预警**：存在将被 YAML 改写类型的字符串值时，结果区顶黄条列出键名。→ **验收：`{"version":"3"}` 出现提示"version 的值 "3" 已加引号以保持字符串类型"**
