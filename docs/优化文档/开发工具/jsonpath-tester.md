## 结论与优先级

**交互优化 + 需拓展** · P1

判据：结果区 420px 钉死 + 无路径标注构成"结果可读性"扣分；过滤器只支持 == 使半数真实查询（价格区间、条件组合）无法表达，功能差距明确。

## 扣分点明细

1. 【可用性】结果区 `max-height:420px` 钉死（`JsonPathTester.vue:93`，共性-根因 2 钉高清单在案），命中 50+ 条时小窗内滚且无总数分页
2. 【可用性】结果卡片只显示值（`JsonPathTester.vue:68` 逐条 pre），**不带命中路径**（如 `$..book[2].title`）——jsonpath.com 每条结果标注来源路径，diff 排查"哪条来自哪"无从下手
3. 【功能】过滤器 regex 仅支持 `@.key=='value'` 单等号（`jsEngine.ts:536`），`[?(@.price<10)]`、`[?(@.a&&@.b)]`、`[?(@.name=~ /^s/)]` 全部静默返回空——**语法速查卡声称"过滤器（简化支持 ==）"（:22）但空结果无解释**，用户以为查询错了
4. 【功能】无多路径批量：`$.a` 与 `$..b` 要跑两次（对标金标准"JSONPath 提取"愿景）
5. 【交互】无实时查询（run 仅 Enter/按钮触发，:25-45），jsonpath.com 输入即算
6. 【功能】切片无步长（`jsEngine.ts:559-561` 仅 `[a:b]`），负步长/`[::2]` 不支持
7. 【灵魂】命中结果无法在左侧 JSON 原文中高亮定位（json-visualizer 的搜索高亮能力就在隔壁 `JsonTreeNode.vue` 却未复用）

## 行业对标与差距

- **jsonpath.com**：左侧 JSON 树+右侧表达式，输入实时求值、每条命中带路径并可单独复制、支持完整 Goessner 语法（含脚本表达式）。差距：**实时性 + 路径回溯 + 过滤器完整度**三重差距。
- **JSON Crack**（jsonhero.io）：查询结果在树上直接高亮节点。差距：结果与原文的视觉关联（与扣分 7 同源）。
- 借鉴优先级：结果带路径 > 过滤器补齐（比较/逻辑操作符）> 实时查询 > 原文高亮联动。

## 可拓展性

- 短期（1 周）：结果卡片头部显示命中路径（walk 时记录 path 即可）；过滤表达式非法时输出明确错误而非空结果
- 中期（1 月）：比较/逻辑操作符补齐（<、>、!=、&&、||）；输入即实时查询（250ms 防抖，同 json-visualizer `JsonVisualizer.vue:22-25` 做法）；复制全部结果为 JSON 数组
- 远期：与 json-visualizer 合并"查询-可视化一体"（金标准 `docs/优化文档/开发工具/json-formatter.md` 远期档 JSON 工作台成员），查询命中直接在树上高亮

## 优化处方（验收标准）

1. **结果带路径**：walk 递归携带 path，结果卡片头部 mono 字体显示 `$..book[2].title`，点击复制。→ **验收：默认示例跑 `$..inStock` 输出 3 条，每条头部含 `[0]/[1]/[2]` 下标路径**
2. **过滤表达式报错可见**：过滤器含未支持操作符时结果区显示"过滤器暂仅支持 ==，检测到 <"而非空列表。→ **验收：输入 `[?(@.price<10)]` 出现明确黄条提示**
3. **比较操作符**：支持 `<`、`>`、`!=`、`&&`。→ **验收：`$.store.book[?(@.price<40 && @.inStock==true)]` 命中"球状闪电"**
4. **实时查询**：表达式输入 300ms 防抖自动执行。→ **验收：输入过程无需回车，停止输入 300ms 内结果区更新**
5. **结果区弹性高度**：`.result-area` 改 `calc(100vh - 340px)` 下限 420px 可全屏。→ **验收：1366×768 下 50 条命中同屏可见 ≥8 条且页面无需滚动**
