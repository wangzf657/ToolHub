## 结论与优先级

**交互优化** · P1

判据：主题切换与预览/复制内容脱节（:51）会让用户把错误排版粘进公众号，属可用性级缺陷；与 mdnice/Doocs 的"即改即见+主题超市"存在交互代差。

## 扣分点明细

1. 【可用性-硬伤】主题切换不刷新：chip `@click="theme = t"`（`MarkdownToWechat.vue:51`）不触发 render，预览 v-html 绑定的 html ref（:71）保持旧主题产物，而字段标签已显示新主题名（:69）——预览内容与标签自相矛盾；此时点"复制到公众号"（:57）复制的是旧主题 HTML，公众号后台得到错误排版且全程无提示
2. 【可用性】预览需手动"生成排版"：输入不触发渲染（render 仅按钮 :56），无防抖实时——预览类工具核心交互缺席
3. 【功能】代码块无语法高亮：pre 仅深底 #282c34+统一 #abb2bf 字色（`mdEngine.ts:329-334`），公众号技术号排版核心诉求缺席（mdnice 有 30+ 代码主题）
4. 【功能】主题仅 4 套且仅 accent 单变量：标题/引用/表格底纹全由一个 accent 派生（`mdEngine.ts:311,319,336`），无字号/间距/字间距风格差异
5. 【功能】无自定义 CSS 输入框（Doocs md 支持），样式微调只能复制后手改——违背"复制即贴"工具闭环
6. 【可用性】预览盒 `max-height:560px` 钉死（`MarkdownToWechat.vue:89`；共性-根因 2 家族形态），长文手机框内滚
7. 【灵魂】无一键复制纯文本版；无快捷键；无"复制成功后打开公众号后台"引导链接
8. 【环境】Cookie 横幅首访遮挡底部（M-01 截图证据）

## 行业对标与差距

- **mdnice**：即改即见分屏、60+ 主题+代码高亮主题库、自定义 CSS、图床（云，架构天花板，本站诚实不做）。差距：实时性与主题丰富度代差。
- **Doocs md**：开源、自定义 CSS、暗色预览、快捷键、Mermaid/公式支持、一键复制与微信提示。差距：可定制性与快捷键。
- 借鉴优先级：主题切换即渲染 > 输入防抖实时 > 代码高亮主题 > 主题扩容 > 自定义 CSS。

## 可拓展性

- 短期（1 周）：watch(theme) 自动 render；watch(input) 500ms 防抖；预览弹性高度；复制前一致性校验
- 中期（1 月）：highlight.js 配色内联化（token style 转 inline CSS）；主题扩到 10+（字号/间距变体）；自定义 CSS 文本框
- 远期：并入 Markdown 工作台"发布"Tab；主题中心与 markdown-to-image 共享（同引擎同主题表）

## 优化处方（验收标准）

1. **主题联动**：watch(theme) 自动调 render。→ **验收：点击"科技蓝"chip 后 500ms 内预览变色，立即复制得到的 HTML 中含 #2f6fd6**
2. **实时渲染**：输入 500ms 防抖自动 render。→ **验收：粘贴 Markdown 1s 内预览更新，无需点击"生成排版"**
3. **复制防呆**：html 生成时间早于最近一次 theme/input 变更时，复制前自动重渲染。→ **验收：换主题后不点"生成排版"直接复制，公众号粘贴得到的是新主题排版**
4. **代码高亮**：pre 内 token 着色且全部内联（公众号不执行外部 CSS）。→ **验收：js 代码块在预览与复制产物中均有多色且粘贴到公众号后台保留**
5. **预览弹性高度**：`calc(100vh - 330px)` 下限 480px。→ **验收：1366×768 下长文预览无需滚动页面可读 ≥30 行**
