## 扣分点明细

1. 【功能-代差】无签名/验签：PGP 的另一半核心是 sign/verify（CyberChef 提供 Sign/Verify/Encrypt-and-Sign/Decrypt-and-Verify），"发我签名的信"与"验对方真伪"场景缺位（openpgp 纯前端全可做）
2. 【交互】Tab 上下文割裂：生成密钥后无法一键"用此密钥加密/把公钥填进加密 Tab"（:220-235 结果区与 :150-169 加密区无联动），手工跨 Tab 复制 4 次
3. 【可用性】输出区钉 240px（:256）、明文输入 90px（:152）——长信加密输入输出都憋屈（同族 260px 病灶变体）
4. 【功能】无私钥详情视图：导入私钥后不显示指纹/keyID/算法/创建时间，"这把钥对不对"只能靠解密成败反推（keybase key inspector 是标准动作）
5. 【功能】仅文本：无文件加密（openpgp createMessage 支持 binary 数据未暴露），.asc 附文件场景断链
6. 【交互】解密结果复制无对勾反馈（:191 通用 copy 仅 toast，与加密侧 :130-137 不一致）
7. 【灵魂】无指纹当面校验引导（"与对方核对指纹"是 PGP 安全仪式核心），安全教学缺一块
8. 【可用性】busy 状态三 Tab 共享但无防误触提示，切换 Tab 后返回不保留中间输入感（输入虽在、视觉焦点丢失）

## 行业对标与差距

- **CyberChef**：PGP Encrypt/Decrypt/Sign/Verify/Encrypt-and-Sign/Decrypt-and-Verify 六操作+armor 选项、可串压缩/编码配方。差距：**签名系操作整体缺失**（纯前端 openpgp 可补齐）。
- **keybase.io**：公钥指纹展示、key inspector、身份核验流程。差距：密钥可读性与核验引导。
- 借鉴优先级：**Tab 间密钥联动 > 签名/验签 Tab > 私钥指纹详情 > 文件加密 > 解密反馈对齐**。

## 可拓展性

- 短期（1 周）：生成密钥后按钮组"用此密钥加密/去解密"自动填充对应 Tab；解密结果对勾反馈
- 中期（1 月）：签名/验签 Tab（openpgp sign/verify API）；私钥指纹与 keyID 详情卡；输出区弹性高度
- 远期：文件加密下载 .asc；密钥环本地保存（口令加密存 localStorage，附风险提示）

## 优化处方（验收标准）

1. **Tab 联动**：生成密钥对后显示"用此密钥加密"按钮，点击切到加密 Tab 且公钥框已填入新公钥。→ **验收：生成→点击→加密 Tab 公钥框内容与刚生成公钥逐字符一致**
2. **签名/验签**：新增签名 Tab（粘贴私钥+口令出签名）与验签入口（公钥+原文+签名出结论）。→ **验收：本工具签名的消息可被 `gpg --verify` 验证通过，gpg 签名的消息可被本工具验真**
3. **私钥详情**：解密 Tab 粘贴私钥后即时显示指纹/keyID/算法/创建时间。→ **验收：指纹与 `gpg --show-keys` 输出一致**
4. **输出区弹性**：`.out` 240px 改 `max-height: calc(100vh - 460px)`、下限 240px。→ **验收：1366×768 下 60 行密文同屏可见 ≥25 行**
5. **明文输入扩容**：加密明文 textarea 提至 140px 并支持拖入 .txt 自动填充。→ **验收：拖入 10KB 文本文件后明文框出现全部内容**
