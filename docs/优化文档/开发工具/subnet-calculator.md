## 扣分点明细

1. 【交互】CIDR 仅滑杆无数字输入（`SubnetCalculator.vue:62-64`）：精确 /26、/30 只能逐格拖，无 -/+ 步进、无回车输入框
2. 【功能】无掩码→CIDR 反向输入：subnetcalculator.info 直接接受 `255.255.255.192` 输入，本工具拿着掩码只能人肉换算前缀；"载入网络地址"按钮（:45-51）只把 network 回填 IP 框，既不做掩码互换也不改 CIDR，文案与行为错位
3. 【交互】结果九行零复制：全文未引 copyText，网络/掩码/主机范围无法单值复制（CalcTool 家族"结果不可单值复制"共性在此复现且更甚）
4. 【功能】无 VLSM/子网拆分：给定 /24 拆 4 个 /26 的需求要另寻工具，对标站的 multi-subnet 表格是核心增值
5. 【灵魂】无私有/公网段判别：192.168/10.x/172.16-31 应标注"私有地址（RFC 1918）"，防火墙调试高频依赖此判别
6. 【可用性-轻】二进制不做位对齐：jsEngine.ts:860 仅 IP 二进制平铺一行，"掩码怎么切出网络位"的 IP/掩码/网络三行对齐视图缺席
7. 【交互】两种输入行为不一致：改前缀滑杆立即重算（:43,:63），改 IP 却要按回车/按钮（:59,:65）
8. 【交互】结果不可分享/持久化：无 URL query 参数承载 ip/cidr，刷新即丢——subnetcalculator.info 的可分享链接是网络团队协作刚需

## 行业对标与差距

- **subnetcalculator.info**：单输入框吃 IP/CIDR/掩码任意格式、VLSM 拆分表、IP 在网段内位置可视化、可分享 URL。差距：**输入宽容度与 VLSM 代差**（掩码解析＋等分算法纯前端可及）。
- **ipcalc.org**：class 判别、二进制逐位对齐演示。差距：教育视图缺席。
- 借鉴优先级：**掩码→CIDR 反向输入 > 结果行复制 > VLSM 拆分 > 私有段判别 > 二进制对齐视图**。

## 可拓展性

- 短期（1 周）：CIDR 加数字输入框与滑杆双向绑定；九行结果逐行复制；IP 框 watch 防抖自动重算（统一两种输入行为）
- 中期（1 月）：输入框直接解析 `192.168.1.130/26`、`192.168.1.130 255.255.255.192`、纯掩码三种格式；RFC 1918 判别标注
- 远期：VLSM 拆分表（输入需求主机数列表→输出子网方案）；IP/掩码/网络二进制三行对齐视图；IPv6 前缀计算卡

## 优化处方（验收标准）

1. **输入格式宽容**：IP 框接受 `IP/CIDR`、`IP 掩码`、纯掩码三种格式自动拆填。→ **验收：输入 `192.168.1.130/26` 滑杆自动跳到 26；输入 `255.255.255.192` 后 CIDR 变 /26 且提示"已按掩码解析前缀"**
2. **滑杆＋数字双向绑定**：滑杆旁加数字输入。→ **验收：数字框输入 30，滑杆同步到 30 且结果即时更新**
3. **逐行复制**：结果表每行 hover 出复制钮。→ **验收：点击"子网掩码"行复制钮后剪贴板为 `255.255.255.0`**
4. **私有段判别**：结果区顶部按 RFC 1918 标注。→ **验收：输入 10.0.0.5 出现"私有地址"标注；输入 8.8.8.8 显示"公网地址"**
5. **VLSM（远期）**：输入 `192.168.1.0/24` 与需求 [100,50,2] 输出 /25、/26、/30 三个子网各带范围与可用数。→ **验收：三行方案不重叠且可用数均满足需求**
