## 结论与优先级

**交互优化 + 需拓展** · P1

判据：双向查询主链路可用无硬伤；对照 unicode-table.com 缺"名称＋区块浏览＋转义矩阵"三大功能面，属功能代差而非交互问题。

## 扣分点明细

1. 【功能】无字符官方名称：unicodeInfo 只回码点/区块（`jsEngine.ts:888-897`），未引入 Unicode 名（Intl 或离线名表皆可），"查这个字符是什么"只能靠区块名猜——对标站每字符首行即名称
2. 【功能】无区块浏览：25 个区块表（jsEngine.ts:900-910）只用于归类已输入字符，不能反向"打开 CJK 区块看全部 20992 字"——unicode-table.com 的网格浏览是其流量主入口
3. 【功能】转义输出矩阵缺失：`\u4E2D`、`\x`、`%u4E2D`（JS/Java/URL 编码各有用场）与命名实体全部缺席，只有十进制实体一列（jsEngine.ts:895）——前端开发实际粘贴频率最高的是 `\u` 转义
4. 【交互】逐行与反查结果均不可复制：行卡无复制钮（UnicodeLookup.vue:63-71），rev-card 大字符同样无复制（:79-87），只有"复制全部"TSV 一条路
5. 【可用性-轻】200 字符切片静默截断：textarea maxlength=400（:60）与 MAX=200（:12）双上限不一致，超出后计数显示"250/200"但内容已截半，无"已截断"提示
6. 【灵魂】不可见字符检测缺席：NBSP/ZWJ/ZWNJ/BOM 是文案排障第一高频，应输入即高亮标注"⚠ 零宽字符"，现与普通字符无差别展示
7. 【功能-轻】emoji ZWJ 组合序列被拆成逐码点行（`[...text]` 按 code point 切分，:24），"👨‍👩‍👧"显示 5 行互不相关的码点，无"这是一个组合 emoji"的说明
8. 【交互】反查不支持的输入（如直接粘贴汉字反查码点入口已在左栏，尚可）但六位以上十六进制（astral 区 `U+1F600` 五位可、`U+10FFFF` 六位可）仅限 1-6 位（:32 正则 `{1,6}`）——边界恰覆盖全平面，无误；唯无"随机字符/上一位/下一位"浏览器式探索

## 行业对标与差距

- **unicode-table.com**：300+ 区块网格浏览、点字符看详情（名称/UTF-8/UTF-16 编码矩阵/各类转义）、按名称搜索、HTML 实体表。差距：**浏览与名称代差**——本工具是"查已知的字符"，对方是"探索未知字符"。
- **BabelStone Unicode 信息站**：每字符带完整名称、UTF 编码矩阵与版本引入说明。差距：名称与版本归属（该字符属 Unicode 6.0 新增）这类考据层缺席。
- 借鉴优先级：**\u 转义列 > 逐行复制 > 不可见字符高亮 > 名称（Intl.Colator 级名表可后置）> 区块浏览（远期）**。

## 可拓展性

- 短期（1 周）：行卡与反查卡加复制钮，复制格式可选（字符/`\u` 转义/实体）；`\uXXXX` 列直接加进行卡；>200 字符时顶部提示"仅解析前 200 字符"
- 中期（1 月）：NBSP/ZWJ/BOM 等控制字符红色高亮＋悬停说明；astral 区块表补全（现 25 区块缺韩文/泰文/阿拉伯文等，落入"其他区域"）；emoji ZWJ 序列识别为单行
- 远期：区块浏览模式 Tab（区块选择器＋虚拟滚动网格）；字符名称离线名表（约 2MB，同 mac-oui-lookup 的 needModel 首用下载模式）；与 special-symbols、fancy-text-generator 组成"字符工具族"互链

## 优化处方（验收标准）

1. **行卡加 `\u` 转义列＋逐行复制**：行尾复制钮默认复制 `\u4E2D` 格式。→ **验收：输入"中"点击行复制钮，剪贴板为 `\u4E2D`**
2. **不可见字符高亮**：cp 落在 0x00-0x1F、0x200B-0x200F、0x00A0、0xFEFF 时行卡加警示底色与"隐形字符"徽章。→ **验收：输入含 NBSP 的文本，对应行显示橙色徽章**
3. **截断提示**：超 200 字符时列表顶部显示"已解析前 200 / 共 N 字符"。→ **验收：输入 250 字中文，提示出现且列表停在 200 行**
4. **反查卡复制**：rev-card 加"复制字符"钮。→ **验收：输入 U+1F600 后点击复制，剪贴板为 😀**
5. **区块浏览 Tab（远期）**：顶部加"单字查询｜区块浏览"Tab，选区块出虚拟滚动网格。→ **验收：选"CJK 统一表意文字"后网格首行显示一 一 丂 丄 且滚动流畅**
