## 结论与优先级

**交互优化 + 需拓展** · P1

判据：解码把字面 `+` 静默改写为空格（`textEngine.ts:263`）属"输出悄悄错"级陷阱，错误提示为浏览器英文原文；form 模式与差异高亮对 urlencoder.org 有明确差距。

## 扣分点明细

1. 【可用性-疑似功能缺陷】解码（组件档）先 `replace(/\+/g, ' ')` 再 decodeURIComponent（`textEngine.ts:263`）——**字面 `+` 被静默改成空格**。RFC 3986 中 `+` 是组件内合法字面字符，只有 application/x-www-form-urlencoded 才把 `+` 当空格；解码 `50%2B25` 对、解码 `a+b` 错（得 `a b`），API 签名串/含 + 的 token 场景直接翻车，且无开关可关
2. 【可用性】解码非法 % 序列（如 `%E0%A4%A`）抛 URIError，TextTool 直接透出英文原文"URI malformed"（`TextTool.vue:40-41` 仅对 JSON 错误做人话化），中文用户无法理解也无法恢复
3. 【功能】无 form-urlencoded 编码档（空格→`+`）：构造 `application/x-www-form-urlencoded` 请求体时只能编码后手工把 %20 换 +；范围选项只覆盖 RFC 3986 两档
4. 【功能】无批量模式：日志中一列 URL/参数逐条处理需整段贴入再拆
5. 【灵魂】无差异高亮：urlencoder.org 类工具可直观看到哪些字符被改写成 %XX；本工具输出一整串，排查"到底哪个字符惹的祸"靠肉眼
6. 【灵魂】无空态示例（如一条带中文+空格+& 的示例 URL 一键填充），首用者不知道"组件/整个 URI"两档该选哪个
7. 【交互】与姊妹工具 punycode-converter（中文域名，`registry.ts:358`）、url-parser（`registry.ts:199`）无交叉引导：编码完想解析参数、遇到 xn-- 想还原，均需回搜索另找
8. 【灵魂】"范围"两档行为差异（encodeURI 保留 :/?# 等结构字符 vs 组件档全编码）无即时说明或对照示例，切档后输出变了但用户不知为何变——需自行试错建立心智模型

## 行业对标与差距

- **urlencoder.org**：组件/整 URI 双档之外提供"空格转 +"开关、编码前后字符数对比、大文本也保持即时。差距：**form 模式开关与 + 号处理的显式可控**。
- **CyberChef**：URL Encode 配方可选"encode all special chars/保留结构字符"多档粒度，且可紧跟 Extract/Decode 管道。差距：编码粒度白名单（只编码非字母数字汉字等）属单工具可及的真差距。
- 借鉴优先级：**修 + 号陷阱 > form 档 > 中文报错+示例 > 差异高亮 > 批量按行**。

## 可拓展性

- 短期（1 周）：解码 + 号行为加开关（"字面加号保留（RFC 3986）/当作空格（form）"默认前者）；URIError 中文映射（"含有不完整的 %XX 转义序列"）
- 中期（1 月）：form-urlencoded 编码档；差异高亮视图（被编码字符标色）；按行批量
- 远期：与 url-parser、punycode-converter 组成"URL 工作台"（解析→编码→域名转码一站式）

## 优化处方（验收标准）

1. **+ 号行为可控**：解码选项新增"+ 号处理"开关默认"保留字面 +"。→ **验收：解码 `a+b%20c` 默认得 `a+b c`；切 form 档得 `a b c`，两档结果均有说明文案**
2. **form 编码档**：范围选项加"表单（form-urlencoded，空格→+）"。→ **验收：编码 `a b&c=d` 得 `a+b%26c%3Dd`，空格为 + 而非 %20**
3. **解码报错人话化**：URIError 映射为中文并指出首个非法位置附近文本。→ **验收：粘贴 `%E0%A4%A` 提示"含不完整的 %XX 转义（位置 8 附近）"而非英文异常**
4. **空态示例**：无输入时输入框 placeholder 给示例并加"填入示例"按钮。→ **验收：点击按钮填充 `https://example.com/搜索?q=百宝工具箱&tag=a+b`，两档编码结果可对比**
5. **差异高亮**：输出区切换"纯文本/高亮"视图，被改写字符标色。→ **验收：示例 URL 高亮视图中 `%E6%90%9C` 等转义段与 `&?=/` 保留段颜色区分**
