## 结论与优先级

**需拓展 + 交互优化** · P1（列映射与导出形态是与标杆的结构性差距）

判据：相比 Datawrapper/LiveGap 缺失的不是细节而是能力面（列映射/图型/导出），标"需拓展"；粘贴即绘缺失标"交互优化"。

## 扣分点明细

1. 【功能-代差】标签列钉死第一列、其余列全部作系列（`ChartFromCsv.vue:57-80`），无 X 轴/Y 轴列选择——Datastudio 内的 ChartPanel 反而有 xCol/yCols 多选（`studio/ChartPanel.vue:91-100`），独立工具反而更弱
2. 【功能】无横向柱状图——引擎参数 `horizontal` 已存在（`chartEngine.ts:36`）但 UI 未暴露，属"有引擎无界面"
3. 【功能】导出仅 PNG 位图（:104-120），无 SVG（矢量无损）、无交互式 HTML、无尺寸/DPI 选择——Datawrapper 导出 PNG/SVG/交互三件套是标配
4. 【可用性】画布 400px 固定（:192-194）不可放大；长标签（几十类目）横向挤压不可读
5. 【交互】粘贴数据后必须手动点"生成图表"（parse 仅由按钮触发 :134）；数据变化后无自动重绘
6. 【灵魂】空数据时 400px 空画布盒常驻占屏（:155-157）；导出文件名固定"图表.png"；无"检测到 N 行 × M 列，将绘制 X 系列"的预告
7. 【美观】饼图/环图不披露"非数值项按 0 计"的口径（parseFloat 失败静默归 0，:64-66）——数据正确性风险无提示
8. 【功能】注册 desc 只写"柱状、折线或饼图"（`registry.ts:8`），实现另有环形图第四种（:29）——文案与实现不同步，搜索命中面缩水

## 行业对标与差距

- **Datawrapper**：一步一屏向导、20+ 图型、轴/注释/主题自定义、PNG/SVG/交互式导出、响应式嵌入代码。差距：**能力面代差**（云 SaaS 架构，标注天花板；纯前端可先补列映射+SVG 导出）。
- **LiveGap Charts**（纯前端）：手绘式编辑器、实时预览、多数据集管理、模板保存。差距：列映射与样式定制。
- **站内 DataStudio.ChartPanel**：列映射（X 轴 select + Y 多选 + 数值列自动识别）已实现于 `studio/ChartPanel.vue:32-43,91-100`——独立工具补映射是移植而非新开发。
- 借鉴优先级：**列映射（移植 ChartPanel 已有实现）> 粘贴即绘 > SVG 导出 > 横向柱/图题**。

## 可拓展性

- 短期（1 周）：X/Y 列 select（移植 `studio/ChartPanel.vue:91-100` 现成实现）；粘贴即绘开关；空态隐藏空画布盒
- 中期（1 月）：SVG 导出（chart.js 已注册插件可用 svg 导出方案或 canvas 2x 采样）；横向柱开关；图题输入；系列 chip 显隐
- 远期：与 DataStudio 图表面板合一（同一 chartEngine 配两套映射 UI 是重复建设）；模板/主题保存

## 优化处方（验收标准）

1. **列映射**：新增"标签列"select + "数值列"多选（默认维持现状）。→ **验收：3 列 CSV 中选第 2 列作标签后，图表类目随之切换**
2. **粘贴即绘**：监听粘贴事件 500ms 后自动生成。→ **验收：粘贴合法 CSV 后无需点击，画布自动出图**
3. **画布放大**：画布右上角"放大"按钮切换为 `min(72vh, 640px)`。→ **验收：1366×768 下放大后画布高度 ≥520px**
4. **横向柱**：chip 组加"横向柱状"。→ **验收：50 个类目的数据切横向后类目文字完整可读**
5. **导出披露**：toast 披露"N 个非数值项已按 0 计"。→ **验收：含空值列绘图后 toast 含该统计**
