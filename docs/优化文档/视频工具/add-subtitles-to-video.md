## 结论与优先级

**交互优化 + 需拓展** · P1（desc 口径兑现 + 叠加预览两大杠杆）

判据：58 分；烧录链路工程正确（extraFiles 写 subs.srt 且执行后清理，:58），但"位置调整"承诺未兑现、校对闭环缺失，与剪映"自动字幕+逐条校对"存在代差。

## 扣分点明细

1. 【口径-个性】desc 承诺"支持样式与位置调整"（registry.ts:11），实现 force_style 只有 FontSize/Outline（FfmpegSubtitles.vue:51）——位置（Alignment/MarginV/边距）UI 无入口；按 blur-video.md 三方矛盾判例登记，libass 一行 style 参数即可兑现
2. 【可用性-个性】解析失败静默：cues computed catch 后返回 []（:19-26），坏格式 SRT 只看到"0 条字幕"与灰按钮，无报错、无出错行定位
3. 【可用性-个性】编码盲区：`await f.text()`（:36）按 UTF-8 解码，字幕站常见的 GBK/GB18030 中文字幕直接烧成乱码——无编码探测（TextDecoder('gb18030') 可解）
4. 【交互】无字幕叠加预览：预览 video（FfBase.vue:169）与字幕参数零联动，哪怕"截帧+canvas 叠字幕"的静态示意都未做，全片重编码是唯一验证路径
5. 【功能】无逐条时间轴校对：不能编辑单条文本/起止、不能逐条跳转预览——烧录前校对是字幕工作流核心环节（Aegisub/剪映的立身之本）
6. 【功能】"仅转换"只出 SRT（:43 硬编码 'srt'）：解析支持 VTT/SBV 进，导出单一路径，页内亦无指引去 subtitle-converter
7. 【功能】无 ASS 输入：parseSubs 仅认 SRT/VTT/SBV（subtitles.ts:42-52）；stripCueStyling 会剥 {\...} ASS 标签（subtitles.ts:133）说明引擎想过 ASS 却没做解析
8. 【性能】音频被无谓重编码 aac 128k（:56）——烧录只动视频流，`-c:a copy` 可省时保音质
9. 【可用性-家族】执行按钮流内底部（FfBase.vue:199-206，M-14，共性-根因 4）；结果直接下载无预览（FfBase.vue:135-138）；25MB 无进度、无 beforeunload（compress-video.md 扣分 4/5）

## loadVideo 门禁简评

MP4/MOV/WebM 正常进门；AVI/WMV 挡门、MKV 依编码而定（videoEngine.ts:27-30）。加字幕素材多为创作者自拍 MP4/MOV，视频门禁影响低；真正的"门"在字幕侧——GBK 编码与 ASS 格式这两类中文用户最常见的字幕文件进不来。

## 行业对标与差距

- **剪映/CapCut**：语音识别自动出字幕→逐条校对→一键烧录全流程 3 分钟；字幕样式模板几十款。差距：**自动字幕生产端站内缺失**——audio-transcribe 只出无时间戳纯文本（AudioTranscribe.vue:157），"录音→SRT"链条断头，本工具只能吃外部 SRT。
- **Aegisub**：逐条时间轴+音波对轴+ASS 全量样式。差距：校对能力代差，ASS 互不相通。
- 借鉴优先级：**desc 口径兑现（位置/颜色）> 字幕叠加预览 > GBK 兼容 > 逐条校对 > 仅转换格式扩展**。

## 可拓展性

- 短期（1 周）：force_style 补 Alignment/MarginV/主字色；解析失败 toast+行号；convertOnly 支持选择输出格式
- 中期（1 月）：截帧+canvas 叠字幕静态预览；TextDecoder 自动探测 UTF-8/GBK；逐条列表（点击跳转预览时间点）
- 远期：与 audio-transcribe 串成"录音→SRT→烧录"站内闭环（转写侧补时间戳），对标剪映自动字幕全流程

## 优化处方（验收标准）

1. **位置与颜色兑现**：新增位置九宫格（复用 FfmpegWatermark 方案）、边距、主字色，映射进 force_style。→ **验收：选"上中"+红色后产物字幕出现在画面上中且为红色，desc 与实现一致**
2. **解析失败显性化**：parse 异常时 toast"无法识别字幕格式（第 X 行附近）"并给格式要求说明。→ **验收：粘贴 3 行乱码后出现报错而非静默 0 条**
3. **GBK 兼容**：UTF-8 解码出现 U+FFFD 时自动用 TextDecoder('gb18030') 重解。→ **验收：GBK 编码中文 SRT 烧录后为正常中文**
4. **截帧示意预览**：预览区"预览效果"按钮，截当前帧+canvas 按 force_style 绘制当前时间点字幕。→ **验收：调字号滑杆后点预览，示意图字号随之变化，无需重编码**
5. **音频直拷**：`-c:a copy` 替代 aac 转码。→ **验收：产物音轨编码与源一致，处理时长下降**
6. **家族处方 1-2**：按钮置顶＋重编码耗时预期文案（compress-video.md 处方 1/2 变体）
