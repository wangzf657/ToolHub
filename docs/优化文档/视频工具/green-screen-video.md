## 结论与优先级

**交互优化 + 需拓展** · P1（desc 口径整改 + Canvas 实时预览两大杠杆）

判据：55 分：chromakey 选型与 alpha 模式工程正确（yuva420p/auto-alt-ref 0），但 desc 卖"图片或视频背景"而实现只有纯色——按 video-color-grading.md LUT 判例属口径失信先整改；抠像工具不给预览等于蒙眼调参，是体验代差的根源。

## 扣分点明细

1. 【口径-个性】desc 承诺"替换为颜色、图片或视频背景"（registry.ts:43），实现只有纯色（outExt 二值 :17、filter_complex 只铺 color :34-36）——图片背景（loop+scale+overlay）与视频背景（双输入 filter_complex）都是 ffmpeg.wasm 完全可做的，承诺与实现直接矛盾（video-color-grading.md 判例同款）
2. 【交互-个性】零预览：similarity/blend 全靠盲调，抠像调参是"看一眼就知道过头没过头"的工作——Canvas+getImageData 对 chromakey 做 RGB 距离阈值近似预览（320px 预览分辨率实时无压力），未做；结果直接下载（FfBase.vue:135-138）
3. 【功能】无 despill：抠像后边缘泛绿/绿色反光是绿幕标准问题，ffmpeg 有 despill 滤镜未用——发丝/半透明边缘必带绿，直接影响合成可用性
4. 【功能】键色只有绿/蓝固定二选（:52-56）：幕布不标准（偏青/过曝/绿布拍蓝幕）时无路可走——chromakey 本身支持任意 0x 颜色，加一个 color input 即可
5. 【功能】alpha 模式无棋盘格预览：交付剪辑软件前无法在页内确认边缘质量；透明结果直接落下载目录
6. 【可用性-家族】执行按钮流内底部（FfBase.vue:199-206，M-14，共性-根因 4）；25MB 无进度（:184-187）；无 beforeunload；VP9 alpha 极慢无耗时预期文案
7. 【灵魂】绿幕拍摄前置条件（均匀打光/避免穿绿/留边缘）工具页零引导——抠像效果一半取决于拍摄，这是最便宜的提升项

## loadVideo 门禁简评

MP4/MOV/WebM 正常进门；AVI/WMV 挡门、MKV 依编码而定（videoEngine.ts:27-30）。绿幕素材几乎都是手机/相机直出 MP4/MOV——门禁影响低；color 模式输出 MP4、alpha 模式输出 WebM 的容器选择由实现写死（:17），无容器门禁风险。

## 行业对标与差距

- **剪映**：绿幕一键抠像+实时预览+页内直接换背景（图片/视频/纯色库）+智能边缘。差距：预览与背景图上传纯前端可追（预览标注"近似"）；一键质量是云算法差距。
- **unscreen（云 AI，天花板）**：无绿幕也能自动抠人像换背景。差距：分割模型架构天花板；纯前端可做的是诚实标注"需绿幕拍摄"+给出拍摄建议清单（扣 7）。
- 借鉴优先级：**Canvas 实时预览 > 图片背景兑现（或 desc 除名）> despill > 取色器 > alpha 棋盘格预览**。

## 优化处方（验收标准）

1. **desc 兑现或除名**：实现图片背景（上传图 loop+scale+overlay），或 desc 删除"图片或视频"。→ **验收：上传背景图产物合成位置正确（二选一交付）**
2. **Canvas 实时预览**：预览帧按 similarity/blend 做 RGB 距离近似抠像，标注"预览为近似"。→ **验收：拖相似度滑杆预览抠除范围即时变化，方向与产物一致**
3. **despill 开关**：新增 despill 滤镜开关（默认开）。→ **验收：开启后发丝边缘绿色可感知减弱，肤色区域不受影响**
4. **取色器**：键色区增加 color input（hex→0x 传入 chromakey）。→ **验收：自定义色后参数串含该 0x 色值，偏色幕布可正常抠**
5. **alpha 棋盘格预览**：alpha 模式结果区以棋盘格底渲染并显示体积徽章。→ **验收：透明模式结果页内可见边缘质量与输出体积**
6. **家族处方 1-2**：按钮置顶＋VP9 耗时预期文案（compress-video.md 处方 1/2 变体）
