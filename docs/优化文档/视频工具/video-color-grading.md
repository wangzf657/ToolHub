## 结论与优先级

**交互优化 + 需拓展** · P1（LUT 口径兑现 + CSS 实时预览两大杠杆）

判据：55 分；注册页当门面卖".cube LUT"（registry.ts:41）而组件里没有半行 LUT 代码——按 blur-video.md 三方矛盾判例属口径失信；且"调色"工具不给调色预览等于让用户蒙眼调色。

## 扣分点明细

1. 【口径-个性】desc 承诺"支持亮度对比度与 .cube LUT"（registry.ts:41），FfmpegGrading.vue 全文无 LUT 文件入口、无 lut3d 滤镜——.cube 文本解析+写入 wasm FS 是纯前端完全可做，承诺与实现直接矛盾（blur-video.md 判例同款）
2. 【交互-个性】零调色预览：eq 的 brightness/contrast/saturation 与 CSS `filter: brightness()/contrast()/saturate()` 一一对应、mono 对应 grayscale()，预览 video（FfBase.vue:169）绑一个 style 即可实时看效果（暖/冷调 colorbalance 无精确 CSS 对应，可标注"预览为近似"）——现在只能"编码→下载→播放"盲迭代
3. 【交互】空调色守卫缺失：预设"不调色"+手动全默认时 vf() 返回空串（:39-41），点执行仍全片重编码一遍原样视频——白烧几分钟还白付一次二转画质损失
4. 【功能】预设无强度：cinema=contrast1.1:saturation0.9（:19）钉死一档，"电影感淡一点/浓一点"无处调——剪映每个滤镜都有强度滑杆；pickPreset 切换还会丢弃已调滑杆（:44-47）
5. 【功能】无色温滑杆：暖/冷只有固定 ±0.12 colorbalance（:20-21），手动四滑杆缺色温/色调——调色四件套（亮度/对比/饱和/色温）缺一件
6. 【功能】无前后对比：调色价值判断全在"比原来好多少"，无分屏/擦除对比（图片类 photo-filters 已有对比范式可移植）
7. 【可用性-家族】执行按钮流内底部（FfBase.vue:199-206，M-14，共性-根因 4）；结果直接下载无预览（FfBase.vue:135-138）；25MB 无进度、无 beforeunload（compress-video.md 扣分 4/5）

## loadVideo 门禁简评

MP4/MOV/WebM 正常进门；AVI/WMV 挡门、MKV 依编码而定（videoEngine.ts:27-30）。调色需求常落在各类来源素材（含下载/其他容器），门禁影响中等；log 素材（S-Log 等）本页无还原档，属能力边界应标注。

## 行业对标与差距

- **剪映**：滤镜几十款分类陈列、每款强度滑杆、实时预览、HSL/曲线/色温参数面板。差距：**实时预览与强度滑杆纯前端可追**；滤镜数量是内容运营差距。
- **DaVinci Resolve**（桌面）：节点式调色/示波器/LUT 管理天花板。差距：架构天花板，站内对齐目标应是"LUT 导入+参数实时预览+直方图简化版"。
- 借鉴优先级：**CSS 实时预览 > LUT 兑现 > 预设强度 > 空调色守卫 > 前后对比**。

## 可拓展性

- 短期（1 周）：预览 video 绑 CSS filter（eq 四参数映射，colorbalance 标注近似）；空调色守卫；desc LUT 措辞修正
- 中期（1 月）：.cube 解析+lut3d 落地 LUT 导入；预设强度滑杆；手动补色温（colorbalance rs/bs 映射）；前后分屏对比
- 远期：直方图/示波器简化版预览组件；与图片滤镜类工具统一"效果预设"描述格式，共享强度滑杆交互

## 优化处方（验收标准）

1. **CSS 实时预览**：手动参数与 mono/cinema 预设映射为预览 video 的 CSS filter 实时生效。→ **验收：拖饱和度滑杆预览即时变化且产物与预览方向一致；暖调预览标注"近似"**
2. **LUT 兑现或除名**：实现 .cube 上传+lut3d，或 desc 删除 LUT 承诺。→ **验收：上传标准 .cube 产物色偏与 Resolve 加同 LUT 方向一致（二选一交付）**
3. **空调色守卫**：vf() 为空时点执行提示"未选择任何调色"。→ **验收：默认状态点按钮不触发编码**
4. **预设强度**：预设选中后出现 0~200% 强度滑杆（线性缩放 eq 参数）。→ **验收：cinema 强度 50% 时 contrast=1.05/saturation=0.95，产物效果弱于 100%**
5. **色温滑杆**：手动区新增 -1~1 色温（映射 colorbalance rs/bs）。→ **验收：色温 +0.5 产物偏暖方向与"暖调"预设一致**
6. **家族处方 1-2**：按钮置顶＋重编码耗时预期文案（compress-video.md 处方 1/2 变体）
