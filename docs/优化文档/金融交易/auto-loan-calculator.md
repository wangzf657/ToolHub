## 结论与优先级

**需拓展 + 交互优化** · P1

判据：无可用性硬伤；与汽车之家级标杆差在"购车总成本"决策维度，与站内贷款家族差在整合（三处重复、零互链）。

## 扣分点明细

1. 【功能】无金融方案对比：车贷核心决策是"厂商金融 0 息但收服务费 vs 银行车贷 3%~5% 有贴息 vs 信用卡分期购车"三方比价（registry.ts:373-412 单方案）——0 息方案的真实成本恰需 IRR 口径（站内 installmentIrr 引擎现成，finance.ts:247-264 未复用）
2. 【功能】杂费缺席：GPS 费/金融服务费/抵押上牌费是车贷落地价的固定组成，note 承认未计（:410）却不给输入字段——"贷款 10 万落地多花 8000"的体感算不出来
3. 【功能】提前还款未透出：引擎 amortize 已支持 prepay 参数（finance.ts:288、313-327 有完整的"期限不变月供减少"重算逻辑），车贷两年后结清是高频场景，UI 却无入口——引擎能力与产品面脱节
4. 【可用性】首付比写死 30%：车价参考行 loan/0.7（registry.ts:407 硬编码 0.7），无首付比例输入；两成首付（部分新能源厂商金融）场景参考值直接错 10 万级
5. 【实用价值】与站内贷款家族分裂：loan-calculator（实用工具，等额本息单模式）、mortgage、amortization 各自为政，本工具是其中唯一双模式却互不链接——用户搜"车贷"进来不知道还有明细表工具，搜"贷款"进来也找不到车贷特有字段
6. 【家族共性】无输入记忆（CalcTool.vue 无 localStorage）、结果不可单值复制（:55-66）；4S 店比价场景需抄月供数字
7. 【灵魂】无"总持有成本"视角：裸车+购置税+保险+利息的落地总价对比是购车决策的最终问法，工具止步于贷款三行

## 行业对标与差距

- **汽车之家/懂车帝购车计算器**：裸车价→落地价全链（购置税/保险/上牌）、厂商金融方案列表对比、月供×手续费合计。差距：**决策链完整性**——对方算"这车我总共花多少"，本工具算"月供多少"（行情/价格数据属架构天花板，成本结构输入是纯前端可实现）。
- **Calculator.net Amortization**：双还款方式对比 + 逐期明细 + 图表。差距：时间维度（明细表站内已有，缺的是链接）。
- 借鉴优先级：**杂费字段+含费月供 > 0 息方案 IRR 对比 > 首付比可调 > 提前还款入口 > 三家族互链**。

## 可拓展性

- 短期（1 周）：首付比例字段（默认 30%）；结果区底部互链 amortization-calculator（透传金额/利率/期限）；预填示例
- 中期（1 月）：GPS/服务费字段 + "贷款总成本"汇总行；厂商 0 息方案输入（手续费率）→ installmentIrr 真实年化对比行；提前还款字段（透传 prepay）
- 远期：与 loan/mortgage/amortization 合并"贷款工作台"（场景入口 + 双模式 + 明细 + 图表）；购车总成本模式（裸车/税/险字段）

## 优化处方（验收标准）

1. **首付比可调**：新增"首付比例%"字段默认 30，车价参考 = loan/(1-首付比)。→ **验收：首付改 20% 时车价参考变为 loan/0.8，hint 同步更新**
2. **杂费与总成本**：新增"GPS/金融服务费（合计）"字段，结果加"贷款总成本 = 本息合计 + 杂费"。→ **验收：填 3000 元杂费后总成本行数值 = 本息合计 + 3000**
3. **0 息方案对比**：新增"厂商贴息：每期手续费率%"可选字段，填后加"0 息方案真实年化"对比行（installmentIrr 口径）。→ **验收：36 期 0 息收 3% 服务费场景对比行显示真实年化 ≈1.6%~1.8% 且与利率方案利息差额可见**
4. **提前还款**：新增"第 N 期提前还 X 元"可选输入，输出"省息金额与剩余月供"。→ **验收：36 期第 12 期提前还 2 万后新月供 < 原月供、省息 > 0（复用 amortize prepay）**
5. **家族互链**：结果区加"查看逐期还款明细 →"跳 amortization-calculator 并透传参数。→ **验收：点击后明细页金额/利率/期限与本页一致**
