## 结论与优先级

**需拓展 + 交互优化** · P1

判据：无可用性硬伤；"三兄弟"问题（auto/renovation/balloon 与 mortgage/loan 的关系）结论：三者各有真差异（双模式/手续费 IRR/尾付结构），非 SEO 克隆，但全部与 mortgage/loan/amortization 零互链，家族整合缺位。

## 扣分点明细

1. 【功能】无尾付比例敏感度：改一次尾付比例看一次结果，没有"10%/20%/30%/40% 尾付的月供与利息总额"并排小表——气球贷决策的第一问恰是"尾付留多少合适"
2. 【功能】无再融资测算：尾付到期是气球贷的生死题，"到期筹不齐→再融资 N 年新月供多少"（finance.ts:296-299 年金公式现成）是直接续接场景，工具止步于风险提示文案（:480）
3. 【口径】末期利息近似未给误差边界：totalInterest 用"尾付单月利息"估算（registry.ts:471 注释"近似"），note 只说"估算"（:483）未说明与逐月复利精确口径的偏差量级——金额大期限长时利息总额可差数百至千元级
4. 【可用性】风险提示行无视觉差异化：风险行 primary:false（:480）落入普通行样式，与"对比等额本息"这类中性信息混排——最重要的行最不显眼（CalcTool 结果行体系无 warn 样式，属家族级缺失）
5. 【交互】期限为自由数字输入（registry.ts:461 type number 默认 36）非 select：与 auto/renovation 的期数 select（:380,425）风格分裂，同家族两套输入范式
6. 【家族共性】无输入记忆、结果不可单值复制（CalcTool.vue:55-66）；与 mortgage/loan/amortization 零互链——气球贷用户大概率也想知道"如果选等额本息逐期明细长什么样"
7. 【灵魂】无场景化预设：气球贷常见于"预期 3~5 年内换房/卖车"人群，无"预计 X 年后卖出"输入联动尾付建议（卖出时点=尾付时点是该产品的使用前提）

## 行业对标与差距

- **Calculator.net Balloon Payment Calculator**：完整摊销表（逐期利息/本金/余额）、尾付金额在时间轴上标注、可选"尾付前月供按摊销期计算"vs"按实际期限计算"两种口径。差距：**口径可选与时间维度**——对方让用户看清"尾付怎么长出来的"，本工具只给三个汇总数。
- **东方财富房贷工具**：气球贷与等额本息/本金并排三方案对比表。差距：方案数量（本工具只有 1v1 对比）。
- 借鉴优先级：**尾付比例敏感度小表 > 再融资月供测算 > 风险行 warn 样式 > 期限 select 统一 > 摊销入口互链**。

## 可拓展性

- 短期（1 周）：风险行加视觉警示（前缀 ⚠ 或 accent-err 背景）；期限改 select（12/24/36/48/60/120）；预填示例（50 万/4.0%/36 期/30%）
- 中期（1 月）：尾付比例敏感度行（四档并排月供+利息总额）；再融资输入（剩余尾付按 N 年重摊销→新月供）；note 补近似误差量化说明
- 远期：与 mortgage/loan 合并"贷款工作台"（气球贷作为还款方式之一而非独立页）；卖出时点联动（预期持有期 < 期限时自动提示"到期前卖出则尾付由处置款覆盖"）

## 优化处方（验收标准）

1. **敏感度小表**：结果区加一行四档对比"尾付 10%/20%/30%/40%：月供 X→Y、利息总额 A→B"。→ **验收：改利率后四档数值 300ms 内同步刷新且月供随尾付比例递减**
2. **再融资测算**：新增"到期再融资年限（可选）"字段，输出"再融资后新月供"。→ **验收：50 万贷 30% 尾付、按 3 年再融 4.0% 时新月供 ≈5 万/36 期年金值，与手工验算一致**
3. **风险行警示样式**：风险提示行加 ⚠ 前缀与 err 色边框。→ **验收：该行边框色与其余结果行可区分（截图对比）**
4. **口径量化**：note 追加"末期利息按尾付单月利息估算，与逐月精确口径在典型场景（≤5 年）误差 <1%"。→ **验收：note 含量化说明；36 期 30% 尾付场景精确复算利息总额与显示值相对误差 <1%**
5. **家族互链**：结果区加"对比等额本息逐期明细 →"跳 amortization-calculator 并透传金额/利率/期限。→ **验收：点击后明细页参数一致**
