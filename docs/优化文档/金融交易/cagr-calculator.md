## 结论与优先级

**需拓展 + 交互优化** · P2

判据：无可用性硬伤且极简达标；但相比 Omnicalculator 缺反向计算与序列输入，功能纵深单薄（需拓展为主），边界引导为辅。

## 扣分点明细

1. 【功能】无反向计算：只能"期初→期末"正向；"目标年化 10%、本金 10 万、5 年后该是多少"或"几年能翻番"无法反推——Omnicalculator/cagrcalculator.net 类工具双向是标配
2. 【可用性】零值边界静默：begin≤0 或 years≤0 时 cagr() 返回 0（finance.ts:117），页面显示"CAGR 0.00%"而非引导；begin=0 时增长倍数 0.00×（registry.ts:123）——语义上"没增长"与"无法计算"被混为一谈
3. 【功能】无现金流失真警告：期间有加仓/分红时简单 CAGR 严重失真（如 5 年从 10 万到 15 万但中途追加 3 万，真实年化远低于 8.45%），本工具无任何提示；正确工具 irr-npv-calculator 同分类却零互链
4. 【灵魂】无说人话换算：增长倍数 2.50× 旁边没有"约 X 年翻一番"（ln2/ln(1+g)）——CAGR 的传播价值恰恰在"几年翻倍"的直觉
5. 【功能】无序列输入：只能算单段首尾；逐年净值批量算逐年/滚动 CAGR 场景缺失——同目录 SharpeRatio.vue 已有"粘贴收益率序列"输入先例可复用
6. 【家族共性】无输入记忆、结果不可单值复制（CalcTool.vue 全文无 localStorage、:55-66）
7. 【交互】分数年口径未披露：years 支持 0.5 步进（registry.ts:119）但 note 只写"复利平滑"，半年按 (end/begin)^(1/0.5) 年化外推的口径未说明
8. 【实用价值】算完即止无延伸：无"按此增速存下去 10 年后是多少"的前瞻联动（站内 compound-interest-calculator 可承接），页面亦无相关工具引导——CAGR 的常见用途恰恰是拿增速去做外推

## 行业对标与差距

- **Omnicalculator CAGR**：正向/反向双模式、每参数口径出处、结果附中间步骤（(end/begin)^(1/n) 逐项展开）——差距：双向与教学化；本工具 note 已披露公式但无中间过程。
- **cagrcalculator.net**：首尾日期输入自动折算年限（日→年）、多资产并排对比表——差距：年限自动折算（用户手算"从 2020-06 到 2025-03 是几年"易错）与并排比较。
- 借鉴优先级：**反向计算模式 > 零值边界引导 > 翻番年数说人话行 > 与 irr-npv 互链 > 日期自动折算**。

## 可拓展性

- 短期（1 周）：begin≤0/end<0 时显示"期初价值需为正数"引导行；结果加"约 X 年翻一番"；底部互链 irr-npv-calculator（注明"中途有现金流请用 IRR"）
- 中期（1 月）：反向模式切换（求期末值/求所需年限/求期初）；粘贴逐年序列输出逐年 CAGR 小表（复用 SharpeRatio 输入形态）
- 远期：与 sharpe-ratio-calculator、irr-npv-calculator 组成"收益质量工作台"（序列输入 → 逐年 CAGR → 夏普 → 现金流 IRR）

## 优化处方（验收标准）

1. **反向计算**：模式 select"求 CAGR / 求期末值 / 求所需年限"，切换后对应字段联动。→ **验收：10000 起、目标 10%、5 年 → 期末值 16,105.10（容差 ±0.01）；求年限模式 10000→20000、10% → 7.27 年（容差 ±0.05）**
2. **零值边界引导**：begin≤0 或 years≤0 时显示"期初价值与年数需为正数"引导行，不再显示 0.00%。→ **验收：begin 填 0 后主结果行为引导文案**
3. **翻番说人话**：结果区追加"按此增速约 X 年翻一番"。→ **验收：10000→25000/5 年（CAGR 20.11%）显示"约 3.8 年翻一番"（容差 ±0.1）**
4. **IRR 互链**：结果区底部注"期间若有加仓/分红，CAGR 会失真，请改用 IRR/净现值计算器 →"并链接。→ **验收：链接可达 /t/irr-npv-calculator**
5. **日期折算**：年限字段旁支持"起止日期"替代输入（日历差/365.25）。→ **验收：2020-06-01 至 2025-03-01 自动填年数 4.75（容差 ±0.02）**
