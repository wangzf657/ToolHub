## 结论与优先级

判据：无可用性硬伤（M-07 家族口径首屏可达）；但相比币安/OKX 合约计算器缺杠杆/强平维度属功能面悬殊（需拓展），note 缺失违反金融类规约硬要求（交互优化优先项）。

## 扣分点明细

1. 【功能】无杠杆/合约维度：compute 全程现货口径（registry.ts:30-56），无杠杆倍数、无强平价（爆仓价）、无维持保证金率——币圈交易决策的高频问题是"10 倍杠杆这次能扛到哪"，本工具只回答现货盈亏
2. 【灵魂-规约】无 note 计算口径：registry.ts:22-57 的 calcDef 未提供 note 字段（违反 AGENTS.md"金融工具需附计算口径"硬要求；对照同家族 installment-rate-calculator registry.ts:363 的口径样板），"单边手续费（%）"实际按买卖双边各计一次（:38 be=buy×(1+fee×2)）只能靠 hint 侧写
3. 【可用性】空态显示全 0 结果：币数量模式下 buy/qty 全空 → Number('')=0 → "持币数量 0.000000 / 保本卖出价 0.00"照常展示（registry.ts:33-43），NaN 守卫（CalcTool.vue:25）不触发——打开即见误导性零值
4. 【功能】无币种语境与货币符号：无 BTC/ETH 币种选择，money() 输出纯数字无符号（finance.ts:187-189），"投入美元"模式（registry.ts:26）暗示 USD 但结果行不带 $，分享比价场景易误读
5. 【交互】ROI 只有持仓期百分比（:51）：无按持有天数折算年化，"拿了一个月 +9.79%"到底好不好缺乏参照
6. 【家族共性】无输入记忆、结果行不可单值复制（CalcTool.vue 全文无 localStorage、:55-66 仅展示）——反复试算不同卖价时全量重填
7. 【灵魂】无预填示例：五字段全空打开即见零值（扣 3 的另一面），预填一组 30000/33000/0.5 币/0.1% 示例可让用户打开即懂
8. 【可用性】两种结果态无状态标注：卖价留空=持仓态 3 行、填卖价=已平仓态 5 行（registry.ts:37-55），切换时结果行数与主结果含义双双改变，却无"当前口径：持仓中/已平仓"标注——截图分享时对方无从判断

## 行业对标与差距

- **币安/OKX 合约计算器**：杠杆倍数、开仓均价、强平价、维持保证金率、资金费率累计、多/空双向——差距：**合约维度代差**（实时强平价需行情属架构天花板；按全仓近似的静态强平价纯前端可实现）。
- **CoinGecko/CMC 计算器**：币种语境、按币种的历史定投回看、组合视角——差距：币种语境与分享友好度（本工具结果无币名无货币符号）。
- 借鉴优先级：**补 note 口径 > 杠杆+强平价（静态近似）> 货币符号与币种名 > 空态守卫/预填 > ROI 年化折算**。

## 可拓展性

- 短期（1 周）：补 note（双边费、未含滑点/资金费率/税费）；$ 前缀或币种名输入；空态守卫+预填示例；结果单值复制（家族共性处方）
- 中期（1 月）：杠杆模式（1x 现货/2~10x 全仓），结果区加静态强平价与"强平风险"提示行；ROI 按持有天数年化
- 远期：与 stock-average-calculator 共享"交易流水+摊薄引擎"（stock-average-calculator.md 远期已立项"持仓成本工作台"），币圈多笔买入摊薄与现货盈亏统一

## 优化处方（验收标准）

1. **补 note 口径**：calcDef 增加 note，写明"单边费率按买卖双边各计一次；保本价=买入价×(1+2×费率)；未含滑点、资金费率与税费"。→ **验收：页面底部出现该 note，且保本价 hint 与 note 口径一致**
2. **杠杆模式**：加"杠杆倍数"select（现货/2x/5x/10x，全仓近似），结果区新增"估算强平价"与红色"强平风险"提示行。→ **验收：入场 100、10 倍全仓时强平价 ≈ 91（容差 ±1，忽略维持保证金），且提示行可见**
3. **货币符号**：结果行金额统一带 $ 前缀（qtyType=usd 时）或按币种名显示。→ **验收：净盈亏行显示形如 +$1,468.50，复制得到纯数字 1468.50**
4. **空态守卫+预填**：buy 或 qty 为空时显示"请填写买入价与数量"引导行；默认预填 30000/33000/0.5 币/0.1%。→ **验收：清空字段显示引导文案；打开页面即见净盈亏 +$1,468.50、ROI 9.79%**
5. **ROI 年化**：新增"持有天数（可选）"字段，填写后追加"年化 ROI"行（复利口径 (1+ROI)^(365/天)−1）。→ **验收：上例填 30 天后年化 ROI ≈ 212%（(1.0979)^12.17−1，容差 ±5%）**
