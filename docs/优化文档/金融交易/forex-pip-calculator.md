## 扣分点明细

1. 【可用性-疑似缺陷】选 USD/JPY 后保持默认 rate=1，结果"每点价值 $1000"（registry.ts:294-296：pipValue=0.0001×100000×1×1 再 ×100）——真实值（USDJPY≈150 时）约 $6.67，**高估 150 倍**；label"直盘填 1"（:290）在外汇术语里 USDJPY 正是直盘，按引导填 1 必错，无任何警告
2. 【功能-疑似缺陷】note 指引与代码双重补偿冲突：note 说"JPY 对点差为 0.01"（:304），用户照改 pipSize=0.01 后代码再 ×100（:295-296），双重补偿得 $100000/手的荒谬值——该 ×100 补偿假定 pipSize 保持 0.0001，与 note 指引互斥
3. 【功能】无账户币种换算：输出恒为 $（:298-301），人民币账户要自己再乘 USDCNH；babypips 标配"账户币种"下拉一键换算
4. 【功能】货币对 select 不联动 pipSize/rate：切换 EURUSD→GBPUSD 数值完全不变，select 沦为装饰（:284-288 仅取 includes('JPY')），用户自然预期"选对即联动"
5. 【交互】rate 需手工外源获取：工具不提供"填 USDJPY 现价自动换算"入口，用户要去别处查汇率再算倒数——换算链断在站内
6. 【家族共性】无输入记忆、结果行不可单值复制（CalcTool.vue:55-66 仅展示）；外汇比价场景复制数字到聊天/笔记高频
7. 【实用价值】6 个直盘预设无交叉盘（EUR/JPY、GBP/JPY 是高频交易对），pipSize/rate 全手填模式下预设价值归零

## 行业对标与差距

- **babypips Pip Value Calculator**：货币对全表、账户币种选择、按报价即时换算并解释推导过程（教学内容与工具同页）。差距：**换算链闭环**——对方"选两下出答案"，本工具"选对+查汇率+手算倒数+防双重补偿"四步。
- **Myfxbook / TradingView 风险工具**：点值→止损距离→手数反向推导（给定风险金额算手数），与仓位管理联动。差距：本工具只做正向点值，站内 position-size-calculator（registry.ts:86-109）做了股票版手数反推，外汇版缺失且两工具零互链。
- 借鉴优先级：**JPY 对自动联动 pipSize/rate > 账户币种换算 > 交叉盘与全对覆盖 > 反向手数推导 > 与 position-size 互链**。

## 优化处方（验收标准）

1. **联动修复**：选择 USDJPY 时 pipSize 自动变 0.01 且新增"USDJPY 现价"字段自动算 rate=1/现价。→ **验收：选 USDJPY 填现价 150，每点价值（标准手）显示 ≈$6.67，误差 <0.01**
2. **双重补偿消除**：pipSize 由用户显式修改时不再叠加 ×100。→ **验收：pipSize=0.01 + USDJPY + rate=1/150 结果与 pipSize=0.0001 + JPY 补偿路径结果一致**
3. **账户币种**：新增"账户币种"select（USD/CNY），CNY 时按用户填的 USDCNH 汇率换算并标注。→ **验收：切换 CNY 后结果单位变 ¥ 且 note 说明换算口径**
4. **交叉盘预设**：choices 扩至 EUR/JPY、GBP/JPY、EUR/GBP 等 ≥10 对。→ **验收：选 EUR/JPY 后 hint 给出所需两个汇率字段的填写指引**
5. **互链**：结果区底部加"→ 用仓位规模计算器反推手数"链接并透传点值。→ **验收：点击后 position-size 页可见点值参数被带入（或给出手填提示）**
