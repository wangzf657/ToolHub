## 结论与优先级

**需拓展 + 交互优化** · P1

判据：相比 OptionStrat 缺策略预设与到期前曲线属功能悬殊（需拓展）；图表高度/区间固定、导入闭环缺失属交互摩擦（交互优化）。

## 扣分点明细

1. 【功能】无策略预设：跨式/勒式/蝶式/价差需逐腿手搭——OptionStrat/optionvisualizer 类工具均有一键模板，新手第一障碍恰是"不知道该搭几条腿、行权价怎么错开"；预设还能顺带解决教学语境
2. 【功能】只有到期线：曲线按到期内在价值（legPnl :30-41 无时间项），无 T+0/到期前损益曲线——时间价值衰减这一期权核心直觉完全不可见（hint :184 已诚实披露，属已知边界而非隐藏缺陷）
3. 【可用性】图表与区间固定：chart-box 钉 380px（OptionsPayoff.vue:266，共性-根因 2 家族）；价格区间固定现价 ±40%（:44-47）不可调——远月深度虚值/末日轮策略的尾部在区间外，图上看不到真实风险
4. 【交互】导出无导入：参数 JSON 可导出（:109-117）但无导入入口——分享/复用闭环断一半，导出的 JSON 只能手工誊抄回表单
5. 【可用性】数量无校验：qty 仅 HTML min=1（:145，手输可绕过），0/负数直接进公式（:33 qty 线性乘）——填 0 后图表变平线、最大盈亏显示 $0.00 无任何提示
6. 【功能】无组合希腊字母与保证金视角：卖出腿的保证金占用、组合 Delta 净额不显示（OptionStrat 标配；实时行情属架构天花板，静态参数净 Delta 纯前端可实现）
7. 【可用性】多腿时图表被推下屏：每腿一行（~38px）+统计区，4 腿以上图表起点跌破 768 视口（M-07 家族口径推算），编辑与看图来回滚动
8. 【功能】无盈亏概率视角（POP）：OptionStrat 按现价与 IV 给"到期落在盈利区间的概率"——本工具只有确定性到期线；静态参数下用正态近似即可纯前端实现（IV 可接 blackScholes 引擎同款输入），是可逼近而非天花板项

## 行业对标与差距

- **OptionStrat**：策略模板库、T+0/到期双曲线、实时 IV 与希腊字母、盈亏概率（POP）、按利润区间着色（实时数据属架构天花板；双曲线可基于站内 blackScholes 引擎 finance.ts:34 静态实现）——差距：**时间维度与概率视角代差**。
- **东方财富期权计算器**：四大家族策略模板、按合约代码取真实盘口（行情属天花板）——差距：模板化与中文语境。
- 借鉴优先级：**策略预设 > 导入 JSON > 区间可调 > 净 Delta 行 > T+0 曲线（中期）**。

## 可拓展性

- 短期（1 周）：导入 JSON（与导出配对，file input 读取后恢复 legs/spot）；qty≤0 行内红字；区间 select（±20%/±40%/±60%/±100%）
- 中期（1 月）：策略预设 chips（单腿/牛市价差/跨式/勒式/蝶式，一键填充 2~4 腿）；组合净 Delta 行（复用 blackScholes 引擎按当前价估值）；图表高度弹性（calc(100vh−…) 下限 380px）
- 远期：T+0 到期前曲线（按剩余天数参数化）；与 black-scholes-calculator 组成"期权工作台"（定价→策略→损益→希腊字母）

## 优化处方（验收标准）

1. **策略预设**：编辑器上方加预设 chips（单腿 Call/单腿 Put/牛市价差/熊市价差/跨式/勒式/蝶式）。→ **验收：点"牛市价差"自动生成买低行权 Call+卖高行权 Call 两腿，图表变斜坡封顶形**
2. **导入 JSON**：加"导入参数"按钮，读取导出格式文件恢复 spot/legs/stock。→ **验收：导出默认腿的 JSON 再导入，图表与统计瓦片数值与导出前一致**
3. **区间可调**：加"图表区间"select（±20%/±40%/±60%）。→ **验收：选 ±20% 后 X 轴两端=现价×0.8 与×1.2，盈亏平衡点若在区间外则标"—"**
4. **数量校验**：qty≤0 时腿行红字"数量需 ≥1"且统计瓦片显示"—"。→ **验收：填 0 后最大盈利不再显示 $0.00 而显示"—"+红字**
5. **图表弹性高度**：chart-box 高度改 `calc(100vh - 360px)` 下限 380px。→ **验收：1366×768 下无需滚动页面即可见完整图表（含 X 轴标签）**
