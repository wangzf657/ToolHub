## 扣分点明细

1. 【功能】无杠杆/保证金换算：期货、合约与融资用户需自行折算保证金占用——TradingView 仓位计算器有保证金/杠杆字段，BabyPips 版有账户币种与手数换算；本工具结果只到"股数+市值"
2. 【功能】多空方向隐式：Math.abs(entry−stop)（registry.ts:98）使做空也得到正确股数，但 UI 无"多/空"标注——新手不知道做空时止损价应高于入场价，填反了结果照出且无提示
3. 【交互】无默认值与快捷档：riskPct 无默认（registry.ts:92 仅 placeholder"如 1"），行业惯例单笔 1% 风险应预填；无 0.5%/1%/2% 快捷 chips——对比敏感度最高的参数让用户手填
4. 【可用性】仓位超账户无预警：占账户比例行照常显示百分比（registry.ts:104），止损极近时 shares×entry 可远超账户总值（隐含杠杆），无红字"该仓位需杠杆/超出账户"提示
5. 【功能】无费用口径：佣金/滑点未计入每股风险，实际单笔亏损将略超预设风险；note（registry.ts:108）未披露此简化——金融口径规约的诚实性打折
6. 【家族共性】无输入记忆、结果不可单值复制（CalcTool.vue 全文无 localStorage、:55-66）——风控参数（账户/风险%）长期稳定却每次重填
7. 【灵魂】无 R 语言语境：结果给"单笔最大亏损"金额但无"这是 1R，止损被打掉=亏 1R"的交易心理框架注释——该品类教学价值的一半在 R 概念
8. 【功能】仅支持"股数"口径：无手数（期货/外汇）、张数（期权/可转债）、币数（加密）单位适配，money() 输出无货币符号（finance.ts:187-189）币种语境未声明——BabyPips 版按手数+账户币种换算，本工具只服务股票现货用户

## 行业对标与差距

- **TradingView 风险计算器**：账户、风险占比、入场/止损/目标三价位一体、盈亏比与期望值联动、保证金与杠杆、多空切换——差距：**风控参数化深度**（本工具是"只算股数"的单引擎切片；三价位联动部分站内 risk-reward-calculator 已有，两工具零互链）。
- **BabyPips Position Size**：账户币种、货币对手数、点值换算的教学式分步引导——差距：新手教育语境（本工具无一处解释"为什么是 1%"）。
- 借鉴优先级：**1% 默认+快捷档 > 多空方向显式 > 超账户预警 > 与盈亏比计算器互链透传 > 杠杆换算**。

## 可拓展性

- 短期（1 周）：riskPct 默认 1；0.5%/1%/2% 快捷 chips；note 补"未含佣金与滑点"；页面底部与 risk-reward-calculator 互链
- 中期（1 月）：多/空 select 显式方向（做空校验止损>入场）；占账户比例 >100% 红色预警行；账户金额记忆（localStorage，风险参数跨会话复用）
- 远期：与 risk-reward-calculator 合并"交易风控工作台"（三价位 → 盈亏比 → 期望值 → 仓位股数一条龙，共享 entry/stop 参数）

## 优化处方（验收标准）

1. **1% 默认+快捷档**：riskPct default 1，字段下加 0.5%/1%/2% 三枚 chips。→ **验收：打开页面 riskPct=1；点击 2% 后单笔最大亏损立即翻倍**
2. **多空方向**：新增"方向"select（做多/做空），做空时校验止损>入场并即时提示。→ **验收：选做空、填入场 25.5/止损 24 时显示"做空时止损价应高于入场价"且不输出误导股数**
3. **超账户预警**：占账户比例 >100% 时该行转红并追加"需杠杆资金，注意强平风险"。→ **验收：入场 25.5/止损 25.49（每股风险 0.01）时可见红色预警**
4. **参数记忆**：账户总值与风险%存 localStorage（key 前缀 toolhub）。→ **验收：填 100000/1% 后刷新页面两值保留**
5. **互链透传**：结果区底部加"计算这笔交易的盈亏比 →"跳 /t/risk-reward-calculator 并带入 entry/stop。→ **验收：跳转后盈亏比页入场价 25.5、止损价 24 已自动填入**
