## 结论与优先级

**交互优化 + 需拓展** · P1

判据：空态"保本胜率 100%"误导属可用性扣分（交互优化优先项）；note 缺失违反金融口径规约；价格阶梯与仓位联动属拓展。

## 扣分点明细

1. 【可用性】空态误导：四字段全空 → entry=stop=0 → risk=0 → rr=0 → 显示"盈亏比 1 : 0.00"primary + "保本胜率 100.0%"（registry.ts:253-263，breakEven=100/(1+0)），NaN 守卫（CalcTool.vue:25）不触发——打开即宣称"零风险保本胜率 100%"，方向性误导
2. 【灵魂-规约】无 note 计算口径：registry.ts:241-270 calcDef 未提供 note 字段（违反 AGENTS.md 金融口径硬要求；对照同家族 installment-rate-calculator registry.ts:363 样板）——"未含手续费/滑点/印花税""保本胜率=1/(1+盈亏比)""期望值=胜率×单股回报−败率×单股风险"三项口径均未披露
3. 【交互】方向书写易误读："盈亏比（回报:风险）1 : 2.00"（registry.ts:261）把 1 固定在风险位——业内更常见书写是"2:1 R:R"（回报值前置）或"R 2.0"，快读用户易把 1:2 与 2:1 记反
4. 【功能】无仓位联动：只回答"值不值得做"不回答"做多大"——entry/stop 与 position-size-calculator 完全同参，两工具零互链零透传，风控自检要手动抄价
5. 【功能】无费用与分批目标：佣金/滑点未计入单股风险（实际盈亏比低于显示值）；单一目标价，"一半 1:1 一半 1:3"分批止盈的加权 RR 无法算
6. 【交互】无默认值：四字段全空（registry.ts:245-249），预填一组 25.5/24/30 典型值可让用户打开即懂字段含义
7. 【可用性】三价位无视觉标尺：止损/入场/目标的距离关系全靠数字脑补——TradingView 多空工具用双色区块直观显示风险/回报面积，价格阶梯图是该品类标配视觉（chartEngine 站内现成）
8. 【功能】无做空语境：Math.abs（registry.ts:253-254）让"止损在上方、目标在下方"的做空单也"碰巧"算出正确盈亏比，但无多/空方向标注与校验——方向填反（做多却填止损高于入场）时同样照常输出

## 行业对标与差距

- **TradingView 多空仓位工具**：图表上直接画风险/回报双色区块、按账户风险%自动算仓位、盈亏比与目标价联动拖拽（图表联动属架构天花板；静态价格阶梯图纯前端可实现）——差距：**风险/回报的空间直觉**。
- **BabyPips 风险回报计算器**：费用计入、多目标分批、教学式步骤引导——差距：口径完整性与新手教育。
- 借鉴优先级：**空态守卫+note（P1）> 价格阶梯图 > 与仓位计算器互链透传 > 分批止盈加权 > R 倍数书写规范**。

## 可拓展性

- 短期（1 周）：补 note（三项口径）；空态守卫行；预填 25.5/24/30/55%；盈亏比行追加"R 倍数 2.0"副表述
- 中期（1 月）：chartEngine 价格阶梯（三价位横向标尺，风险段红/回报段绿）；"按 1% 风险算仓位 →"跳 position-size-calculator 透传 entry/stop；手续费率输入修正实际 RR
- 远期：分批止盈多目标（每段比例+价格，加权 RR 与加权保本胜率）；与 position-size/kelly 组成"交易风控工作台"

## 优化处方（验收标准）

1. **空态守卫**：entry/stop/target 任一为空或相等导致 risk=0 时显示"请填写入场、止损与目标价（三者需互不相等）"。→ **验收：清空字段显示引导行，不再出现 1:0.00 与 100.0%**
2. **补 note 口径**：calcDef 加 note"未含手续费与滑点；保本胜率=1÷(1+盈亏比)；期望值=胜率×单股回报−(1−胜率)×单股风险"。→ **验收：页面底部显示该 note，与两处 hint 口径一致**
3. **预填示例**：入场 25.5/止损 24/目标 30/胜率 55 为默认值。→ **验收：打开即见盈亏比 1 : 3.00、保本胜率 25.0%、每笔期望收益 +1.80（0.55×4.5−0.45×1.5，容差 ±0.01）**
4. **价格阶梯图**：结果区下方接 chartEngine 横向标尺图：止损/入场/目标三标记点，入场左侧风险段红色、右侧回报段绿色。→ **验收：上例中标尺可见三价位且红色段长度:绿色段=1:3**
5. **仓位联动**：结果区底部"按 1% 风险算这笔仓位 →"跳 /t/position-size-calculator 透传 entry/stop。→ **验收：跳转后仓位页入场价 25.5、止损价 24 已填**
6. **R 倍数副表述**：盈亏比行 hint 追加"即 3R 交易（每承担 1 份风险博取 3 份回报）"。→ **验收：hint 随盈亏比数值联动更新**
