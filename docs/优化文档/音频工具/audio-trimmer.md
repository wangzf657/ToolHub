## 结论与优先级

**交互优化** · P1（波形拖选是单点最大杠杆）

判据：61 分；可用性尚可但交互便捷性 8/15 明显偏低——"裁剪音频"的核心动作是"选一段"，本工具却让用户用数字键选；波形已在页面上，只差让它可交互。

整改优先序：波形拖选+播放头（P1，最大杠杆）→ mm:ss 显示与输入 → 编码进度 → 偏好记忆（P2）。

## 扣分点明细

1. 【交互-硬伤边缘】波形图纯展示不可交互（`AudioToolBase.vue:70-81` 仅 waveformCanvas 绘制+ResizeObserver 重绘，无任何 pointer 事件），mp3cut.net 的核心交互"在波形上拖出选区/拖边界"完全缺失
2. 【交互】起止点靠手输数字（`AudioTrimmer.vue:65-80`，step 0.01），配合试听按钮反复校准一个切点要 4~6 次往返；无"设为当前播放位置"快捷键/按钮
3. 【灵魂】解码与 MP3 编码无进度反馈：AudioToolBase 仅"正在解码音频…" spinner 文案（:107），AudioTrimmer 产物阶段仅"正在处理，请稍候…"（AudioToolBase.vue:119）；5 分钟音频 lamejs 编码约需 10~20 秒，无百分比
4. 【可用性】试听播放无停止按钮、无播放头位置显示——`playBuffer`（audioEngine）播起就走，选区长了用户只能等它放完或刷新
5. 【功能】淡入淡出是秒数输入而非波形曲线，且试听/导出才生效，无实时预览提示"淡出 2s"在波形上的范围
6. 【交互】起点默认 0、终点默认全长（:20-24）合理，但"终点 0 时裁剪区间无效"的错误要到点试听或导出才报（:45）；输入 0-0 无即时校验提示
7. 【交互】起止点只接受纯秒数（type=number step=0.01，:67-71），长音频要输 3600+ 的数字且换算困难——mp3cut.net 全程 mm:ss 展示，本工具连显示都是秒（fmtTime 仅在选区文案里出现，:87）
8. 【交互】输出文件名不可自定义（`outName` 由源文件名派生，AudioTrimmer.vue:59），铃声场景想命名"我的铃声.mp3"做不到
9. 【灵魂】导出格式/码率/淡入淡出不记忆，连续裁多段铃声每次都要重设

## 行业对标与差距

- **mp3cut.net（123apps）**：加载即出全宽波形，拖蓝色选区手柄定界、点波形移动播放头、全流程单屏无滚动、"剪切 selected/删除 middle"两种模式一键切换。差距：**选区交互代差**——对方 2 次拖拽完成的事，本工具要 6 次数字输入。
- **vocalremover.org 裁剪器**：波形+播放头同步、A/B 键标记起点终点（键盘操作）。差距：键盘效率与播放头可视化。
- 站内动线：裁剪完常接"转格式/合并"，mp3cut.net（123apps 全家桶）结果页直接挂转换/合并入口；本工具裁完即下载，audio-convert/merge-audio 要用户重新找入口拖文件。
- 借鉴优先级：**波形拖选区 > 点击定位播放头 > 播放头显示+停止按钮 > mm:ss 输入显示 > 编码进度百分比**。

## 可拓展性

- 短期（1 周）：波形加 pointer 事件——点击定位播放头、两端拖拽手柄改 start/end（同步数字框）；播放头红线+停止按钮
- 中期（1 月）：encodeMp3 移入 Worker 或分块编码并报进度；"删除中段保留首尾"模式切换；淡入淡出范围在波形上以阴影标示
- 远期：多段标记列表（一次标 5 段、批量导出）；与 audio-convert/vocal-remover 共建"音频工作台"（模式 E）

## 优化处方（验收标准）

1. **波形拖选区**：波形图两端渲染可拖手柄（≥24px 触控），拖动实时更新起止数字框与选区时长文本。→ **验收：拖动终点手柄从全长到 1:30，数字框与"共 90.00 秒"同步变化，无需手输**
2. **点击定位播放头**：点波形任意位置即从该处播放选区，播放头红线跟随音频进度移动。→ **验收：点击波形 50% 处后音频从对应时刻发声，红线实时移动；播放中有"停止"按钮可中断**
3. **编码进度**：MP3 导出显示百分比（按已编码样本数/总样本数估算）。→ **验收：导出 3 分钟 MP3 期间进度从 0% 递增到 100%，完成后自动下载**
4. **即时区间校验**：终点 ≤ 起点+0.01 时，输入框即时标红并提示"终点需大于起点"，试听/导出按钮禁用。→ **验收：输入 start=10 end=5 后输入框红色提示出现，按钮禁用态生效**
5. **淡入淡出可视化**：波形选区两端按淡入/淡出秒数渲染渐变阴影。→ **验收：设置淡出 2s 后，选区末端 2s 区域显示渐隐阴影；改回 0 阴影消失**
6. **mm:ss 双向输入**：起止点支持"1:30"或"90"两种输入格式（解析后归一到秒），选区文案保持 mm:ss。→ **验收：输入 1:30 后等效 90 秒；选区文案显示 1:30 而非 90 秒**
7. **输出文件名**：DownloadButton 旁加文件名输入框（默认沿用 outName）。→ **验收：改名为"我的铃声"后下载文件为 我的铃声.mp3**
8. **偏好记忆**：格式/码率/淡入淡出写入 localStorage，下次自动回填。→ **验收：设 WAV+128kbps 刷新后保持**
