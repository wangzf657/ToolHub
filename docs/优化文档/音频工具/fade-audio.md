## 扣分点明细

1. 【功能】"指数"曲线名实不符：实现为 t³ 幂曲线（`FadeAudio.vue:31` 注释自认"立方近似指数"）而标签叫"指数"（:25）——真指数/等功率淡出（10^(-3t)）与 t³ 在长淡出（10s+）听感差异可闻，懂音频的用户被标签误导；S 形余弦=等功率平滑过渡✓实现正确
2. 【可用性】试听须从头播到尾：playBuffer 从 0 播整曲（`:59-63`；`audioEngine.ts:508` src.start() 无偏移参数），曲尾淡出要听完才知道效果；无停止按钮（家族共性，见 audio-trimmer.md 扣分点4）
3. 【可用性】fade 区域零可视化：波形已在页面上（AudioToolBase）但淡入/淡出范围没有任何视觉映射——改 2s→5s 全靠想象；audio-trimmer.md 处方 5（渐变阴影方案）同样适用本工具却未实现
4. 【功能】无任意位置淡入淡出：只能作用于文件首尾（curvedFade :46-47 首/尾循环）；中段某点淡出再淡入（电台串播/合集衔接常见）做不到，须裁剪工具接力而动线未打通
5. 【功能】无淡出目标电平：只能淡到绝对静音（shape 终点增益 0），mp3cut.net/Audacity 支持淡到指定电平（如 -20dB 保留底色衔接人声）
6. 【交互】时长手输无滑条与时长上限提示：不知道总长时 0~? 只能试；输入超总长静默钳制（:40-41）但 UI 不反馈"实际淡出被截短为 X 秒"
7. 【可用性】导出无进度：`:71` encodeMp3 无 onProgress（家族共性，见 audio-trimmer.md 扣分点3）；试听前 apply（:62）整曲重算同步阻塞，长文件点试听先卡
8. 【交互】曲线/时长/格式均不记忆；输出名 -fade 后缀固定（:77）
9. 【家族共性】波形纯静态（`AudioToolBase.vue:70-81`，见 audio-trimmer.md 扣分点1）；执行按钮流内底部（M-15；共性-根因 4）

## 行业对标与差距

- **mp3cut.net**：剪切页内置 Fade in/out 勾选，选区+淡入淡出+试听一屏闭环。差距：试听定位与可视化闭环——本工具效果参数更全（三曲线）但验证成本更高。
- **Audacity**：Fade In/Out（线性）与 Studio Fade Out（等功率曲线）+增益包络可视化——曲线真实度的参照（桌面标注天花板外：等功率余弦本工具已有，补真指数即可拉平）。
- **audioalter.com**：一键式效果全家桶，即拖即试。差距：即拖即试的轻量感。
- 借鉴优先级：**试听定位（淡出区起点起播） > fade 区域波形阴影 > 真指数曲线 > 增益包络小图 > 参数记忆**。

## 优化处方（验收标准）

1. **试听定位**：新增"试听淡出"按钮，从 max(0, 全长−淡出−5s) 起播到曲尾，可停止。→ **验收：设淡出 3s 后点该按钮，起始位置正确且播放到曲尾自动停**
2. **fade 区域可视化**：波形首尾按淡入/淡出秒数渲染渐变阴影。→ **验收：设淡入 2s/淡出 5s 后波形两端阴影宽度比例正确，改回 0 阴影消失**
3. **曲线更名或实现真指数**：标签改"立方/余弦/线性"或实现 10^(-3t)。→ **验收：曲线名称与实现一致；长淡出（10s）三曲线试听可辨差异**
4. **钳制反馈**：输入淡出 30s 但总长 20s 时提示"实际淡出 20s（已按全长截短）"。→ **验收：提示文案出现且波形阴影按 20s 渲染**
5. **包络小图**：120×60 增益-时间曲线随参数实时更新。→ **验收：切换三条曲线小图形状即时变化**
6. **导出进度**：编码期间百分比递增。→ **验收：10 分钟音频导出期间进度 0→100%**
