# 第一部分 产品结构与设计说明

## 1. 产品定位

百宝工具箱是一个**纯浏览器端（client-side）工具聚合平台**：

- 核心承诺：文件永不上传、无需注册、无水印、无体积限制、加载后可离线使用。
- 技术：静态站点 + 客户端 JS/WASM 处理（Web Crypto、Canvas、pdf.js/pdf-lib、ffmpeg.wasm、浏览器内置 AI 推理框架等）。
- 不投放页面广告。

## 3. 视觉设计体系

**主题**：默认深色（深海军蓝底），可切换浅色。
- 背景基调 `#0a1018 ~ #0d1424`，面板 `#111a2c` 半透明 + 1px 细边框（rgba 白 6-8%）
- 强调色：靛蓝 `#6366f1`（首页/工具页均以靛蓝为主，个别分类使用主题色区分）
- 圆角：面板 16px、卡片 14px、胶囊 999px
- 字体：中文「系统无衬线 + Noto/苹方/雅黑」栈，本地优先，不加载外部字体
- 卡片：图标圆角方块（带低饱和彩底）+ 标题 + 右上角星标收藏按钮 + 两行截断描述

**首页区块顺序**：

**工具页布局**：

## 5. 技术选型

| 能力 | 选型 |
|---|---|
| 图片处理 | 原生 Canvas + OffscreenCanvas（零依赖引擎） |
| HEIC/TIFF 解码 | 纯 JS 解码库（heic2any / utif，懒加载） |
| OCR | tesseract.js（首次加载下载语言包） |
| 背景移除/上色/放大/图像分类 | transformers.js（首次加载下载模型，浏览器缓存）+ 传统算法兜底 |
| PDF 读写 | @cantoo/pdf-lib（读写+加密）+ pdfjs-dist |
| PDF→Office | pdf.js 文本提取 + docx / SheetJS / pptxgenjs 生成 |
| Office→PDF | mammoth(docx→HTML)/SheetJS + jsPDF 输出（基础版） |
| 音频编解码 | WebAudio 解码 + WAV 自研编码 + lamejs（MP3） |
| 视频处理 | @ffmpeg/ffmpeg（懒加载 core，首次使用提示）+ Canvas/MediaRecorder 兜底 |
| 表格/图表 | papaparse + SheetJS + hyparquet + Chart.js + alasql(SQL) |
| 文本/AI | 词典/统计算法即时可用 + transformers.js 可选增强 |

**约束**：核心工具 100% 本地；需要模型/编解码器的能力统一遵循「首次加载后离线可用」模式，界面明确标注。全量依赖（仓库、许可证、引入理由）见各版本文件夹的 `依赖清单-V<主.次>.md`。

## 6. 产品决策
1. 品牌：**百宝工具箱 / ToolHub**，闪电 Logo（原创 SVG），口号「你的文件，永不离机」。
2. 语言：简体中文 UI；工具 URL slug 为全站唯一标识，一经发布不再更改。
3. 覆盖策略：**全部 11 分类 + 4 编辑器**全部建模；每个工具都有真实可用的实现（共享引擎 + 模式化组件），重度能力（AI/OCR/ffmpeg）懒加载并在 UI 标注首次下载。
4. 独立可部署：`npm i && npm run dev / build`，产物为纯静态文件，可放任意静态服务器。
5. 版本化文档：每个功能版本一个基线文件夹（需求/设计/工具清单/依赖清单四件套），见根目录 `AGENTS.md` 的文档规约。

## 8. 工具注册表格式

每个分类一个 `registry.ts`，导出 `ToolDef[]`：

```ts
import type { ToolDef } from '@/types'

const tools: ToolDef[] = [
  {
    slug: 'merge-pdf',
    title: '合并 PDF',
    category: 'pdf',                 // 分类 id
    desc: '把多个 PDF 按顺序合并成一个文件，全部在浏览器本地完成。',
    keywords: ['pdf 合并', 'merge', '拼接'],   // 搜索关键词（中文/英文）
    component: () => import('./components/MergePdf.vue'),  // 懒加载工具组件
  },
]
export default tools
```

`ToolDef`（见 `src/types.ts`）：slug/title/category/desc/keywords/component|textDef|calcDef/imgcvt/needModel?。
工具组件的约定：**不自带页面框架**，只渲染工具面板内容（见 §11 ToolPage）。需要与页面通信时用注入的 `toolMeta`。

## 12. 十一种实现模式（含示例约定）

1. **text**：`TextTool.vue` 通用组件 + `registry.ts` 内声明 `{ kind:'text', transform: (input, opts) => output | Promise<output>, options: [...] }`。输入/输出双 textarea + 复制/下载/交换 + 选项表单。
2. **calc**：`CalcTool.vue` 通用组件 + 配置化字段（fields: NumField/SelectField/DateField/CheckField...）+ `compute(values) => ResultRow[]`（label+value+强调位）。特殊布局（如图表）走自定义组件。
3. **img**：自定义组件用 `FileDrop` + `imageEngine.applyOps` + `CanvasStage` 实时预览 + `DownloadBar`。交互型（裁剪/取色/打码）在 canvas 上叠加鼠标交互层。
4. **imgcvt**：`ImageConvertTool.vue` 通用组件 + `{ from: string[], to: 'image/png'|'image/jpeg'|'image/webp', quality?: boolean }`。批量多文件 + ZIP。
5. **pdf**：自定义组件 + `pdfEngine`。页面型操作先渲染缩略图网格。
6. **aud**：自定义组件 + `audioEngine`；波形预览 + 操作按钮 + 编码选择。
7. **vid**：自定义组件 + `videoEngine`（Canvas/MediaRecorder 快路径）或 `ffmpeg.ts`（重转码）。ffmpeg 首次使用显示下载提示。
8. **data**：自定义组件 + `csvEngine`/`officeEngine`；表格用虚拟滚动（>1000 行分页即可）。
9. **compare**：`CompareTool.vue` 通用双输入 + 各自 transform/diff 函数；图像对比为专用组件。
10. **ai**：优先 `nlpEngine` 纯本地算法（即时、离线、诚实标注「规则模型」）；图像/AI 增强型（OCR/抠图/转写/翻译/描述/检测/分类）用 `useModel()` 懒加载（tesseract.js / transformers.js），UI 显示模型下载进度与缓存说明。
11. **special**：完全自定义组件（二维码、科学计算器、录音机、番茄钟、发票、简历等）。工作室（`studio: true`）共 8 个注册项，复用 `editors/components/` 下 4 个组件（PdfStudio/VideoStudio/PhotoStudio/DataStudio），以「XX编辑器」「XX工作台」双入口出现在对应分类。

## 13. 质量与规范

- TypeScript strict；组件 `<script setup lang="ts">`；避免超长文件（>300 行须拆分组件/composable）
- 所有用户可见文案简体中文；注释中文
- 错误处理：解析失败给出中文友好提示（`useToast`），不得英文报错透传
- 大文件：异步 + 进度条；>50MB 给出提示
- 单元换算/金融公式等给出「计算口径」说明文字
- 金融/历法等高口径敏感工具落地前先核对金标准（税率表/国标示例/公开常量），落地后以金标准哨兵锁定
- 所有文案与图片资源均为本项目原创（中文文案 + 自绘 SVG），不得引入任何第三方站点素材
